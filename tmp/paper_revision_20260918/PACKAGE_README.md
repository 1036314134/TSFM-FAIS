# Peer Repair and Forecast Fusion for Missing Sensor Histories

Open `tsfm_fais_iclr2027.pdf` to read the manuscript. The package contains one current manuscript, its editable LaTeX sections, the bibliography, vector figure assets and supplementary result tables.

Compile from this directory with a standard TeX installation:

```text
pdflatex tsfm_fais_iclr2027.tex
bibtex tsfm_fais_iclr2027
pdflatex tsfm_fais_iclr2027.tex
pdflatex tsfm_fais_iclr2027.tex
```

The included layout files follow the repository's existing conference format. The document header identifies a manuscript and does not assert submission or acceptance. Authors remain anonymous.

The primary procedure and the scope of its existing evaluation are defined in the manuscript. The supplementary results README describes the metrics, method identifier and developmental status. No raw datasets or trained model weights are needed to compile this package.
