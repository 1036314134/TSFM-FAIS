# R22：共同预测偏差的缓存诊断

2026年9月15日，R21固定标记干预停止后登记。该步骤是经典预测校准对照，不是ELF复现，不作为新方法贡献。研究定位问题是：候选之间的选择没有稳定收益时，候选中位数共有的偏差是否能从已到达的过去反馈中估计？若可以，后续方法需要明确区分通用预测适配和缺失处理带来的增量。

完全复用已核验R19的24个开发任务、每任务8个历史锚点、generic/shuffled/matched三个掩码规则、两预测器的冻结预测和过去原观测目标。无新基础模型调用，无新填补或神经训练，不扩大R19锚点、阈值、种子，也不改变A的停止决定。当前未来均已用于开发；本诊断不能称独立确认。

以八候选预测中位数为共同基准。对每个目标分别拟合三个固定经典控制：过去残差的加权均值作为常数校正；过去残差的加权中位数作为常数校正；向恒等变换收缩的两参数仿射校正。每历史总权重1/8，其内部仅对原可观测未来等权。残差和预测按该目标训练前缀均值/总体标准差表示。

仿射控制令p为过去中位数预测，r=y-p，x=(p,1)。固定求解min_delta sum_i w_i(r_i-x_i^T delta)^2 + ||delta||^2，部署输出p_current+x_current^T delta。正则系数固定为1，无网格，无当前误差调参。均值和中位数控制对应delta=(0,b)。加权中位数遇到精确半权重边界时取两相邻残差的中点，数值判断容差1e-12。

三掩码规则各三个校正，共9个新诊断输出。保留R19原median8、mean8、源MAE单候选/固定组合、源联合固定组合、两个长历史原生对照，以及三个规则的ERM结果，共19个报告方法、912条窗口评分。当前所有校正参数与预测在读取当前未来前冻结。核验时间边界、原产物身份、均值/中位数的一阶条件、仿射正规方程、独立目标损失及原基线重放。沿用R19四来源组的逐层等权汇总，MAE为主、MSE完整保留。

本步骤直接执行短缓存诊断，不等待半小时。控制效果只回答这种低容量校正是否有可用信号；无论结果如何，都不能将经典仿射校正或过去反馈本身包装为论文创新。通用在线适配的已有代表是ELF，其包含在线线性预测器及组合权重机制，目标与实现比此处常数/仿射控制更完整：https://proceedings.mlr.press/v267/lee25ag.html 。
