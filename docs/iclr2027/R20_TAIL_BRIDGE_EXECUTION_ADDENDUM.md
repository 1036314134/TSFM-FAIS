# R20 执行补充登记

登记于正式全量预测与新误差评分之前。主体协议、已经冻结的事件清单和小批吞吐输入保持其原有身份。

共53个输入：36个人工末端遮盖输入、11个共同通道自然停报输入、6个仅TimesFM适用的自然输入。Chronos执行47个、TimesFM执行53个，共100个输入与模型配对。每个联合或独立目标请求范围保留八候选H96、八候选H96+g、原生桥接，以及原生长历史1024和4096两个对照。完整逻辑请求数为47×19+53×2×19=2907；缓存去重、重复一致性请求与实际模型批次单独计数。

长历史对照具有额外历史信息，单独命名为native_long1024和native_long4096。起点为max(prefix_end,t-length)，结束于t，最后96步覆盖为本次已遮盖上下文，禁止从长历史恢复人工隐藏的末端观测。

每个输入与模型配对固定29个预测输出：普通跨度八个单候选与预算匹配八个单候选；两种跨度各自的均值、中位数、源MAE最佳单候选、源MAE固定组合、源联合固定组合；bridge_native；两个长历史对照。源固定控制直接复用已核验R19 source_defaults.json，不重新拟合。共2900个窗口评分和5800个目标评分。MAE为主，MSE全部保留，两个目标各自按原可观测未来计分后等权平均。

自然共同面板11个事件是两个模型的主要配对比较。TimesFM额外6事件及其全部17事件分别报告。人工面板按g=8、24、48分别呈现，也提供三种g等权的机制汇总；这些遮盖共用12个历史，不能计为36个独立历史。汇总先在相同历史内平均g，再在序列内平均历史，接着平均序列得到数据集值、平均数据集得到来源组值，最后等权平均来源组。新加坡两数据集归入同一来源组。

主比较固定为bridge_native对median8和budget_median8。同时完整保留各固定强对照和来源结果。自然面板样本少且已用于开发，只提供描述性结果，不作独立确认或显著性声明。代码、配置、依赖版本、小批成本、冻结产物和失败记录一并保留。
