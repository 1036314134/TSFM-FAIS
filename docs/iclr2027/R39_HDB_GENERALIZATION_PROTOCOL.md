# R39：新时段车场数据上的方法适用性检查

2026年9月17日，R38停止后、车场预测和评分之前登记。本轮检验北京上的固定静态填补与VAR各半组合是否能迁移到另一应用场景。主方法half_var_full_gaussian保留其经典组合身份，不以本轮重新命名或宣称新算法。若没有稳定增量，后续方法不能建立在其普遍有效的假设上。R38的相关性组合不继续调参。

数据仅采用已完整采集和独立核验的官方HDB C类型新鲜小时值。总56天分为四段，每段336小时：6月1日至14日为拟合前缀，6月15日至28日为本轮开发段，6月29日至7月12日为未评分确认段，7月13日至26日继续封存。本轮任何拟合、人口选择、预测或评分只分析前672小时。后两段的原始采集与质量核验不等于预测方法已经使用它们；它们也不构成全新独立来源或预训练未见证明。

所有目标需在336小时前缀拥有至少256个原观测、至少128个相邻观测对，且总体标准差大于1e-12。自然任务在开发段内、预测跨度H24完整落在该段时，取目标末端缺测年龄6、30、54小时的时刻，要求192小时上下文至少96个目标观测、未来至少12个原观测；未来支持仅用于定义可评分人口，不读取其数值或误差进行选择。每车场先按时间去除重叠未来，再最多等距保留2个事件。存在合格事件的车场按SHA256(r39|7401|标识)排序，取前32个，不足32则全部保留并报告实际数量。所有未选车场和事件、排除原因都记录，结论限于这类有前缀支持的近期缺测任务。

同一目标集合增加两个固定开发时刻384和552的原生及人工缺测辅助面板。两者都要求历史目标至少96个观测、未来至少12个观测；人工任务还要求最后24小时至少12个目标原观测，并仅隐藏目标最后24小时，其他原缺口保持。人口在预测前冻结，各面板分别汇总，不按准确度删除任务或改选目标。

每目标从所有满足前缀支持的其他车场中按前缀成对原观测的绝对Pearson相关排序，最少128共同观测，同分按标识排序。按此顺序最多选6个peer，只有加入后共同完整前缀行和相邻完整对均至少128才接受。选择只读前336小时，候选及接受顺序留存；所有方法使用相同已选择信息。标准化采用各列前缀原观测均值和总体标准差，退化尺度按既定规则置1。目标只有C类型可用量，不混入M类型，不按总容量截断预测。

R35的固定Gaussian静态填补和VAR拟合、0.001 ridge、谱半径0.99上限、协方差0.95完整加0.05对角及1e-6数值正则全部沿用，不扩参数。每历史在原观测位置精确保值。新增场景的简单填补控制为前缀中位数、仅向前携带、窗口内线性插值、日周期回填、前缀KNN（5邻居、统一权重、标准化nan-euclidean距离）；日周期回填用当前点之前最近的同小时原观测，无此信息时用前缀同小时中位数。KNN和Gaussian分别另列仅填目标的控制，其他peer原缺口保持。

Chronos2沿用冻结参数和原0.5分位读出。11个输入查询分别为原生目标192、原生联合192、原生联合至多336、6个全列填补、2个仅目标填补。仅为全部原生查询共同排除当前192历史少于2个观测的peer，目标始终保留；全列填补同样使用该查询列集合。原生长历史读取同一预测时刻之前至多336小时，作为更多历史的明确强控制，不伪称等上下文预算。7变量上限和实际列数、每次输入、原始分位及计算时间均保存。

六全列填补和两仅目标填补共8个预测，加原生联合192构成9候选池，固定均值/中位数均报告。保留所有13个基础模型点输出（11单次与2池组合），并逐一增加与同一VAR各半组合，避免只给主填补增加统计预测信息。另有VAR、日周期朴素、周周期朴素、前缀小时均值4个统计控制，以及静态Gaussian预测与周周期朴素各半，共31个输出。日/周周期朴素从当前192历史沿24/168滞后寻找最近原观测，没有则回退前缀同小时中位数。前缀小时均值以未来日内小时索引，不利用未来测量。主half_var_full_gaussian仅需一次基础模型调用和统计递推；池组合、长历史和完整实验审计的成本分别计数。

所有完整预测冻结后才评分。主自然缺测面板以目标车场内窗口等权、再车场等权汇总前缀标准化MAE/MSE；同时保留每窗口分数、各车场分数和逐车场排除敏感性。辅助原生/人工面板不合并为更有利的总分，不把车场当成独立来源。冻结预测参数、填补观测保护、peer选择、输入时间、查询重放与指标独立核验完成后才分析。没有神经填补器或其他预测器的本轮结果只能作为投入判断，不能据此宣称完整基线胜出或投稿就绪。

若主方法未超过同样VAR组合及强季节/原生/池控制，停止将该固定各半组合当成可迁移技术前提，不通过本开发段筛选新权重；若存在稳定信号，再登记更强填补与第二预测器检验，并保留后段确认。每30分钟检查一次正式进程，运行时不分析或编码，9月18日起不新增实验。
