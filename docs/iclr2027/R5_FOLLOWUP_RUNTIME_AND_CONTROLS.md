# 新验证的执行和对照说明

新输入准备与审查已完成，覆盖 823 个任务、39 个前缀标准化器、7 个数据集和 14 个成功拟合的神经填补模型。两个部署表示单元检查通过；15 个源开发家族的真实输入回放中，40 维组合特征与原缓存的最大差异为零。四个冻结选择器的 90 个联合或目标决策全部相同。该检查没有新增预测器调用或读取新验证未来。

新方法的训练误差对象是三元组实际返回的预测中位数与完整源历史教师预测之间的差异。成员目标对照使用相同三元组、特征和配对分类器，但标签是三名成员分别相对教师的误差均值。两者均在部署时使用当前可见历史和七个候选预测；源教师和真实未来均不是部署输入。旧个体教师前三规则使用其原 33 维表示和原冻结模型，不重新拟合。

本次执行保留 16 个预测输出：七个单候选，组合误差学习规则，成员误差学习规则，新规则的源固定三元组，原个体教师前三规则，旧源固定三元组，七候选预测中位数/均值以及六个有限填补候选的预测中位数/均值。两种源固定组合的区别需要明确：新规则使用冻结学习器训练时记录的共同最优组合；旧版保留已有源训练选择的组合，TimesFM 可以按目标分别固定。二者均仅依据已保存的源训练结果，没有依据新验证的预测误差选择。主比较仍为组合误差学习规则与七候选预测中位数。

上述 16 输出的完整执行列表在候选预测阶段补充写明，此时尚未运行新策略评分或读取新未来误差；不能声称这份逐项列表早于首个候选查询。原协议的主要方法、匹配对照、七候选池、指标及三个数据面板没有改变。新增明确列出的两个源固定实现均作为对照保留。

候选预测阶段只保存七个预测器输出，参数摘要必须与原已审查的冻结预测器相同。策略应用阶段先生成两套可见特征，批量应用源模型，保存每个选择以及全部 16 个最终预测。完成这些文件后才读取真实未来，并仅在原观测位置计算误差。审查阶段独立累计比较器投票、按候选名称重建中位数、检查原方法排序并复算逐窗口及家族宏平均误差。运行时只记录特征构建和批量选择耗时；这些数字不能当单次在线端到端延迟。

新来源原生缺失、已见家族未用序列及人工缺失分别报告。两个新原生来源和两个新人工缺失来源的家族数量都有限，汇总器给出每个家族的成对效应及所有对照，不据小样本声称总体显著性。多个掩码保留其共同历史标识。候选失败状态及相应回退也单独计数，不能用“模型拟合成功”替代窗口运行有效性的说明。

当前候选预测、策略评分和综合审查的完成状态必须以对应产物及实际进程判断。准备和回放通过不代表预测效果已经改善。
