# 同八候选池的迁移结果

短迁移完成68,340条评分，预测重建最大差7.11e-15，指标重算差为零；MoTM单独输入和八候选中位数在所有原面板复现。没有新增上下文拟合或时序预测器调用。证据位于artifacts/iclr27-r12/motm-pool-transfer-v001。

旧七家族原始缺失上，八候选学习器Chronos为0.612652/0.800212，TimesFM为0.619109/0.800245，仍弱于同池中位数0.609386/0.797358与0.613597/0.793853。八候选固定联合目标分别为0.612523/0.808967与0.617087/0.793427，TimesFM存在更好MSE与更差MAE的取舍。候选数不足不能作为此前迁移失败的主要解释。

人工缺失H96上，新学习器C=0.608675/1.115826、T=0.593234/1.092591；TimesFM虽优于同池固定控制和中位数，但弱于原七候选联合目标的0.582252/1.065021。Chronos仍有MAE/MSE取舍。北京原始缺失上也没有统一优势，其他跨度和全部种子保留。当前不将八候选扩展宣称为已解决真实缺失的改进。

下一项只检验训练分布：在相同八候选、联合目标下加入其他家族的真实缺失历史，当前测试组整体排除，另以纯源历史匹配更新次数。此前七候选MSE扩展的失败保持有效；本轮复用旧数据作分组开发验证，不能增加独立确认数量。
