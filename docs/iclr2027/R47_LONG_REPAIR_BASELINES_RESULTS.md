# R47：长历史固定填补基线结果

2026年9月17日19:41，准备、预测、评分和独立审计全部完成。长历史与现成填补的组合进一步降低了北京自然缺失预测误差，但HDB自然缺失仍以原生长历史预测更好。此次补齐了有必要保留的强基线，没有训练或提出新算法，也没有建立独立确认结果。

## 设计与完整性

沿用北京231、HDB83任务、六个面板。模型可用历史上限8192；北京实际使用8192，HDB使用349—586小时。只在最近192点的原目标缺口写入冻结填补轨迹，更早历史、目标原观测和所有非目标变量及其NaN保持不变。每种填补分别采用原变量范围和仅目标范围预测，并保留与原VAR预测各半的控制。填补器没有额外利用长历史或重新拟合。

HDB另补六种仅修复目标的192点原变量范围对照。旧median/ffill/linear/seasonal24全变量填补还会改变辅助列，不能直接作为此次匹配的短历史对照；KNN/Gaussian的新短对照则分别精确恢复旧target_knn/target_gaussian。

独立审计重放3342次修复查询和628次原生长查询，预测最大差0；166次既有HDB短控制恢复精确，67959个旧输出保持。74643窗口分数、136089目标分数以及站点聚合、逐站排除结果通过原指标容差检查。四阶段记录耗时约38.99分钟，审计约占其中19.78分钟；这不含此前填补轨迹和VAR拟合成本。后28天HDB数据继续未评分。

## 六面板结果

下表列出本轮新增方法中MAE最低的描述性结果及此前最低MAE参照。选择发生于开发结果读出之后，不构成预设主方法、统一策略或显著性结论。MAE/MSE均采用原观测训练前缀均值和总体标准差单位，所有指标越低越好。原量纲与前缀单位的长原生近似重复项按前缀版本列示。

| 面板 | 本轮最低MAE方法 | MAE / MSE | 此前最低MAE方法 | MAE / MSE |
|---|---|---:|---|---:|
| 北京自然H24 | 长peer ridge修复、原变量预测、与VAR各半 | 0.388053 / 0.244688 | 短KNN目标修复、与VAR各半 | 0.397000 / 0.264402 |
| 北京人工H24 | 长local ridge修复、仅目标预测 | 0.507640 / 0.542087 | 短local ridge修复、仅目标预测 | 0.508233 / 0.592891 |
| 北京原生H96 | 长peer ridge修复、仅目标预测 | 0.794642 / 1.431789 | 长原生、仅目标预测 | 0.789801 / 1.416477 |
| HDB原生网格H24 | 长median修复、原变量预测 | 0.447686 / 0.638002 | R46仅限制辅助未来时间键控制 | 0.446839 / 0.638954 |
| HDB自然H24 | 长median修复、仅目标预测 | 1.263786 / 4.012167 | 长原生、仅目标预测 | 1.178178 / 3.887765 |
| HDB人工H24 | 长seasonal24修复、原变量预测 | 0.771148 / 1.495462 | 缺失扰动LoRA控制 | 0.643229 / 1.120020 |

北京自然面板的上述VAR各半组合，相对此前最低MAE控制改善2.25%/7.46%，MAE在8/12站、MSE在10/12站更低；逐一排除站点后的相对变化仍为MAE −3.96%至−1.42%、MSE −9.24%至−6.17%。本轮最低MSE来自长KNN修复与VAR各半，为0.388676/0.244071；相对此前最低MSE的长原生与VAR各半控制，MAE/MSE改善5.83%/7.49%。两个控制身份不同，不能合并成同时取得各列最小值的方法。

北京自然面板不依赖VAR组合也存在收益：长Gaussian目标修复、原变量预测为0.391787/0.252425，相对同长原生0.484839/0.359322改善19.19%/29.75%，相对同修复短预测0.429044/0.311819改善8.68%/19.05%。同长比较只改变当前目标缺口的处理；长短比较增加了历史信息。两种效应分别成立，不能混为一次新算法收益。

北京人工面板的最低MAE只比既有隔离local ridge改善0.12%，MSE改善8.57%，逐站胜出为6/12和7/12。逐站排除后的变化范围分别为−4.28%至+5.04%、−14.86%至+3.38%，结论对站点组成敏感。相同长local ridge修复下，仅目标预测比原变量范围改善16.56%/29.45%，说明R44的变量范围差异在长上下文下仍存在；这不证明某一缺失机制造成了该差异。

北京H96的全部新增方法仍未超过长原生仅目标MAE或其VAR各半MSE。虽然八个长修复版本相对各自短版本都在12/12站改善MAE/MSE，但同长原生更强，不能据长短对照宣称填补在此面板有贡献。

HDB自然面板全部新增修复及VAR各半组合的MAE、MSE均高于长原生仅目标。新增最低MAE方法仍退化7.27%/3.20%，只有5/18车场双指标胜出；逐站排除后的MAE/MSE退化范围为3.98%—11.08%和1.16%—6.45%。在原变量范围内，长median修复相对同长原生也退化5.46%/1.72%。更长历史能改善多数短修复，但没有改变该强比较结论。

HDB网格的长median修复比此前最低MAE控制差0.19%，MSE低0.15%，均对逐站排除敏感，属于小幅指标取舍。HDB人工的最佳新控制仍比缺失扰动LoRA差19.89%/33.52%；固定VAR混合不能解决该来源上的退化。

## 后续研究判断

R47应加入完整基线，尤其北京自然的长Gaussian/peer ridge/KNN及VAR组合、北京人工的长仅目标local ridge。此前较弱的短输入原生或填补对照不足以支撑新的精度主张。R42—R46的主负结果保持，不将R47控制重新命名为这些主方法成功。

当前可支持的是特定北京开发面板上的固定修复收益，以及明显依赖来源、时间跨度和变量范围的结果差异。它们尚未提供可部署的判别规则；按已知面板选赢家会使用开发标签。下一项方法立项需要同时明确机制区别、实际部署可见的判断依据、同信息强比较和未用确认范围。HDB没有改善不能否定所有领域限定的方法论文，但若据此缩小到有力跨传感器关系的应用，必须将新范围作为开发假设重新登记和确认。

此时没有足够依据自动启动又一轮同族参数、注意力规则或门控网格。后续研究问题与近期先例的复核见[阶段研究判断](E:/ZMY/Github/TSFM-FAIS/docs/iclr2027/RESEARCH_REASSESSMENT_AFTER_R47_20260917.md)。论文仍保持方法定位；当前未达到投稿就绪状态。
