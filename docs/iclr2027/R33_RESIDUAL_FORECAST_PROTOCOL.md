# R33：共有成分与剩余成分的预测分解

2026年9月17日，R32完成并按停止条件结束后登记。R30的peer_ridge仍是自然缺测最强MAE控制，R31/R32在两个填补专家之间学习选择未获得稳定增量。R33检验不同计算路径：跨站关系解释的成分与目标剩余成分分别预测，再还原目标。它是确定后续方法方向的固定探针，不是已经成立的新算法。

回归加剩余项预测已有公开实现。TimesFM的官方XReg接口包含相应模式，并要求动态协变量覆盖历史与预测长度；本实验的未来协变量仅由冻结预测模型产生，绝不读取真实未来。[官方API说明](https://github.com/google-research/timesfm/blob/master/timesfm-forecasting/references/api_reference.md)、[官方回归实现](https://github.com/google-research/timesfm/blob/master/src/timesfm/utils/xreg_lib.py)。本实验使用Chronos及原缺失输入，不能称为TimesFM接口的完整复现，也不能把经典分解本身作为论文新颖性。

数据沿用R30全部231任务：自然H24主面板45、人工H24辅助48、原生缺失H96辅助138。全部属于同一北京开发来源，三个面板分别报告。原17个通道、R27选择的peer、原20%训练前缀7012小时及标准化参数不变。主指标为标准化下游MAE，MSE完整保留；原37个控制逐值复用。

每个目标在训练前缀上拟合ridge，损失中lambda=0.001，截距不惩罚，至少128个共同原观测。候选解释变量为当前192小时内至少有两个原观测的非目标通道，两个PM目标均排除，以免用另一目标的预测替代尚待解释的目标信息。支持不足时按既有前缀相关性规则去掉最弱解释变量；没有可用解释变量时使用零共有成分，保留该退化情况。整个窗口和预测区间使用同一个前缀模型，不随未来观测调整系数。

在目标和所选解释变量均有原观测的历史位置，计算r=y_z-beta_0-X_z beta。任何所需单元原本缺失时，该位置的r保持NaN，不用填补值制造残差标签。r的均值和总体标准差只在原前缀共同观测位置估计；小于等于1e-12的标准差置1。当前历史的r按此前缀尺度标准化。两个剩余序列共同输入冻结Chronos；某目标少于两个原可计算历史r时不调用该行，并令其预测剩余项为0。

解释变量的未来取R30同信息native_peer查询的已冻结中位预测，计算共有成分c_hat=beta_0+X_hat_z beta。预设主输出residual_tsfm为c_hat加上Chronos预测后还原尺度的剩余项。三个控制分别为residual_zero（c_hat本身）、residual_last（加最近可计算的历史r）、residual_ar1（以前缀估计并裁到[0,.99]的AR系数，将最近r向前缀均值衰减到实际未来时刻）。没有历史r时三个剩余项均为0。原native_peer查询在实际部署需一次调用，主分解另需一次剩余序列预测；实验缓存节约不能算作单次部署调用。

未来解释变量是模型预测，分解项相加也不是经验证的联合概率中位数。因此不宣称概率校准、真实协变量已知或统计最优保证。4个新输出加原37个，共41方法、9471窗口/18942目标分数。R31/R32的H24负结果保留在原文件，并在跨轮分析中参考，不伪造H96对应值。
