# R37：静态条件不确定性向冻结块编码器传播

2026年9月17日，R36主方法失败后登记。固定half_static_var控制有稳定开发收益，后续必须保留为强基线。本轮没有新增神经训练，不重启低秩协方差、动态模型或采样数量搜索。新检验对象为静态条件填补的表示：以条件矩近似替代单个填补值经过非线性编码后的表示，再与同样的VAR预测组合。

沿用R35静态full的逐值填补均值、17变量、原7012小时前缀及R30的231个历史。C0为已冻结的0.95S+0.05diag(S)+1e-6I。均值保持原实现；计算缺口不确定性时把1e-6I作为条件求解的数值正则，不当作真实缺失变量方差。具体使用Sigma=C0-1e-6I及Sigma_MM-Sigma_MO(C0_OO)^(-1)Sigma_OM，观测位置方差和协方差为0。该工作分布等价于对观测端施加小的正则噪声后推断缺口，原观测输入仍保持已知测量值。时间间独立是明确假设，不声称真实后验已校准。

条件协方差只允许既有1e-10倍max(1,谱范数)内的负特征值作为舍入裁0。静态均值直接取冻结输入，不改原始观测。所有计算在原前缀z单位中进行。标准化后进入模型的原观测表示逐值保持；实际评分口径仍为原训练前缀均值和总体标准差。

为避免把单次均值填补的方差等同于完整历史方差，模型内部使用后验二阶矩归一化。令L=192、均值轨迹m_t、条件边际方差v_t，中心取原均值轨迹的平均，平方尺度为Var_t(m)+(L-1)/L² sum(v_t)。该式利用本工作分布的跨时间独立假设；不等于真实随机标准化后的精确积分。若该通道所有v为0，直接保留原模块的统计以确保恒等路径。输出使用同一选定统计逆变换。

本地检查点的输入块为48→3072→768的ReLU残差MLP，没有该块末端LayerNorm，且标准化后使用arcsinh。先以固定9点Gauss–Hermite求每个不确定数值经arcsinh后的均值与方差，原观测零方差位置直接保留原数值表示。时间与有效标记是确定量。线性层传播这两个矩；隐藏层用高斯矩匹配与E[ReLU(Z)]=s*phi(m/s)+m*Phi(m/s)计算均值，零方差恢复普通ReLU。输出投影及残差支路使用其均值。arcsinh后的线性和近似为高斯，后续Transformer没有传播完整协方差，因此整个方法不是精确Bayes预测。

四个固定条件共享上述二阶矩归一化：仅归一化；只替换arcsinh后的数值均值；只替换ReLU期望而保留原数值均值；两者都替换。预设主为最后一项与VAR各半的hybrid_posterior_moment，其单独基础模型输出另报。对不确定性为0的整个块，直接保留原块输出；未来块不作改写，原时间编码、有效标记、注意力和模型权重保持。另以未条件化的源边际方差填入缺口作为同结构对照，检验条件不确定性是否必要。

固定16条静态条件历史（8对正负样本，基种子6103及任务标识）提供两个参照：只对输入块编码取Monte Carlo均值后调用一次后续模型；以及对完整模型执行16次预测。样本使用同一选定归一化统计，不随样本重新估计。完整模型参照报告原0.5分位的均值/中位数，以及同R35整数质量分位混合的均值/中位数；每项同时报告原输出和与VAR各半的输出。MC误差与分布假设限制保留，不增加样本数或挑种子。

保留R36全部87个输出。新增固定强控制为原25基础输出及target_static_point分别与VAR各半（26项，原full_static配对已保留），以及三个R36学习组件与VAR各半（3项）。另由原静态单次分位得到均值/中位数及对应VAR组合（4项）。四种矩条件各报单独/组合（8项），未条件方差与MC块均值各报单独/组合（4项），完整MC四种聚合各报单独/组合（8项）。合计140方法、32340窗口/64680目标分数。主自然H24 45、人工H24辅助48、H96辅助138分别汇总，MAE为主，MSE全量保留。

主方法每任务一次完整预测，加局部矩计算；MC块参照额外计算16组输入块，完整MC参照需16次完整预测。实际计算与验证开销单列，不把多项共享输出算作独立证据。不得仅比较单独F而忽略同样的VAR组合，也不得把固定组合本身称为新技术贡献。
