# 固定选择器的独立历史学习曲线

本阶段判断增加独立监督历史是否可能改善现有预测收益选择器。仅使用已完成的 R4 缓存，保持原始输入预测流程以及训练前缀标准化后的 MAE/MSE，不把本批结果与 R5 先标准化输入的表格混合。它是已有选择器的数据效率诊断，不预设训练数据不足，也不预设能改善论文方法。

5940 个源训练任务来自 165 个独立历史起点。同一历史的全部缺失机制、缺失率、随机掩码、候选和预测目标始终保留在同一分组。对每个家族、数据集和序列内部，按固定哈希次序选取 25%、50%、100% 的起点，向上取整且至少保留一个。三个抽样种子为 6101、6102、6103，25% 的集合嵌套于同种子的 50%，再嵌套于全量集合。抽样只读取起点与来源标识，不读取任何误差。三个分组、完整性和结果扰动检查已通过。

保持原 `UtilitySelector` 的设置：响应与静态特征、160 棵树、15 个叶节点、步长 0.05、最小叶样本数 25、L2 正则 5、模型种子 5101、平方回归目标，以 LOCF 为固定参考。预测目标继续为等权的归一化 MAE/MSE 组合。每个留一家族折中的两个损失分母从该折全部源训练 LOCF 误差确定，跨抽样比例固定；因此本阶段测量增加拟合行的影响，不是严格的总标签预算实验。

Chronos 保持整上下文选择，TimesFM 按两个独立目标选择。每次排除一个完整家族训练，并在该家族原有较晚验证起点上评分；另外单独记录其余源家族较晚起点的误差，用于区分时间迁移与家族迁移表现。训练未来与验证上下文必须保持原有 192 步隔离。当前待评分的 MAE、MSE 和联合损失在决策输入中显式移除，动作确定后才接回评分。

全量训练先运行 30 个折，并与已完成的 R4 `sequence_response`、`target_response` 的联合目标结果核对，误差容差为 1e-9。若不能复现，则停止后续小样本比较并调查差异。全量集合在三个抽样种子下相同，模型种子也固定，因此每折只拟合一次。总共 210 次拟合，逐折保存模型、选择结果、训练起点、耗时和来源摘要，可在资源让路后恢复。

主要对照为从同一拟合子集选择的固定候选，以及现有同任务预测中位数。分别保留每个抽样种子的结果和家族配对变化，不把不同种子或掩码当作额外独立家族。源家族验证在留一家族折之间会重复，因此仅作描述性诊断。若增加到 100% 仍没有改善趋势，不能以“训练不够”为理由扩大现有方案；若呈现趋势，也只能支持后续数据扩展试验，不能保证继续扩展会超过强基线。

执行使用一个低优先级 CPU 核，不启动新的预测器或读取独立确认结果。仍遵守第三优先级及既有资源让路规则。

2026-09-12 已完成 210 次拟合。全量结果与 R4 原分析的最大差不超过 1.11e-16，210 个模型及选择产物摘要、90 组嵌套抽样均通过复核。最终读数与图表位于 `selector-learning-readout-v002`；修正了早期灰度图残留的颜色，以及源验证折被错误命名为家族的字段。数值不变，原产物保留。

每折平均拟合历史数为 41.1、78.4、154.0。TimesFM 在未见家族上的 MAE/MSE 从 0.831538/1.850374 降至 0.811915/1.752461，再至 0.805590/1.685421；25% 到全量后，按三种抽样结果平均，11/15 家族两项指标同时改善。Chronos 对应为 0.842621/1.819581、0.850086/1.878398、0.851371/1.878259，没有相同改善趋势。两模型均未超过同池预测中位数。

源家族较晚时段的 TimesFM 结果在 50% 到全量时略有退化，不能把未见家族的平均曲线外推为必然持续收益。当前只支持考虑一次有界的 TimesFM 数据扩展检查，不支持以训练量不足解释全部方法问题。现有序列时间网格还能给出 183 个新增起点的元数据上界，见 `source-expansion-readiness-v001.json`；其真实观测完整性和原文件身份尚未重新审查。
