# R31：原前缀内的预测损失校准

2026年9月16日，R30全部核验后登记。R30普通peer ridge在自然H24上为0.430634/0.312650，AR桥接反而更差；模拟H24中peer/AR的填补误差远低于local ridge，下游预测却较差。停止固定AR修正。新假设是：同样局部/跨站回归候选，以过去真实未来的预测损失训练输入组合，能否超过填补损失监督及强固定组合。

R5输入组合、R10预测目标等旧路线已经做过，不把它们说成从未尝试。本轮改变为新peer信息、持续缺测H24任务、系统内历史校准、低成本局部/跨站关系候选。算法组合与小网络本身不构成新颖性保证，须以匹配对照和后续独立确认判断。

全部新学习只用R30原训练前缀内部。前半前缀（原时间轴前10%，每站3506小时）用于拟合回归、统计/神经填补器和peer相关性选择；后半（至原前20%，7012小时）用于校准。每站在前半结束后至少192小时、未来24小时结束不超过7012的24小时网格上，选择8个等距合格历史；要求两目标最近54小时原观测完整，未来每目标至少12个原观测。固定模拟6、24、54小时两PM通道不可用，共96历史/288任务；同历史多掩码共享未来，不算独立样本。

校准peer名单仅由前半前缀决定，不能复用看过后半标签的选择。校准输入/损失按前半前缀尺度表示。部署使用已冻结的R30全前缀模型、peer名单和尺度，符合基础模型先交叉拟合产生校准预测、再用全训练前缀拟合部署候选的安排。两阶段差异显式保留；不读取评价未来用于训练或模型选择。

主要输入专家为local_ridge和peer_ridge，均只填原两个目标缺口，其他列保持原观测/NaN。可训练权重按目标生成，对该目标全部缺失位置共享，原观测严格保持。输入在原前缀标准化float32空间一致地构造，alpha=0/1必须重放相应专家；观测位置显式回写原值，避免混合算术改变观测。

共享门控为10维可观测特征→8维GELU→1维Sigmoid，共97参数。特征为缺测年龄/192、目标观测比例、同目标peer在当前缺口的观测比例、局部/peer回归在已观测目标上的反事实双PM隐藏残差MAE、两修复值在当前缺口的平均绝对差、最后已观测目标z值、最后局部/peer修复z值、当前缺口的原辅助观测比例。残差特征禁止将两个PM真值作为预测特征；只用当前已到达的观测评价，不读真实未来。特征均值/标准差只由校准训练任务拟合，极小标准差置1，标准化后裁到[-5,5]。

forecast_gate为预设主模型，通过冻结Chronos的可微路径最小化校准真实未来的平滑MAE；imputation_gate具有相同结构、初始化、任务顺序和更新数，只最小化人工隐藏的原观测历史单元平滑MAE。二者部署均先组合修复历史、再调用一次冻结预测器，避免把输入/输出动作空间差异混作监督目标贡献。基础权重不更新。

另有两目标各一个全局alpha的fixed_input模型，以同样真实未来损失训练；固定0.5输入/输出组合；以及使用同一校准预测库拟合的全局/逐站固定MAE凸预测组合。固定预测库包含R30的25个基础输出（排除12个已有凸组合/单候选别名），前半前缀拟合候选仅用于生成校准库。部署固定组合使用对应R30全前缀输出，所有权重仅从校准数据学习。不同调用成本单独报告。

门控与固定输入均为单种子5101、固定3轮、每任务一步、AdamW学习率0.01/权重衰减0.001、梯度范数上限1。初始化输出alpha=0.5，使用末轮模型，不按评价分数选择检查点。每步loss为每目标原可观测位置平均再对两目标平均，sqrt(e²+1e-6)。真实未来训练损失须先清除未观测标签的NaN，再加掩码，避免无效梯度。固定MAE凸组合通过单纯形线性规划求解，不放宽原数值要求。

评价只在原R30预设H24的45自然/48模拟任务上进行，原H96仍保留为R30范围限制，不假装本轮已验证跨度迁移。保留全部37旧控制，新方法原观测、peer和历史预算相同。主比较是自然H24上对peer ridge、KNN、SAITS、同信息原生、同容量imputation_gate、固定输入及校准固定预测组合；MSE完整报告。不能只胜均值/中位数就宣布方法贡献。

当前原始可微/公开接口在局部/peer 0.5输入组合上逐值一致，alpha梯度有限，骨干冻结。完整执行前还需多任务与更新后权重检查。所有新评价预测冻结后统一评分，再独立核验时间划分、原观测保护、特征、模型最后一步重放、全部预测、误差和站点聚合。

若主方法不能获得强固定方法和填补监督之外的稳定下游增量，则停止本固定训练设计，不扩张学习率、轮数、种子或特征网格。仍为同一已用来源的开发，不作新颖性、跨模型或独立确认声明。正式阶段运行时每30分钟仅紧凑检查，全部完成后再分析。用户已授权相关历史和常规研究选择自主推进，无需重复确认。
