# 成本敏感两两选择与回归对照

本阶段补充已有算法选择策略的比较，检查当前收益回归器的表现是否与其学习方式有关。SATzilla 的相关研究已使用候选算法间的成本差加权二分类，并以两两投票决定候选，因此该机制不作为 FAIS 新颖性。[Xu 等，SAT 2012，第 2 节](https://www.cs.ubc.ca/~kevinlb/papers/2012-SAT-EvaluatingSolverContributions.pdf)

使用原 R4 缓存和联合 MAE/MSE 目标，保持六种填补加原生缺失回退的七候选池。Chronos 整上下文选择，TimesFM 按独立目标选择；源训练和留一家族验证与原分析一致。当前未来误差在决策输入中显式移除，选择后才接回计分。没有新增预测器调用或独立确认结果读取。

对每一对候选 a、b，输入由各自既有可见特征拼接构成。分类版本的标签为 a 是否有更低的源训练损失，样本权重为原有家族平衡权重乘 `|loss(a)−loss(b)|`；零差值不参与该二分类拟合。误差差值权重沿用经典成本敏感选择方式，树模型采用当前环境的梯度提升实现，并非复现 SATzilla 的完整森林与调度流程。

匹配回归版本使用完全相同的两两特征、模型数量和基础树参数，直接回归 `loss(a)−loss(b)`，以预测差的符号投票。两版本均使用 160 棵树、15 个叶节点、步长 0.05、最小叶样本数 25、L2 正则 5、种子 5101 和单线程。每折共有 21 个比较问题，两个预测器、15 个家族、两版本共 1260 个比较问题。全部源差值相同或分类标签为单一类别时采用明确的常数结果，并记录数量。

分类概率大于 0.5 时为左候选投票，回归差值小于 0 时为左候选投票；精确相等各得半票。采用票数而非概率之和，避免不同候选对的概率幅度改变本应一致的胜负次序。平票先选该折源训练上的最优固定候选，再按候选标识排序。该平票规则与 SATzilla 原文不同，属于这里预先固定的保守选择。

投票、循环平票、成本幅度对多数标签的影响，以及分类和回归推理不读取结果标签的三个专项检查已通过。每折保存模型、候选选择、源起点、成本分母和耗时；按折恢复，保持第三优先级。线上仍需取得已有候选预测并执行两两比较，缓存复用不能被报告为零查询成本。

两个两两版本之间可比较学习目标；它们与原共享收益回归器的模型数量和特征组织不同，不能把所有差异只归因于损失函数。最终都需与源训练最优固定候选及相同预测池的预测中位数比较。该阶段是开发对照，不预设能够形成有竞争力的新方法。

2026-09-12 已完成 60 个留一家族折和 1260 个树模型，无常数比较模型。`pairwise-selection-audit-v001` 核对 11232 个保存的目标级或整段决策，逐一匹配原预测成本，验证训练家族隔离、完整覆盖、模型及结果摘要；最大重新汇总差为 2.22e-16。

成本敏感分类在 Chronos 的家族平均 MAE/MSE 为 0.806072/1.661712，在 TimesFM 为 0.775948/1.581418；均优于原共享回归器和源训练最优固定候选。匹配两两回归分别为 0.808955/1.675823、0.785057/1.632544。相对同池预测中位数，分类版本仍分别高出 0.025466/0.102955 与 0.003378/0.025860。分类相对共享回归同时改善两项指标的家族为 9/15 和 8/15，相对预测中位数为 3/15 和 6/15，不能将宏平均改善描述为所有家族均获益。

本轮补充了较强的已知选择策略，但尚未构成新方法优势。Chronos 的大部分变化也出现在匹配两两回归中，因此不能将其全部归因于成本加权。下一项只用缓存检查整段、分段和逐预测位置的共识选择，详见 `R5_HORIZON_CONSENSUS_PROTOCOL.md`。
