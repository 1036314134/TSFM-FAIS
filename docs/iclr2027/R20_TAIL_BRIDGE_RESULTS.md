# R20：末端缺失预测起点调整的开发结果

2026年9月15日18:21，准备、预测、读出和独立核验全部完成。固定动作bridge_native未通过继续条件，停止扩展探针B。R19探针A也已停止，R18保持未启动。两轮结果没有建立面向ICLR2027的方法贡献，不支持投稿就绪判断。

本轮保留原长度96的历史范围，按实际输入范围计算末端连续缺失长度g，去掉原窗口内缺失尾部，从较早起点预测96+g步并取最后96步。内部缺失与时间格点不变，不增加更早观测。Chronos仅适用于全部通道共同停报；TimesFM逐目标调整。主要真实配对面板包括11事件、5个合并来源组。MAE/MSE按原观测训练前缀均值和总体标准差标准化；按历史、序列、数据集、来源组逐层汇总，两个目标等权。误差越低越好。

相对八候选中位数，bridge_native的Chronos MAE/MSE上升28.36%/121.71%，TimesFM上升35.28%/125.12%。相同输出长度控制没有改变结论。TimesFM相对原生处理改善18.20%/48.08%，但无法据此主张对缺失处理强基线的优势。源固定组合也明显优于桥接动作。

退化主要来自新加坡组。SG_PM25_H在origin=24268、g=41事件中，Chronos桥接MAE/MSE为3.139855/13.400445，中位数为1.337645/2.668717；TimesFM分别为3.616167/14.936720和1.440841/3.184189。新加坡天气事件也没有带来补偿性的收益。Chronos在其余四个来源组的MAE略有改善，TimesFM仅油价组MAE改善，部分组存在MAE/MSE取舍。这些是预定来源分解，不能通过事后排除失败来源、缩小尾长范围或换主预测器恢复原假设。独立核验确认了该事件的输入、截取时刻和原评分观测；当前证据支持性能退化这一观察，未验证其更深层模型机制。

TimesFM另6个目标末端缺失事件单独面板的桥接MAE/MSE为0.798794/0.924657，相对中位数改善2.02%/9.27%，但原生处理为0.654324/0.676498，桥接仍退化22.08%/36.68%。全部17个自然事件汇总的桥接为0.851238/1.896317，中位数为0.671949/0.960676，桥接退化26.68%/97.39%。附加面板未形成对可用强固定方法的优势。

人工补充包含12个已用完整历史，各遮盖末端8、24、48步，三种遮盖共用同一未来。合并结果中，Chronos桥接0.716243/1.089872，相对中位数MAE上升1.84%；TimesFM桥接0.711625/1.101875，相对中位数MAE改善0.94%、MSE改善3.18%，但源MAE固定组合0.706122/1.069676和源联合固定组合0.702493/1.061394仍更好。不同尾长下排序有变化；这些结果保留为机制检查，不能将某个有利尾长提升为确认性主结论。

另保留具有额外历史信息的原生长历史1024/4096对照。其最后96步使用本次已遮盖上下文，未恢复人工隐藏的尾部真值。真实共同面板Chronos长4096为0.617047/0.862064，TimesFM长4096为1.005618/3.574483；额外历史不是统一改善保证。这些方法不与固定96步桥接混称等信息比较。

完整核验覆盖100个输入与模型配对、2623个不同有效查询、2907个逻辑范围请求、2900个窗口评分和5800个目标评分。独立误差重建最大差7.11e-15，预测参数、观测保留、训练截止、原始时间格点、输出跨度与切片均通过核验。自然事件从既有R5/R6开发窗口中固定，人工历史此前用于R19反馈，全部均为已用开发数据。事件少且相关，不提供独立确认或显著性声明，也不能推断所有末端缺失处理均无效。

完整四阶段墙钟分别为准备21.89秒、预测294.76秒、读出4.84秒、核验21.53秒，不含前置开发与小批吞吐。完整执行新生成2401个有效查询，复用小批222个，共2623个不同查询；合计46次数值重复请求、2669次适配器调用、4957次模型forward批次。完整准备记录48次MoTM上下文优化、32次传统前缀统计拟合，复用原神经填补器；5个小批输入的准备成本单独保留，不补造未测量的细分计时。

研究决策：固定起点调整动作缺乏对强固定基线的可靠优势，不扩大候选池、不训练选择器、不搜索更多g阈值。普通起点移动和跨度对齐本身也不足以支撑方法创新。A/B两条约定路线均已完成检验，应重新确定研究问题和贡献范围；下一次确认实验需要先完成未用数据认证。当前保存全部结果，停止本分支新实验，研究定位选择后再登记后续路线。
