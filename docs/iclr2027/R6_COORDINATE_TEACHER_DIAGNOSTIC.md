# 逐预测位置教师参照检查

2026-09-14，在真实未来决策类诊断后登记。区间固定凸组合与逐位置凸组合在原始缺失和人工缺失上的可达误差有差别，但真实未来理想参照不能说明这种差别可以从可部署信息学得。本项只使用已经收集的 R6 完整历史教师，检验逐位置改善是否也能在原有教师代理目标下出现。

对 R6 的 32 个完整原历史及对应 1,152 个遮盖输入，在 H96/H192、两个预测器上，将每个完整历史教师的点预测截取到该位置七候选预测的最小值与最大值之间。该点是逐位置凸组合类中最接近教师的预测。它仍使用部署时不可见的完整历史，不能作为可部署方法或学习效果。

先保存由候选预测与教师预测确定的全部输出，再读取真实未来评分。验证输出处于七候选逐位置范围内，教师 MAE/MSE 不高于七候选中位数和已计算的区间固定教师最优组合；真实未来误差则如实报告，不施加改善断言。保留两跨度、两指标和每来源结果，特别检查平均改善是否掩盖局部退化。

全部工作复用现有缓存，无新预测调用、填补拟合或选择器训练。源训练的逐位置教师数组已在 `complete-history-projection-v001` 找到，并与已有对齐数据的教师绑定一致。是否实施逐位置学习，须先看这项实际结果，不能由真实未来理想参照直接推出。
