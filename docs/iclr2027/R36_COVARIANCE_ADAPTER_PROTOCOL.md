# R36：面向预测损失的条件协方差修正

2026年9月17日，R35主方案失败后登记。其静态联合填补控制在自然H24较peer_ridge改善1.67%/1.77%，但人工面板没有同样优势。R36检验一个有区别的学习动作：对静态条件关系作小规模、正定性有界的修正，以真实历史未来的预测损失监督。它不是R35动态模型的阶数、收缩或采样网格，也不能提前视为已成立的新方法。

沿用R32原96份校准历史、6/24/54小时缺口和三种成组观测干预，共864任务。源基础统计只拟合最早3506小时，校准真实未来最迟结束7012小时。源peer及尺度取R31/R32前半前缀定义；部署使用R35已冻结的原7012小时前缀静态均值与协方差。基础静态协方差仍为0.95S+0.05diag(S)+1e-6I，不调整原收缩系数。

共享适配器有U∈R^(17×2)，共34参数。V为seed5101生成并固定的17×2正交列矩阵。令T=I+[0.5/sqrt(34)]tanh(U)V^T，C_U=T C_0 T^T。U初始化为0；由||T-I||_2≤0.5可知T可逆，C_U保持正定。三个训练目标使用相同初始化、源任务顺序、一步一任务和864次更新，AdamW lr0.01、wd0.001、梯度上限1。均使用末次模型，不按评价分数选择检查点。附加正则为1e-3||T-I||_F²，固定不搜索。

每种可见变量集合均按同一个C_U进行高斯条件均值填补，观测值在输入端保持原值。为确保零参数与冻结静态输入逐值相同，实际输入采用已冻结静态填补加上同一计算精度下m(C_U)-m(C_0)的修正；原观测位置的修正为0。该锚定只处理计算路径的一致性，不增加数据。矩阵条件计算使用float64，预测模型输入保持既有float32排列。基础模型参数冻结。

主forecast_covariance最小化源真实未来两目标的平滑MAE。imputation_covariance_targets使用人工隐藏的两个PM历史标签；imputation_covariance_all使用所有人工隐藏且原本可见的历史通道标签，先按通道内有效单元平均，再对有标签的通道等权。三者共享容量、更新预算与正则，重建控制的标签范围分别披露。所有未观察标签先清除NaN再计算加权损失。其他原生缺失不制造真值。

新增强控制half_static_var为R35静态full预测与直接VAR预测各0.5的固定输出组合。另在相同源任务上，以R32的25基础输出加源静态full、静态target和直接VAR，共28输出拟合全局与逐站、分目标的MAE最优凸组合，沿用1e-7原始/对偶检查。这些控制与适配器获得相同的历史预测监督；固定组合的多模型调用成本完整报告。

评价保留R35全部81输出，并加入三个适配器、两个源校准固定组合和一个0.5静态/VAR控制，总87方法、231任务、20097窗口/40194目标分数。主自然H24 45、人工H24辅助48、原生H96辅助138分别报告。训练监督只有H24，H96明确为跨度迁移辅助。MAE为主、MSE全量保留，评分仍使用原训练前缀标准化。

正式启动前必须检查零适配器与R35静态输入/预测的一致性、原观测保持、矩阵正定界、梯度有限性、真实未来隔离以及同容量控制。若需要数值梯度修复，必须独立证明前向与原接口相同，并另记实现变化。所有评价预测先冻结后评分，再核验前缀/标签/条件计算、最后优化器更新、全部新预测、固定组合最优性及各层聚合。

继续条件为主自然面板获得静态full、peer/KNN等旧强基线、两个同容量重建控制、直接VAR及强固定输出组合之外的稳定下游增量。只胜旧失败门控或仅有训练损失下降不算成功。若失败，停止此固定低秩协方差形式，不扩秩、界、正则、学习率、种子或轮数。若有信号，仍需相关工作核对、跨来源/预测器和未用确认。当前仅一个重复开发来源，不声称真实后验校准、普遍最优或投稿就绪。正式运行时每30分钟查一次，9月18日起不自动新增实验。
