# 单候选排序与三候选组合目标的诊断

当前学习器以各候选单独的完整历史教师误差产生配对标签，部署时输出排名前三的预测中位数。个体排序目标不直接等于组合预测的误差。本项先检查二者在已冻结开发预测中的差距，避免直接增加新的选择器结构或超参数搜索。

只读取原 1,872 个源验证掩码任务、52 个历史起点的预测缓存。对七候选的全部 35 个三元组，计算预测中位数及其与完整历史教师、实际未来的误差。Chronos 的选择必须由全部目标共享；TimesFM 可逐目标选择。比较完美单候选教师排序后的前三组合、直接最小化三元组教师误差、现有冻结学习器及七候选中位数。另给出分别读取当前未来 MAE 或 MSE 的单候选和三候选理想参照，区分学习差距与有限候选集合的限制。

完整当前历史和当前未来在部署时都不可得。上述教师选择与理想参照仅是诊断，不能当新方法成绩；不同指标的理想选择也不是同一个可部署策略。不重开自然缺失确认，不训练新选择器，不增加预测器调用。只有观察到明确的目标差距及真实下游意义后，才考虑后续方法修改。

实现为 `analyze_triple_objective_gap.py`，先通过针对联合/独立目标边界和非等价目标的检查，再运行缓存分析。新产物单独保存，保留原已确认失败的方法结果。

缓存诊断及针对性检查已完成，现有学习器成绩从保存的排名重建后与原记录一致。直接三元组教师优化在 Chronos 的 1174/1872 个任务、TimesFM 的 1326/1872 个任务中严格降低了教师 MSE。按家族等权的真实下游成绩如下：

| 诊断策略 | Chronos MAE / MSE | TimesFM MAE / MSE |
|---|---|---|
| 现有学习器，排名前三 | 0.776350 / 1.553672 | 0.760947 / 1.520308 |
| 完整历史教师下的个体最优前三 | 0.766143 / 1.514401 | 0.743840 / 1.474997 |
| 完整历史教师下的最优三元组 | 0.763035 / 1.502305 | 0.736004 / 1.454019 |
| 当前未来 MSE 最优单候选 | 0.700491 / 1.308212 | 0.675787 / 1.250714 |
| 当前未来 MSE 最优三元组 | 0.712153 / 1.350141 | 0.697719 / 1.324472 |

教师组合目标的差距有实际下游意义，但相对当前学习器与理想参照的距离较小。后一个距离同时包含不可见历史的信息差，不能全归因于学习器误差或声称增加训练即可消除。当前未来理想单候选在该面板上的均值还优于理想三元组；这两个动作集合并不互相包含，固定取三个候选不是普遍的最优规则。

这些结果支持下一步检查与实际输出一致的组合评分，以及在单候选、三候选和七候选中位数之间的可学习选择。它们没有验证这种新策略能从可见输入学得，也没有解释原自然确认失败的全部原因。后续只在源开发上修改方法，原确认保持已经使用且结论不变。
