# 同一配对分类器下的组合目标检查

43 选项的共享回归已经完成且复核一致。单位方向主版本在 Chronos 下为 MAE/MSE 0.782935/1.571836，未超过七候选中位数 0.780606/1.558757；TimesFM 为 0.771730/1.550615，只有较小改善。两者都不如原配对个体排序后三候选的开发成绩。四种菜单和直接风险回归的结果全部保留，不依据它们重新挑选主要版本。

这一比较同时改变了学习器和组合目标，不能单独否定目标对齐的作用。下一项固定 35 个三元组选项及其现有 40 维可见特征，采用已经实现的成本敏感配对分类器，比较两种标签：成员单独教师 MSE 的均值，以及三元组实际中位数预测的教师 MSE。两种标签都减去同一个七候选中位数教师成本，公共偏移不改变配对差值。只有第二种标签直接对应返回的组合预测。

两种条件均使用 595 个两两比较器、160 棵树、15 叶、学习率 0.05、最小叶样本 25、L2 系数 5、种子 5101及相同家族权重。各完成两预测器的 15 个留出家族折，合计 60 个折、至多 35,700 个非恒定/恒定比较器。检查点按折保存并压缩，第一折的实测耗时用于估计计算量，不据该折误差改配置。成本高于原七候选的 21 个比较器；不能将新旧方法全部差别归因于标签。

两条件只从同一 35 个三元组中选择一个，七候选中位数和原配对排序为外部比较。它们之间的参数量、输入、候选集合和训练历史相同，能够更直接检查组合目标的作用。成员均值标签是对照，组合中位数标签是预先指定的主要检查。始终保留联合 Chronos 的共享选择和 TimesFM 的独立目标选择，不加入新的手工特征或教师模型。

复用已经核验的选项特征和教师标签，不增加基础模型推理，不读取源真实未来用于拟合。验证选择先保存再评分；审查重放所有比较器、投票选择和下游指标。原自然确认集不重开。完成后根据两个预测器的真实 MAE/MSE 判断是否保留该方向；当前仅为待执行检查，无新方法优势或新颖性主张。
