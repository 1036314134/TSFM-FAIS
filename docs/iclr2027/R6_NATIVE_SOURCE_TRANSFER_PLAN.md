# 原始缺失历史的跨家族训练扩展

2026-09-14，在逐位置组合完成并未形成稳定优势后登记。本次只检验训练数据扩展：在同一原33维共享门控中，加入其他家族的原始缺失历史及其真实已观测未来，是否改善留出家族的预测。网络、候选预测池、三个种子及25轮训练日程保持不变，不开展新的网络或损失搜索。

原源训练仍含15个家族、165个历史、5,940个人工缺失任务。扩展池来自已使用的两个集合：旧原始缺失164历史、七家族；R6北京原始缺失192历史；R6自行车时间网格缺口2历史，共358个历史、九个既有家族。每个历史只收录一次，R6人工遮盖任务不进入扩展池。SG PM2.5与SG Weather合并为一个留出组，以避免这两份新加坡数据互作训练和评价；其余家族各自为组，因此共八组。每个模型仅使用其他组的扩展历史，当前留出组的全部序列和未来均不进入训练。原165历史所属家族也须与扩展家族不相交。

这是回顾性的跨家族开发试验。旧确认产物保持不变，不能把本次训练扩展后的交叉验证称为重新通过旧独立确认。增加样本数、领域覆盖与原始缺失类型同时发生，正面结果不能单独归因于其中一个因素。若有稳定收益，仍需新的独立确认。

跨度固定为96，目标为两个原目标，未来仍使用原观测掩码，每个目标至少48个有效位置。训练损失为每目标观测位置的标准化MSE，然后对目标等权。Chronos在两个目标之间共用七候选权重，TimesFM逐目标决定权重。损失的二次系数按该观测权重计算，未观测未来不构造伪标签。原始前缀均值、尺度、候选填补结果和预测器输出均复用已审查缓存。

每个留出组训练三种子扩展门控，以及一套使用完全相同训练样本和损失的固定凸组合。候选输入统计仅由该折训练数据计算。比较既有源真实未来监督门控、既有源真实未来固定凸组合、七候选中位数、八候选中位数、原生缺失输入及各单一填补器。预测先保存再对留出组计分，不选择种子。八组、两个预测器、三种子，共48个新门控检查点和16套固定权重；不额外训练完整扩展源模型。

源基线须先在三块原始缺失子集上复现已有标准化指标。审查核对源/扩展数量、整组排除、训练输入统计、种子、候选顺序和输出重放；独立检查带掩码的二次损失与直接残差一致，未观测未来值的任意变化不得改变训练系数或评分。主要报告九个既有家族等权MAE/MSE，同时报告八个留出组等权、各家族结果及旧七家族汇总，明确自行车只有两个历史。无显著性保证，不将相关时间窗口视为独立家族。

此试验使用已缓存预测，新增预测器调用、填补器拟合和下载均为零。经现有资源守护程序运行，单核Idle、第三优先级、180秒空闲准入；结束事件触发系统提醒，周期任务保持暂停。结果优先用于判断原训练信息的限制，不预设正面结论。
