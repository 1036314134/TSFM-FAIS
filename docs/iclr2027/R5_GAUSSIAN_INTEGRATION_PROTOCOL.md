# 条件高斯填补与预测组合开发对照

本阶段检查简化单缺失场景中的信号能否出现在既定 90 个多缺失开发任务上。它是概率填补及多次预测的对照，当前没有新方法或正确后验的主张。理论背景及局限见 `R5_VECTOR_IMPUTATION_NOTE.md`；普通高斯条件分布是已有方法。[Rasmussen 与 Williams，第 2 章](https://gaussianprocess.org/gpml/chapters/RW2.pdf)

所有上下文与评分沿用共同训练前缀单位，目标仍为两个变量、未来 96 步。每个变量独立采用均值 0、平稳方差 1、相关系数 `ρ=exp(−1/12)` 的 AR(1) 工作模型；长度尺度 12 在结果查看前固定。对真实观测精确条件化，并保持所有原始观测数值不变。全无观测变量保留该工作先验。缺失机制、跨变量相关性和尺度变化未被该模型完整描述，因此不能声称条件分布已校准或满足 MNAR 情况。

每个窗口使用由固定种子与任务标识生成的局部随机数，产生 16 对正负成对的条件样本。固定报告 8、16、32 个样本的预测均值与逐坐标中位数，并报告条件均值填补的一次预测。每组偶数样本的平均填补结果与条件均值相同，因而输入平均与输出平均的差异不会来自随机填补均值的偏移。全部设置保留，不通过本批实际未来选择长度尺度、样本数或预测模型。

AR(1) 条件均值和协方差通过缺失连续区块的三对角精度矩阵计算。实现已与独立的稠密高斯条件公式比较，覆盖内部、边缘、全缺失和单位置情形；正负成对采样及观测保持检查通过。结合已有响应曲线检查，共六项专项测试通过。

主指标仍为下游 MAE/MSE，逐家族等权。对照复用同任务、同输入单位、同模型的六种填补、原生缺失回退、候选预测均值/中位数，以及加入 MoTM 后的预测中位数。填补误差只对条件均值结果作辅助报告。模型参数保持，当前未来和人工隐藏位置真值仅在全部样本及预测组合固定后用于评分。

每个模型新增 2,970 个逻辑预测输入，包含 90 个条件均值和 2,880 个条件样本；既有对照的缓存成本另计。每个窗口保存预测、条件均值、输入摘要、随机种子及来源身份。两模型使用相同条件样本，后续可通过输入摘要核验。进程恢复时保留已完成窗口，运行时间字段只反映当前进程的已记录计算。

结果若仅超过同高斯模型的单次填补，仍不足以支持论文方法优势；还需比较原生处理和已有强预测组合。开发结果不构成独立确认，373 个确认起点继续保持未运行。该阶段沿用第三优先级和已有让路程序。

2026-09-12 完成状态：两个模型均完成 90 个任务，原有强预测组合仍更准确。32 次预测均值相对原候选预测中位数，Chronos 的 MAE/MSE 差为 +0.045983/+0.165635，TimesFM 为 +0.052058/+0.168767。`gaussian-integration-audit-v001` 核验了 90 组跨模型相同样本、原始观测、参数保持及计分，最大汇总差为 4.44e-16。所有样本数与均值/中位数版本均保留；当前不扩大该固定工作先验。
