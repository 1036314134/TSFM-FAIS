# 候选预测信息与完整历史教师监督

现有完整历史教师监督改善了预测前选择器，但该信息边界下的 Chronos 三候选结果仍低于七候选预测中位数。用户的首要目标是下游 MAE/MSE，因此需要把同一监督目标用于允许查看候选预测的选择器。该检查不以减少预测器查询为目标：全部七个合法候选的当前预测先生成，再决定选择哪个候选。

保持源训练历史、七候选池、模型及树参数不变，使用原有 21 个历史输入特征和 12 个已登记的预测响应特征。预测响应描述相对于 LOCF、六种有限填补预测中位数和历史末值的变化及预测自身变化；两项分位数字段在当前点预测导出中为零。全部响应只依赖当前候选预测和历史，不含完整当前历史或当前未来真值。不新增手工特征，不改变当前目标粒度。

两种监督分别运行：`clean_forecast_mse` 以源完整历史预测为参考，`future_mse` 以源真实未来为参考。两者均采用平方成本，比较使用相同的 33 维输入、源家族折和 21 个配对分类器。每个模型、每个监督有 15 个家族折，总计 60 个折。完整历史监督不读取源实际未来生成训练目标；它仍使用人工遮盖前的完整源历史，信息范围需明确披露。

输入范围显式登记为 `candidate_forecasts`，选择前名义上需要七个上下文预测，与七候选中位数公平比较。代码沿用已审查的选择器训练流程，原预测前分支默认保持原有边界；两个分支的输入清单、信息范围和查询数量分开记录。此时不得称为一次预测前选择，不能将缓存复用记为零部署成本。若之后对已查询候选再做三候选输出组合，实际查询预算仍为七。

主评价使用全部 1872 个开发任务的训练前缀标准化 MAE/MSE，90 任务面板只作单独诊断。与相同响应输入的真实未来 MSE 监督、原始预测前学生、单候选和预测均值/中位数比较。完整教师及其利用不可见当前历史的投影选择仅作额外信息参照。没有新的确认数据被用于选定该检查。

实现保留旧脚本入口名称以复用已有的分折、来源核验及恢复逻辑，清单中新增 `input_scope` 和 `decision_input_boundary`，实际边界以这些字段为准。旧审查的 `source_outcome_free_projection_supervision` 字段只粗略标记了投影成本审查，不能覆盖实际未来监督的分折记录；新审查明确列举使用实际源未来的目标，实际训练信息以 `source_outcome_supervision` 和目标名称共同确认。
