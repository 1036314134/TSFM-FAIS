# R3 方法开发记录

状态：开发假设与实现说明，尚未形成确认结论。

## 共享损失与信息来源

候选流程 a 对缺失历史 C 产生完成结果 I_a(C)，冻结预测器输出 p_a=f(I_a(C))。原生支持缺失输入的预测器可以额外提供直接预测动作。训练前缀确定逐目标正尺度 s_k，所有候选共享同一尺度。实际评价损失为

\[
L(p,Y)=\frac{1}{H K}\sum_{h,k}\frac{|p_{h,k}-Y_{h,k}|}{s_k}.
\]

在预先指定或训练阶段确定的参考动作 b 下，教师目标为 Δ_a=L(p_a,Y)-L(p_b,Y)。历史窗口的未来标签仅在该区间结束后用于离线训练或历史反馈。部署特征只取自观测历史、填补结果和预测响应。直接收益回归用平方损失估计条件均值，选取估计 Δ 最小的动作；非负估计保留参考动作。额外切换阈值由与训练窗口隔离的开发数据选择。

## 预测距离约束

逐元素反三角不等式给出

\[
|\Delta_a|\leq D_a,
\qquad D_a=\frac{1}{H K}\sum_{h,k}\frac{|p_{a,h,k}-p_{b,h,k}|}{s_k}.
\]

D_a 在预测阶段即可计算。当 D_a=0 时两者预测相同，Δ_a=0；否则定义 U_a=Δ_a/D_a，必有 U_a∈[-1,1]。开发对照使用平方损失拟合 U_a，并将模型输出截到 [-1,1] 后乘回 D_a。只要 D_a 被包含在条件信息中，就有 E[Δ_a|信息]=D_a E[U_a|信息]。这是目标变换的依据；有限样本估计误差及家族变化仍可能导致不良选择。

上述关系是绝对误差的基本性质，不单独主张理论创新。确认前需要检验归一化目标是否改善跨家族和跨预测器表现，并与相同输入的普通收益回归比较。试跑已经观察到依赖参考动作和模型的退化，当前不能将其写为默认有效模块。

## 公平比较与计算成本

响应特征读取全部候选预测，因此与相同候选池的均值集成、中位数集成和预测中位代表选择比较。静态选择器使用相同预测监督，仅不读取候选预测响应。重建监督对照的标签仅依赖完整开发数据中隐藏的历史值，不能据此推断没有完整历史的真实部署场景也可获得这种监督。

历史回测对照属于持续服务设置，允许使用已经到达的部分历史反馈，并明确承担生成所有候选预测的成本。离线跨家族选择、持续服务时的适配以及未见预测器迁移分别报告。经验切换阈值不提供分布外安全保证。
