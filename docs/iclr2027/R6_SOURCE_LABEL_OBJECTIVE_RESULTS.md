# 同一网络的源监督目标比较

2026-09-14。真实未来监督的 30 个家族留出折、90 个模型已完成并独立核验。两个完整源模型的 seed 5101 与 R6 前固定的控制模型逐参数完全相同。独立矩阵推断重放全部 90 个模型，33,696 个决策级评分通过，预测差异为零；相同监督下固定凸组合的直接残差最优性检查最大相对差 7.05×10⁻¹⁵。

| 源家族留出验证，家族等权 | Chronos-2 MAE / MSE | TimesFM 2.5 MAE / MSE |
|---|---:|---:|
| 组合教师监督门控 | 0.779079 / 1.543561 | 0.754242 / 1.492189 |
| 真实未来监督门控 | 0.803794 / 1.630845 | 0.766743 / 1.525696 |
| 真实未来监督固定凸组合 | 0.791536 / 1.591860 | 0.777307 / 1.561970 |
| 七候选中位数 | 0.780606 / 1.558757 | 0.772570 / 1.555558 |

真实未来监督相对教师监督的平均 MAE/MSE 变化为 Chronos +3.17%/+5.65%、TimesFM +1.66%/+2.25%。但 Chronos 的真实未来监督在 7 个家族双指标胜出、6 个家族双指标退化，余下为取舍；TimesFM 为 5 个胜出、8 个退化。因此，“教师监督平均更好”不是每个家族的排序。Exchange-rate、ETT 等来源对平均差异有较大影响，不能将这一结果直接解释为某一标签源普遍更可靠。

这项源验证支持保留教师监督作为一个有依据的条件，但与 R6 的结果共同表明其收益未稳定迁移。R6 人工缺失面板上，TimesFM 的真实未来监督为 0.600364/1.130239，优于教师监督的 0.624733/1.158096；Chronos 的平均方向则不同。实际未来监督不能据 R6 表现被事后指定为某个模型的新主方法。

这次源家族留出验证是在 R6 结果已查看后补做。网络结构、训练日程和相应完整源控制模型与此前一致，结果不是对原方法选择过程的重新描述，也不能声称它曾用于 R6 前选择主方法。证据为 `source-future-cv-v001` 与 `source-future-cv-audit-v001`。没有新增基础模型预测或填补拟合。

当前仍为 NOT READY。较合理的下一项是补齐固定模型在原始缺失数据上的覆盖：原 R5 九家族的 373 个历史、其中 164 个原始缺失历史已有经核验缓存，而新共享门控尚未在这整个集合上统一评价。这项检查应标为已用数据的回顾性扩展，不能当作新的独立确认。
