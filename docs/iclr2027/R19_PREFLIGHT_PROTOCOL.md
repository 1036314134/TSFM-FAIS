# 缺失结构匹配回放的预检查

2026年9月15日，用户授权按新的研究方向继续，正式实验期间改为每半小时检查一次。R18尺度变体保持挂起，不恢复旧优化路线。本轮先检查探针A的数据和时间支持，不计算当前未来误差，不训练新神经门控。

候选开发人口为已有R5与R6原始缺失窗口；要求两个预测目标中至少一个当前有缺失。历史和预测长度均为96，校准预算B=8。锚点按当前预测边界t向前每96步排列，满足u+96<=t、u-96不早于原填补器拟合前缀结束，且历史未来两个目标各至少48个原始观测。初步检查1024与4096两种历史可读范围，4096不超过当前两个适配器共同的声明范围；正式比较如使用更长历史，必须含相同可读范围的直接预测对照。

第一版严格条件匹配只接纳完整观测的历史上下文，使结构匹配、位置打乱和同缺失量随机掩码叠加后均能严格保持其定义，不以填补值替代历史观测。另记录仅匹配当前掩码时原缺失为其子集的支持量作为可行性描述，不据此放宽主准入规则。合格锚点优先取最近8个；不足8个的当前任务保留为支持不足并回退，不降低门槛。

核对旧数据路径迁移后的源文件校验值，重新加载原轨迹并与缓存当前上下文逐值比较；复核训练前缀均值和总体标准差。历史评分只能使用已到达的原观测位置。先清点已生成预测、已读取评分、已参与R13分组训练的窗口；尚未证明未使用的新时间块和新序列只标为待进一步审查，不假定存在独立确认集。

预检查只决定是否具有至少24个、覆盖至少4个来源家族的合格开发任务，选择规则只依据来源身份、时间和原始观测。若精确支持不足，不通过改变误差指标、填真值或缩减B追逐结果；评估探针B的固定动作筛查。正式方案、掩码构造、保守评分公式、默认策略及完整计算预算在预测前另行冻结。
