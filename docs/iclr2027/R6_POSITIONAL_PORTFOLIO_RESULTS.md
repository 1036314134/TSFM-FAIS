# 逐位置预测组合结果

2026-09-14。源训练、独立审查和迁移评价均完成。逐位置条件在主要汇总上优于同容量池化控制，但没有形成相对强静态基线的双指标稳定优势。因此保留为开发对照，暂不升级为主方法，也不继续搜索该网络的层数、宽度或修正范围。

所有数值为原训练前缀标准化后的下游 MAE/MSE。每目标只计真实未来的原始观测位置，再按窗口、序列、数据集和家族汇总。主方法平均三个预定种子的有界预测，两个目标和预测位置的对应关系均已核验。

旧原始缺失集合上，两个逐位置模型均未超过两种中位数组合。R6北京192个原始缺失历史上，逐位置结果为 Chronos 0.958161/1.950442、TimesFM 0.983326/2.046647；相应七候选中位数为0.956488/1.953139和0.978526/2.041793。这里仍没有统一优势，且R6该子集只有一个家族。

迁移评价重放82,008条种子/目标轨迹，保存后核验20,502条评分，范围违规为零，标准化评分重算差异为零。旧基线与失败记录全部保留。新增预测器调用和拟合均为零；新拟合仅发生于源训练阶段。完整数值见 `artifacts/iclr27-r6/positional-source-v001`、`positional-source-audit-v001` 和 `positional-transfer-v001`。

统计解释检查覆盖11项：家族异质性已显式报告；未由家族均值推断单窗口收益；窗口准入使结论仅适用于选定样本；未借缺失率调整识别因果影响；不涉及诊断概率的基础发生率；未以先前最差组的改善作为结论；旧失败未剔除；所有预定条件、种子及两项指标保留；本轮属于多次开发后的试验，未作为新确认；未将模型差异解释为因果属性；标签、输入与预测的时间关系按原协议保持。没有开展显著性检验，也不据此声称统计等效或普遍无效。

逐位置组合已有文献先例，详见 `R6_POSITIONAL_PORTFOLIO_POSITIONING.md`。当前结果只支持局部表示在这个固定模型类中优于池化输入的部分汇总比较，尚不能支持足以投稿的新增方法主张。论文研究目标仍未达成。
