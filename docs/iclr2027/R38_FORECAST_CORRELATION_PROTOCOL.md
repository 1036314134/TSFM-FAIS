# R38：预测相关结构与状态不确定性的组合探针

2026年9月17日，R37停止后登记。本轮不改变填补、基础模型输入编码或任何神经参数，只使用原静态full的冻结预测分位和原VAR状态模型。预设主correlation_transport检验对整段预测联合组合是否优于逐坐标0.5平均。Gaussian预测组合是已有数学工具，本轮不预设创新成立。

人口仍为R30的231任务，原17变量、训练前缀及标准化一致，主自然H24 45、人工H24辅助48、原生H96辅助138分别汇总。保留R37全部140输出，新增6个固定组合，共146方法、33726窗口/67452目标分数。MAE为主，MSE完整保留，不按面板挑选不同主组件。

对每个任务，从原VAR最终过滤状态及协方差出发递推未来。目标为原两个PM，按时间优先顺序展开为2H维向量。C_V为该向量的完整条件协方差，C_I为仅由当前状态不确定性传播得到的部分；未来过程噪声只进入C_V。均值v必须复现原linear_var_direct。A、b、Q、状态和所有稳定化规则沿用原R35，不重新拟合或调节。

基础模型中心f取原full_static查询的0.5分位。对其原分位轴排序后，以R35固定整数质量求积计算围绕f的二阶量s_F²，作为未校准的误差尺度代理。令D=diag(sqrt(s_F²/diag(C_V)))，构造C_F=D C_V D+C_I。再按trace(C_V)/trace(C_F)统一缩放C_F，使两个模型的总不确定性预算相同；trace(C_F)不超过1e-12时退回C_F=C_V。主输出为v+C_V(C_V+C_F)^(-1)(f-v)。这是等权Gaussian意见组合的点形式，不要求两个预测器的误差独立，也不表示这些工作协方差已经校准。

相关结构来自前缀统计模型，边际尺度来自基础模型分位，当前状态不确定性由原观测缺口决定。该代理未包含基础模型全部误差相关性，相关性迁移及总量匹配是待验证假设，不声称真实最优组合或误差上界。

5个机制控制分别为：忽略C_I；C_F采用diag(s_F²)+C_I而不迁移相关结构；不做trace匹配；两个模型均只保留协方差对角；保持主协方差而把f换成原分位分布均值。其余操作固定。与旧half_static_var、所有同样VAR组合、原单次分位均值组合及直接VAR比较，不能只比单独基础模型。

新组合不调用基础模型，只复用已审计的原始查询。完整预测先冻结后评分；独立核验用创新响应因子重建多时点协方差，并以另一种精度矩阵形式复算Gaussian组合，检查旧控制和全部指标。新增代数输出不要求不同求解路径逐位一致，固定rtol=1e-9、atol=1e-10；已保存输出的计分与各层聚合仍为1e-12。不为通过检查放宽规则。

若主自然面板没有超过最强固定组合和机制控制的稳定MAE增量，则停止这套固定相关结构组合，不扩大尺度、权重、秩或正则网格。若有信号，仍需额外来源/预测器和未用确认。新增官方车场数据单独采集、质量核验，保持未评分，不把已知Singapore来源组改称全新独立来源。正式工作运行期间每30分钟紧凑检查，9月18日起不新增实验。
