# R42：普通适配与缺失扰动适配的受控能力检查

2026年9月17日，在任何本轮训练或评价之前登记。R40固定可信度注意力停止，R41领先关系检查不支持继续。此次改变研究假设，检验直接更新标准低秩适配参数能否学习足够的下游预测增量，并以不增加人工缺失的同容量训练排除普通领域适配的贡献。它是能力对照，LoRA及缺失扰动本身均不预设为新增方法贡献。[LoRA原论文](https://arxiv.org/abs/2106.09685)

采用已安装Chronos-2公开实现的LoRA默认目标范围和规模：rank8、alpha16，全部self_attention的q/k/v/o投影及output_patch_embedding.output_layer。原预测器参数和数值后端不变，通过本仓库临时前向钩子增加等价低秩分支，不安装依赖或修改包源码。A按默认Linear的Kaiming均匀初始化、B为0，种子7402。零适配和移除钩子必须精确恢复原预测。外部适配器为可训练参数，不能将这轮描述为完全未适配的零样本预测。

主corruption_lora在保留原天然缺失的输入上加入预定人工扰动，控制natural_lora使用相同历史在人工扰动前的原始观测。两个模型使用完全相同的未来标签、前缀标准化、变量、初始化、顺序、样本权重、优化器和1728次单任务更新。没有第二轮、验证集择优、早停、学习率或秩搜索，固定最后一步作为评价模型。

北京来源完全复用R36已核验的864个源任务及原标签，来自96个历史锚点，原较早拟合前缀3506、所有训练未来结束不晚于7012。缺失模式和6/24/54小时年龄不变。自然控制只恢复源任务人工隐藏的原观测，真正天然缺口不恢复，使用同一原keep列集合。没有读取北京评价未来作为训练标签。

HDB仅使用最早336小时，原18个目标车场、原6个前缀peer及原均值/总体标准差。历史锚点固定192、216、240、264、288、312，L192/H24，要求原目标历史至少96个观测、未来至少12个原观测。每个合格历史生成目标、目标加前3个peer、全部7列三种末端扰动，年龄6/24/54，保留原天然缺口。完整候选池先固定；按种子7403的确定性排列循环取864项，池不足时明确记录重复，超过时取排列前864项，不根据损失筛选。HDB的前缀统计和peer在全部336小时拟合，属于同一可用训练集的预处理，不能声称源锚点上的严格前序适配。未来评价时刻均不早于336，不涉及评价未来。

北京864项也按7403确定性排列；训练序列交替一项北京、一项HDB，共1728项。两个来源各占一半更新预算。每项在实际可观测未来目标上按目标等权优化前缀标准化预测中位数的smooth L1，beta=0.01；评估仍使用真实MAE/MSE。原始未来NaN在进入损失之前用独立掩码隔离，避免无效标签参与梯度。AdamW学习率1e-5、weight_decay0.01、梯度范数上限1，固定批量1，冻结骨干保持eval模式，无额外dropout或学习率调度。

评价仍为R40北京231与HDB83开发任务，全部314任务、六面板、原数据与信息范围不变。只用原生192输入，调用训练后的两套适配器各一次；每项另保留相同VAR各半控制，共4个新增输出。保留北京原162和HDB原47方法，因此总42579窗口/80925目标分数。主corruption_lora不加VAR，必须与natural_lora、原生/长历史以及全部旧强控制比较。普通适配胜出不能事后改为原缺失扰动主方法成功。
