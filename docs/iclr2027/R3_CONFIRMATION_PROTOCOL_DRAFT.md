状态：草案，尚未冻结，尚未生成新确认家族的预测结果。日期：2026-09-10。

## 主要问题

检验在相同候选集合、历史训练信息和预测查询预算下，部署时可获得的预测响应是否有助于选择填补流程，并降低相对于预先定义基准的预测损失。平均预测损失和严重退化同时报告。主要检验的具体方法及对照在开发实验结束后登记，不根据确认结果修改。

初始开发实现使用 L1 收益回归。它估计的条件中位数与平均 MASE 目标存在区别，因此开发阶段同时比较平方损失训练的收益均值估计。基准也分别比较训练集选出的固定填补器、预先指定的 LOCF 和模型支持时的原生缺失输入。所有这些比较均为开发分析；尚未选定最终方法。

## 信息边界

候选填补器只使用目标数据的历史训练前缀进行拟合。预测器保持冻结。用于选择器拟合和切换规则校准的监督任务必须与确认任务隔离。

新家族确认时，不允许把该家族的预测未来标签用于选择器拟合、参考动作选择或切换阈值调整。目标家族的训练前缀用于填补器拟合，属于需要明确声明的适配信息，不能描述为整个系统完全没有目标数据适配。

历史反馈对照只允许使用在当前决策前已经结束的预测区间，并仅从该缺失轨迹原本可观测的单元计算反馈误差。当前未来真值只能用于最终评价。历史窗口的预测范围与主任务一致，避免用缩短预测跨度的代理任务冒充同一预测目标。

## 指标与对照

训练和评价共享逐变量训练前缀 MASE 尺度及实际季节滞后。报告常量前缀及接近零的尺度数量。主指标按数据集再按家族等权；配对比较以家族为统计单位，补充窗口聚类的敏感性分析。

必要对照包括预先指定的简单处理、训练阶段选定的固定处理、原生缺失处理、相同预测监督的静态特征选择器、重建监督选择器、预算匹配的预测均值与中位数集成、预测中位代表选择，以及观测历史回测。包含不同历史反馈信息的设置须分别标明。

直接传入缺失输入的动作需要逐模型解释：Chronos-2 保留缺失观测信息；当前 TimesFM 官方接口先去除开头 NaN 并做线性插值。两种默认流程均应纳入确认候选池或明确报告为单独对照，不能将当前仓库适配器默认拒绝 NaN 当作模型库不支持此类输入的证据。

各填补流程包含统一的数值失败回退，并报告原始有效率、回退次数和完整流程的评价结果。不能因为一个外部方法失败而隐藏其余可执行对照，也不能在结果产生后改变可用率门槛。

## 成本与证据约束

候选填补、预测响应查询、历史探测及最终预测复用均计入成本。批量调用次数与实际预测上下文数分别记录。clean 和 oracle 只作为诊断；额外的 clean 调用从部署方法成本中单独列出，不能把缓存后的耗时当成在线成本。

切换阈值目前只基于开发数据选择，尚无分布外安全保证。未见预测器迁移需要使用冻结的选择器和阈值，且应处理不同预测器的候选动作可用性。当前按模型分别训练的开发选择器不构成该迁移证据。
