# 随候选分歧缩放的有界预测修正

2026年9月15日，R17迁移与观测分布诊断后登记。该试验检验固定量纲修正在较窄候选范围上易被截到边界的假设，保持原七候选、原165训练/52验证、两个掩码种子、49/16维输入、609参数、25轮、三种子及优化预算，不增加模拟源或改变真实未来联合MAE/MSE目标。

记逐位置候选中位数为m、最小/最大值为l/u，原网络输出z。新预测为clip(m+s*tanh(z),l,u)。尺度s取单位1、全候选范围u-l、候选绝对偏差的中位数median_j|p_j-m|三种，分别命名unit、range、mad；不加可调倍率。主mad_local，两种输入模式local/pooled与三尺度交叉、两个预测器、三种子，共36个模型。原R17无tanh的固定量纲模型及此前全部37输出作为已冻结参照保留。单位尺度帮助区分tanh的影响，range与mad比较对极端候选的敏感性。

尺度完全来自当前可见候选预测，不使用真实未来或不可见完整历史。mad尺度为零时输出严格为中位数且对修正头的梯度为零。给定相同z时，该输出映射在正比例缩放和平移候选后相应变换；这仅是解码映射的性质，不能声称整个网络具有同样不变性。限制修正范围不保证降低真实MAE/MSE，MAD也不是已校准的不确定度。

三尺度使用相同源输入、规范化统计、初始化、批次次序和优化器。所有条件只使用真实未来联合目标sqrt(error^2+0.001^2)与MSE各半。新模型沿用原PositionalPortfolio的可学习层，仅在输出映射增加已知尺度和tanh。pooled使学习到的z沿时间共享，而显式尺度仍可随预测位置变化；它不等同于常数偏移或固定组合权重。各尺度下local和pooled使用同一显式尺度，因此其比较只改变网络的局部输入。

验证沿用原11880训练目标轨迹、3744验证轨迹/预测器。36新模型各保留三种子及平均输出，共24新输出，连同原R17的37种冻结输出共61种、456768行目标评分。原模型结果直接复用，并核对预测索引与校验值；不重训旧模型。三种子平均仍采用中位数中心的偏移平均并clip，目标顺序不变。所有验证未来在拟合数组中不可用，预测冻结后评分。

核验覆盖源身份、参数量、初始化、归一化、随机训练顺序、零尺度梯度、单个极端候选、有界输出、固定z时的正尺度/平移关系、独立网络重放及全部旧预测/新评分。训练和独立审查两个正式阶段上限3/1小时，第一优先级单核管理，运行中只每小时检查一次。完成后立即做原R6双跨度及旧真实缺失短迁移，保留八候选中位数等强基线。当前目标数据已多轮使用，不视为新独立确认。
