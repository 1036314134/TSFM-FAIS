# Small shared forecast gate: matched source-development experiment

The 595-comparator selector has low in-sample teacher regret (Chronos 0.0106; TimesFM 0.0152), while later histories in the same source families already have regret 0.1030/0.1109. Held-family regret is 0.1132/0.1177. These measurements motivate testing a smaller shared learner; they do not prove that parameter count alone caused the gap. The existing 373-window and 823-task evaluations have been inspected and remain used data.

The question is whether directly training a small gate for the returned forecast mixture generalizes better than training the identical gate on weighted individual-candidate errors. Both conditions use the same original 33 visible features per candidate, seven queried forecasts, source training histories, family weights and random seeds. A shared 33-to-16 ReLU encoder produces candidate representations. Their mean is concatenated with each candidate representation; a 32-to-16-to-1 score network and seven action biases produce simplex weights. There are 1,096 trainable parameters. Weight averaging over three fixed seeds, 5101/5102/5103, defines the primary prediction for each condition. No seed is selected using validation performance.

The ensemble condition minimizes the teacher MSE of the weighted forecast that is actually returned. The matched member condition minimizes the weighted mean of the seven individual teacher MSE values. The difference is the usual weighted forecast-dispersion term, so this is an established ensemble identity rather than a new theorem. Both objectives omit the same reference-teacher error, which is constant with respect to the weights. Exact quadratic coefficients are recovered from the existing forecast Gram matrices and audited single-candidate relative teacher risks; no current future labels or new forecasting calls are needed for fitting.

Each family-held-out fit uses only the original training split of the remaining families. Feature means and scales are fitted on those training rows using the same family weights; scales have a floor of 1e-6, and standardized features are clipped to [-10,10]. Fix 25 epochs, batch size 128, AdamW learning rate 0.001, weight decay 0.001, and gradient norm limit 1.0. There is no validation-based stopping or parameter search. Each condition has 30 folds and three seeds, giving 180 small fits in total. Runs use one low-priority CPU core through the existing priority guard.

Strong controls include the seven-candidate mean and median, a source-fixed convex combination solved by the existing checked simplex optimizer, and the source-fixed teacher-best single candidate. The previous 35-triple selector and original individual-teacher top-three rule are compared from their audited development results. The shared gate uses convex forecast mixtures rather than a three-candidate median, so differences from older models confound representation, learner and decision class. Only the two matched gate conditions isolate the training objective under the same new architecture.

Save all three seed models and their validation weights before loading actual validation futures for scoring. Report both training-prefix-standardized downstream MAE/MSE, each seed and the prespecified average-weight output, complete family results and source-fixed controls. A favorable training objective alone is insufficient. If this bounded test does not improve the relevant strong controls under both metrics across the two forecasters, do not expand its hyperparameter search by default. Any subsequent independent confirmation requires unused data and a fresh method freeze.
