# 43 选项共享评分的开发结果

准备、两组各 30 折拟合和复核已全部完成。复核重放 60 个模型、11232 个验证决策及 1007748 行派生教师标签，实际预测指标差异为零，教师风险重构最大差异为 1.71e-13。标签行来自原训练/验证历史的多个选项，不代表新增独立历史。主版本事先固定为单位方向评分及完整 43 选项菜单。

| 方法 | Chronos-2 MAE / MSE | TimesFM 2.5 MAE / MSE |
|---|---|---|
| 七候选中位数 | 0.780606 / 1.558757 | 0.772570 / 1.555558 |
| 原配对个体排序后三候选 | 0.776350 / 1.553672 | 0.760947 / 1.520308 |
| 单位方向评分，43 选项 | 0.782935 / 1.571836 | 0.771730 / 1.550615 |
| 直接风险评分，43 选项 | 0.792070 / 1.614396 | 0.773154 / 1.547557 |

新主版本没有跨两预测器的共同改善，两个预测器上也都没有超过原配对三候选版本。它并非始终选择参考：Chronos 在 1872 个决策中选择七候选参考 542 次，TimesFM 在 3744 个逐目标决策中选择 1114 次。选择次数是行为分析，不是效果优势。

其余三种推理菜单全部保留。限制为三元组时，单位方向版本在 TimesFM 为 0.768590/1.542630，仍未超过原配对三候选；不能在看到这些结果后把该菜单重新称为本轮预定主要版本。直接风险版本在 TimesFM 上存在 MAE/MSE 取舍，不能仅引用其中改善的指标。

因此，不把该共享回归版本送入新的独立确认。它同时改变了原学习器、输入表示和动作范围，结果不足以单独否定组合目标。下一项依据 `R5_MATCHED_PORTFOLIO_OBJECTIVES.md` 使用同一配对分类器、同一三元组特征和同一候选池比较成员误差均值与真实组合误差，控制上述差异。当前没有新的主要方法优势，原自然确认失败的结论保持不变。
