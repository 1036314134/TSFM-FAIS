# 真实缺失训练分布的同预算比较

2026年9月15日，在R12同池迁移核验后登记。本轮沿用R12八候选、原决策单位、97维输入、2,121参数、联合MAE/MSE目标与三个种子。保留原165个源训练历史的2,970个单种子遮盖输入，原52个源验证历史不进入拟合。

真实缺失池固定为旧七家族164个缺失历史、R6北京192个原始缺失历史和Bike两个时间网格缺口，共358历史、九家族。SG PM2.5与SG Weather合为Singapore组，其余各一组，共八组。当前评价组的全部家族与历史均不进入拟合、归一化或固定组合求解。源家族与真实缺失家族必须互斥，不按误差删除窗口。所有数据已用，仅作为回顾性分组开发验证。

每组比较real_augmented（原源历史加其他真实缺失组）和source_steps_matched（仅原源历史）。两者更新次数均为当前real_augmented样本数在128批量下的25轮更新数；学习率与权重衰减0.001、梯度上限1、种子5101/5102/5103，网络与候选相同。两个预测器、八组、两程序、三种子共96新模型，主real_augmented。另拟合同样混合训练人口的固定联合损失组合与单候选，完整保留R12源模型、源固定控制和同八候选均值/中位数等10个旧方法。

真实未来只在原观测位置计算训练损失；每目标按其观测数归一化，再等权平均两个目标。未知未来不填补为训练标签。联合损失仍为MSE与sqrt(e²+0.001²)各半。源历史完全观测时，保留原R12数值计算路径；两个完整源seed5101在原25轮更新数下须重放R12模型参数与训练历史。原始源索引重排仅为拼接，不改变训练顺序或样本，须通过映射检查。

组间训练需要读取其他组的未来标签，因此不宣称全部原始缺失标签从未读取；必须证明当前组标签不参与其模型训练。全部组的预测先保存，再开始组内评分，不按评分调整程序。保留九家族等权和八排除组等权两种汇总，以及旧七家族/北京/Bike子集。预计20方法、21,480目标决策评分。源模型参照直接复用已审查预测，避免改变其推断批次；原三个子面板的误差以1e-12数值精度复现。

准备、训练和独立审查分别设1/3/1小时上限，第一优先级、单核，无新预测器或填补调用。独立核对人口和组排除、原观测掩码、特征/预测/归一化、同更新预算、原模型重放、固定最优性及评分。正式实验期间每小时检查一次，短诊断立即处理。新旧真实数据均已参与开发，任何收益仍须另行独立确认；数据扩展及常见网络本身不构成新颖性。
