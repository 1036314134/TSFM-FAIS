## 主要人工缺失结果

以下为 H=96、四个来源家族的宏平均，下游 MAE/MSE 均按各序列训练前缀观测均值和总体标准差标准化。共有 32 个完整原始历史和 1,152 个遮盖输入；遮盖条件不能作为独立历史计数。

| 方法 | Chronos-2 MAE / MSE | TimesFM 2.5 MAE / MSE |
|---|---:|---:|
| 冻结主方法：组合教师目标 | 0.608321 / 1.110985 | 0.624733 / 1.158096 |
| 匹配控制：成员教师目标 | 0.593649 / 1.134564 | 0.605122 / 1.132753 |
| 匹配控制：源真实未来监督 | 0.616020 / 1.147136 | 0.600364 / 1.130239 |
| 源固定凸组合 | 0.600751 / 1.109923 | 0.616414 / 1.148950 |
| 七候选预测中位数 | 0.614601 / 1.180633 | 0.619774 / 1.215528 |
| 八候选预测中位数，含 MoTM | 0.605507 / 1.139357 | 0.611607 / 1.171881 |

主方法相对七候选中位数的 MAE/MSE 变化分别为 Chronos −1.02%/−5.90%、TimesFM +0.80%/−4.72%。相对八候选中位数，两模型均呈 MAE 退化、MSE 改善；相对源固定凸组合，两模型两个指标均略退化。不能仅选择七候选中位数或仅展示 MSE 作为主方法优势证据。MoTM 扩展的候选数量与查询成本应单独说明。

成员目标在 Chronos 上比主方法有更低 MAE、更高 MSE，在 TimesFM 上两个指标均更好。主方法相对成员目标在 TimesFM 的四个家族中没有双指标胜出，三个家族双指标退化。源真实未来监督控制在 TimesFM 上也优于主方法；Chronos 的主方法宏平均较好，但仅一个家族双指标胜出、三个家族双指标退化，说明平均收益集中。上述控制不能在查看结果后被悄然改名为原定主方法。

四家族是有目的选择的来源。基于它们重新加权得到的中央 95% 范围只描述当前来源组合的敏感性，不构成总体置信区间或显著性证据。逐家族结果、两种跨度和全部 22 个主方法比较均保存在读出文件中。

## 原始缺失结果

北京数据的原始缺失子集包含 192 个历史，12 个站点属于同一来源家族。H=96 下主方法 Chronos 为 0.955657/1.950378，七候选中位数为 0.956488/1.953139，源固定凸组合为 0.954660/1.946952。TimesFM 主方法为 0.982291/2.050711，中位数为 0.978526/2.041793，源固定凸组合为 0.979966/2.043733。这里没有支持稳定原始缺失收益的证据。

同一北京面板另有 128 个完整历史。在完整输入上，各填补候选保持观测值，组合方法的结果相同。因此主报告须同时保留原始缺失子集及完整输入控制，不能用完整输入稀释缺失条件下的差别。Bike 与 Occupancy 的未知时间格点另列面板，不将其解释为已知的传感器故障。

## 后续研究范围

当前候选预测仍允许比较“是否存在更好的固定组合”和“这样的组合能否从过去信息学得”两个不同问题。先执行 `R6_LOCAL_CALIBRATION_DIAGNOSTIC.md` 的缓存检查：真实未来拟合的每序列固定权重只能作为不可部署参照，前缀完整窗口清点仅证明可用性。根据实际结果决定是否开展一个固定设置的目标前缀校准试验。

R6 的误差现已查看，此后对该集合的任何方法改动与评价均属于开发性复用。原 R5 两次确认失败和 R6 的有限收益均保留；新增方法若要形成可信的优越性主张，需要另外的未用数据确认。当前主稿尚未整合 R6 方法与结果，现有 PDF 不能代表这次实验。论文就绪仍取决于方法或经验结论的实质新意、足够的独立证据及完整可复现稿件，不能用较多实验次数替代这些要求。
