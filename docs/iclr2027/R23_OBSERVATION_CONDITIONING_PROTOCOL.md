# R23：用当前可观测历史校正预测先验

2026年9月15日登记。R21固定来源标记干预已停止，R22经典过去偏差校正未形成对强固定控制的稳定优势。本轮的问题是：当前窗口已经到达的真实观测，能否通过一个明确的预测误差相关结构，修正较早起点给出的未来预测？本轮是固定机制筛查，尚未证明方法新颖性或投稿贡献。

完全复用R21按来源固定的23个开发历史、8来源组及两个冻结预测器。评价起点为t，主跨度96。先用[t-192,t-96)的原始历史，让同一预测器从t-96预测192步，输出前96步对应当前历史、后96步对应真正未来。当前[t-96,t)中原可观测目标用于条件更新，缺失值不作为观测，不使用t及之后的实际值。原时间格点保留。无额外历史标签训练、无新填补器、无新的模型参数拟合。

较早历史使用已验证的原生处理与整通道缺失时前缀LOCF回退；前缀统计截止须不晚于t-192。Chronos较早预测联合使用原有全部变量；条件更新对两个目标分别执行，当前其他变量不参与该更新。对照直接预测可使用完整192步的全部变量，因此不会减少其可用信息。TimesFM按目标独立处理。

设预测先验的192步点输出为mu，当前观测目标的标准化值为x_O。固定相关核R_ij=0.5+0.5 exp(-|i-j|/96)。主unit_conditioner使用K=R，并输出mu_F+K_FO(K_OO+0.1I)^(-1)(x_O-mu_O)。这是带正则的高斯条件更新形式，当前并不假设真实预测误差已经满足该高斯模型。无观测时保持原先验，原始观测数值不被改写。

预定的概率尺度辅助对照spread_conditioner使用K_ij=s_i s_j R_ij，s_i=max(0.05,(q_0.9-q_0.1)/(2 Phi^(-1)(0.9)))。三个输出分位数先按值排序，仅用于尺度，不更改原点输出mu。其正则为0.1 diag(s_O^2)，两种条件更新均加1e-8I作数值稳定项。所有单位均是训练前缀标准差单位；系数96、0.5、0.1和0.05预先固定，不按本轮误差搜索。辅助条件方差只用于代数核验，不宣称具有覆盖率或不退化保证。

必须保留不作更新的prior_slice、当前最后一个观测的残差平移last_innovation、当前全部原观测残差的平均平移mean_innovation，以检验复杂条件更新是否超出简单最新反馈。直接原生192步历史分别请求H96以及H192取前96，后者匹配先验请求跨度，避免把输出请求长度差异计入条件更新收益。另复用R21普通八候选单方法、均值、中位数、源MAE单候选/固定组合及源联合固定组合13个固定基线。共20个方法、46个模型与历史配对、920个窗口评分。

新基础模型逻辑输入范围请求为23×3（Chronos联合）+23×2×3（TimesFM独立）=207，数值重放另计。全部输入、两种原生对照和预测先验先冻结；之后在只读当前历史观测的步骤冻结全部20种预测，最后才读真正未来计分。主unit_conditioner必须与native192、budget_native192、median8及简单innovation控制比较；spread_conditioner为辅助，不事后改为主方法。MAE为主、MSE完整保留，按序列、数据集、来源组逐层等权汇总，新加坡合并。

所有任务仍是已用开发数据。新发现的单变量来源暂不用于试错或效果筛选；CPHL与Water Quality的测量/站点关联尚未核清，停车场仍归入已知新加坡来源组。独立确认前须冻结方法并完成使用范围及来源关联认证。

高斯条件更新和预测偏差校正都是既有工具。ELF已研究冻结预测器的在线适配；近期研究也已有冻结时序预测器的Kalman校正与更新稳健性分析，分别见https://proceedings.mlr.press/v267/lee25ag.html 和https://arxiv.org/abs/2608.30502 。本轮区别在于使用一次较早预测覆盖的当前部分观测来修正同次预测的未来部分；该区别本身尚不足以证明创新，后续需要严查相近方法与实质增量。

若不能稳定超过同信息直接预测及简单最新反馈，停止该固定条件更新，不扩大核长度或正则网格。若出现信号，再研究可从源任务学习且能迁移的误差相关结构，并补充完整相关工作。正式预测、读出、独立核验运行中每30分钟仅检查一次状态；短诊断与准备立即处理。
