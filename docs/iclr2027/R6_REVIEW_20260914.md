# R6 工作稿的内部研究审查

审查于2026-09-14下午更新，结合 `tsfm_fais_r6_draft.tex`、后续实验报告及已查看的 `manuscript-render-v002`。当前源稿新增的两条相关工作引用和三组源训练对照尚未完成新渲染，下面的版面结论仅对应v002。研究判断仍为 NOT READY。这个判断针对研究贡献与证据强度，不把任何内部评分当作外部审稿意见。

**CRITICAL：贡献尚未充分成立。** 当前主线有清楚的预测任务、匹配目标对照和真实的迁移失败，但小型门控、历史预测组合、完整历史教师以及成员/组合误差分解都分别有既有依据。源开发改善在 R6 未稳定复现，局部前缀校准和真实历史标签控制也没有双预测器统一优势。现有稿件能够准确报告这些比较，尚未证明它们形成了足够重要的新方法或可推广的新经验结论。不能通过换标题、只展示 MSE 或突出某个模型解决该问题。

新增几何输入和逐位置修正均未解决上述问题。逐位置条件在R6人工缺失上的TimesFM MSE低于强静态控制，但MAE没有同步改善；旧七家族原始缺失上两项指标均不及中位数组合。Hasson等的既有研究已包含位置相关的组合权重，因而新增输出自由度也不足以单独构成方法贡献。完整结果和文献阅读范围分别见 `R6_POSITIONAL_PORTFOLIO_RESULTS.md` 与 `R6_POSITIONAL_PORTFOLIO_POSITIONING.md`。

恢复既有区间字段的96模型源端对照也已完成审查：Chronos的MAE约改善0.27%、MSE约退化0.18%，TimesFM的MSE约改善0.38%、MAE约退化0.02%，仍为小幅取舍。该结果不支持现在就投入原始缺失全量概率重算，也不证明概率信息一般无效。更丰富的本地模型表示是下一项接口检查的对象，尚无准确度证据，不能将代码可读取张量当作新方法有效性。

**MAJOR：诊断已有进展，尚未形成充分解释。** 128个完整历史教师预测及相应理想组合已经完成。主门控对源固定控制的教师MSE改善，在H96转化为真实MSE退化；样本交叉项核验解释了这些有限样本数值的反转，但不能单独识别教师的因果偏差。教师理想组合的来源差异也表明，缩小教师损失不保证每个来源的真实预测改善。源真实未来监督的90模型家族留出验证同样完成，其平均表现逊于教师监督，而R6 TimesFM上的排序不同。相关结果分别见 `R6_TEACHER_TRANSFER_RESULTS.md` 与 `R6_SOURCE_LABEL_OBJECTIVE_RESULTS.md`，不需要重复收集同一教师或重做相同目标比较。

原训练来源的限制已通过一次有界对照检验：八组留出的48模型训练扩展加入其他组的原始缺失历史，并保留相同样本下的固定凸组合。独立审查已通过。九家族汇总中，Chronos对原源门控小幅改善，TimesFM略有退化；旧七家族子集上两模型均未超过八候选中位数。详见 `R6_NATIVE_SOURCE_TRANSFER_RESULTS.md`。这限制了“只增加这些原始缺失历史即可解决迁移”的解释，仍不能分别识别样本量、领域或缺失类型的因果作用，也不能说明数据扩展普遍无效。

**MAJOR：结论覆盖仍有限。** R6人工缺失只有32个原始历史、四个有目的选取的来源，其原始NA来自一个家族。后续已补齐旧七家族164个原始缺失历史的共享门控评价，但这些数据已用，不能增加新的独立确认数量。多个掩码和跨度也不能补足独立来源数量。训练预算研究虽包含TiRex，但只有三个数据集和12个历史。方法路线需要有实际意义的改进及修订后的新独立确认；经验研究路线需要跨来源、跨预测器支持的重要结论及可用于决策的条件。累积多个失效变体本身不能代替这些证据。

**写作与技术说明。** 新稿明确了 33 维可见表示、每种子 1,096 参数、三个种子合计 3,288 参数、预测输出组合、标准化与原始未来观测位置。主表保留强静态组合，原始缺失正文明确比较原生输入，附录保留全部 23 个冻结方法和后续历史校准控制。模型预训练排除、窗口准入、额外候选计算量和数据复用的限制均有说明。没有从有限观察推断所有窗口或所有预测器的排序。部分术语和段落仍可随最终贡献进一步精简，但当前优先事项是研究证据。
