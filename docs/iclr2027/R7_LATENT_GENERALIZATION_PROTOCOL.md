# 内部表示的时间与家族泛化诊断

2026年9月14日，在R7跨家族结果完成审查后登记。目的为核对当前表示方案在训练历史、已见家族后续历史和未见家族后续历史三个范围的误差。此为有界开发诊断，使用既有模型与预测，不增加预测器调用，不重新训练或调整模型，不改变R7主条件。

复用 latent-source-v001 的完整输入、latent-source-gates-v001 的24个完整源检查点与原30个家族留出折预测。完整源模型训练人口仍为165个历史、15家族；同家族时间验证仍为原52个未进入训练的后续历史。原家族留出结果在相同52个验证历史上报告。主比较保留point/latent与teacher/future四条件、三学习器种子、两种固定凸组合、两种固定单候选、均值和中位数。记录训练与验证历史互斥、模型和输入绑定以及固定控制最优性。

完整源模型的预测先保存，再读取验证未来计算误差。主指标沿用训练前缀标准化MAE/MSE；完整历史教师MAE/MSE仅辅助分析监督拟合程度。三个范围分别按R7源口径聚合，并保留家族与种子结果。训练误差只作拟合诊断，不能作为预测能力证据。预测使用既有独立网络重放和独立加权求和核对；家族留出结果必须精确复现已审查决策评分。

若内部表示只有训练误差改善而时间验证与家族验证均退化，则不支持直接扩大同类门控；若时间验证改善而家族验证退化，才有依据研究可迁移表示或局部校准。两类情况都不预先认定原因，也不在结果出来前启动新方法搜索。三个范围的训练人口不同，不能把它们当作只改变领域的一项因果实验。最多读取24个完整源模型并重放一次全部源输入；单核CPU执行，上限30分钟，第一优先级。运行期间不分析或持续等待，下一次小时检查在完成后读取结果。
