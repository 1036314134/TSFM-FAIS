# 源时间校准与预测偏离约束试验

2026年9月14日，在R7泛化诊断完成后登记。原内部表示增加训练拟合但未提高后续时间准确度，故本轮检查通过源训练内部的独立历史选择训练强度，能否减少过拟合。使用已采集的3,906输入，不增加填补器拟合或预测器调用。既有52个外层验证历史已在开发阶段使用，不能称本轮为独立确认。

每个预测器仍有15个家族留出折及一个完整源拟合。外层训练仅使用原165训练历史中允许的家族。每个数据集与序列内，若至少有4个训练历史，将时间最晚的ceil(n/4)个历史划为内层校准，其余为内层拟合；不足4个的组仅进入拟合。按原始origin_id分组，全部缺失机制、缺失率和目标一起划分。删除未来区间与首个校准未来重叠的内层拟合历史，即要求拟合origin+96不超过首个校准origin。记录被排除历史，不把掩码数量算成独立历史数量。所有源归一化统计仅由当前拟合行确定。

沿用97维、隐藏16、每种子2,120参数的网络，点特征条件将额外64维设零；表示条件保留。训练目标均为真实训练未来MSE，加lambda乘当前预测与同拟合人口最优固定凸组合预测之间的MSE。lambda预定为0或1，轮数候选仅1、5、10、25，学习率、权重衰减、批量、梯度上限与R7相同，种子5101、5102、5103。约束作用于返回的预测，不以填补误差代替预测目标。两种lambda具有相同初始化与训练人口。

在内层校准历史上，先平均三种子预测，再按原源家族等权口径计算MAE/MSE。固定凸组合为校准参照。仅当候选两项误差均严格小于参照时允许入选；在合格候选中最小化两项相对参照误差比值的均值。没有合格候选则选固定组合。数值相同优先较大lambda、较少轮数。该规则只是内层选择规则，不提供目标集误差保证。输出point_calibrated与latent_calibrated，并保留只允许lambda=0的point_early_stop与latent_early_stop，区分轮数选择和偏离约束的影响。新试验主条件预定point_calibrated；不能按单个预测器更换主条件。每个选择完成后按选定轮数和lambda在全部外层允许训练历史重新拟合三种子，重复配置只拟合一次；固定回退直接使用全部外层训练历史的固定组合。

384个内层25轮拟合是最大固定预算，另有至多384个选定配置外层拟合，因配置复用或固定回退可减少。保留全部内层候选评分和选定理由。实际未来标签仅在源训练范围内用于拟合、固定组合和内层校准。30个外层验证折的全部预测保存并形成冻结记录后才读取其真实未来评分。R7的22个方法作为同预测缓存上的原基线全部保留；另加四种新程序的三种子与平均预测，最多38种方法。

独立检查须重建时间划分和未来区间分离、拟合统计、内层快照、校准评分与选择、外层配置与模型、预测组合和真实MAE/MSE；原基线评分必须精确复现。低层测试比较Gram形式的偏离损失及梯度与直接预测空间计算，核对原历史整体划分、时间区间排除和双指标选择规则。实验按第一优先级、单核运行，训练上限4小时、审查上限1小时。运行期间停止研究分析，只每小时做一次完成检查；完成或失败后立即分析处理。若新程序不能在预定双预测器和强基线比较中形成可信收益，不因内层择优、代码审查或局部改善而宣称投稿就绪。
