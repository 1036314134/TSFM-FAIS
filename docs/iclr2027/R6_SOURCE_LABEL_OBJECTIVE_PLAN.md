# 同一共享网络的源监督目标验证

2026-09-14，在完整教师诊断和原始历史权重对照读出后登记。当前 teacher/member 两种小网络已有源家族留出比较；真实未来监督的小网络已使用完整源训练集拟合，并在 R6 作为事先声明的控制评价，但尚缺同一结构的源家族留出结果。早期配对分类器的教师/真实未来比较不能替代这个匹配控制。

只补齐真实未来监督、原家族权重下的 30 个源家族留出折，每折三个原种子，共 90 个小网络。保持 33 维特征、七候选、架构、特征标准化、25 轮、batch 128、AdamW、梯度裁剪和三种子平均规则。训练标签仅由相应折的原训练历史真实未来构造，不从验证未来生成拟合标签。原家族权重教师门控的源预测与指标直接作为已审查对照，不重新调参。

先用两个预测器各一个完整源拟合、种子 5101，验证新入口与 `source-future-control-v001` 的相应状态张量完全相等。随后执行留出折，保存模型和验证预测后再计分，独立重放权重、预测、时间/家族隔离及 MAE/MSE。R6 上对应的完整源模型和结果已经存在，无需新拟合或新预测，也不能把它们重新称为未用测试。

源评价仍按原家族等权的标准化下游 MAE/MSE 口径。完整报告两目标、各来源和三个种子的固定平均，不做教师/真实标签混合比例搜索。若真实未来监督仅在某些条件改善，就按条件报告；不得用已有 R6 分数事后指定每个模型采用哪种监督目标。任何新的方法选择规则仍需新的独立确认。

同步保留由同一源真实未来损失拟合的固定凸组合，作为相同监督信息下的静态控制。它使用同一候选池和家族权重，不增加基础预测调用；不将动态门控与固定权重比较时的差别归因于监督标签不同。

这是一项必要的匹配基线补充，不把直接监督或目标选择本身声明为创新。所有计算复用现有缓存，不新增基础预测调用或填补拟合，继续单核 Idle 与第三优先级。当前只有本协议，训练/审查脚本和队列项尚未实现、未启动。
