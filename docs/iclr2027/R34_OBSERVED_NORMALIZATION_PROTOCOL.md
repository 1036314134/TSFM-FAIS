# R34：原观测统计与填补有效性分离

2026年9月17日，R33停止后登记。R21曾只修改块编码器标记并保持归一化统计不变；R34检验另一固定干预：填补数值送入冻结预测器，内部当前窗口的中心和尺度只按原观测位置计算。它是接口机制探针，不宣称简单统计量或掩码操作本身构成新颖方法。

本地Chronos 2.2.2的_prepare_patched_context先由InstanceNorm计算统计，再把时间、标准化数值和有效掩码编码成块；输出用同一统计恢复尺度。InstanceNorm采用float32的nanmean及总体标准差，可选arcsinh，零尺度回退到模型eps。R34在单次调用中临时向该模块提供指定loc_scale，不改安装包、模型参数或输入数值。输入块掩码仍由实际传入值的NaN定义；人工填补的位置保持可用，注意力及时间编码沿用原路径。钩子退出后必须移除。

对各通道原观测掩码O，按原调用的float32输入计算mu_O和sigma_O。当原观测少于2个，或观测标准差不超过该模型eps时，该通道保持原完整输入统计。主条件同时采用观测中心与尺度。没有填补变化的通道应保持原统计，所有原观测数值在输入端逐值保持。输出也使用本次选定统计逆变换。arcsinh开关、数值类型及其逆变换完全沿用原模块。

主要评价的标准化口径仍为原训练前缀均值和总体标准差；以上干预只涉及冻结模型内部的当前窗口归一化，两者不得混淆。原观测统计不等于未知完整历史的真实统计，存在选择性缺失偏差，不能宣称其无偏或预设其必然提高预测。

人口沿用R30的231任务：自然H24主面板45、人工H24辅助48、原生H96辅助138，保持原17通道、peer、L192、原20%训练前缀和全部37旧输出。复用原冻结查询的逐值输入，统计掩码由已遮蔽历史构造，禁止利用人工隐藏真值或真实未来。对原两组7个填补候选及4个统计修复分别应用观测统计，得到18个单查询输出；两组各与不变的native_peer组成8候选均值/中位数，再增加4个输出。预设主方法observed_norm_peer_ridge，不根据本轮效果更换主填补器。

针对相同peer_ridge输入额外固定三个机制控制：location_norm_peer_ridge仅更换中心；scale_norm_peer_ridge仅更换尺度；shifted_norm_peer_ridge只把两个目标的统计掩码循环移动37步，保留掩码数量，其他通道掩码不动。错位控制只检验位置的作用，正确位置优于错误位置仍不等于优于原方法。不扩展移动步数或混合系数。原37输出加22个观测归一化输出和3个机制控制，共62方法、14322窗口/28644目标分数。

普通raw模型预测和干预后的完整分位输出均需保存，主评分仍取0.5分位。每个任务最后重放一次不带钩子的peer_ridge，必须与R30冻结原始查询逐值一致；该验证调用另计，不混入部署成本。各单方法部署仍为一次预测调用，组合方法计对应候选调用数。没有新增训练或源标签选择。

专项检查覆盖统计掩码对填补值的不变性、低支持/零方差回退、全部观测时的恒等路径、arcsinh与逆变换、钩子移除。小批覆盖三面板、两跨度及较多缺失历史，且不评分新误差。正式全部预测冻结后评分。独立核验以float64原观测计算非退化参考统计，对新增float32观测统计固定rtol=2e-6、atol=1e-6；未改动及回退到原路径的统计与原模块逐值比较，避免把常量序列在float32求和中的舍入残差误作方法改变。按保存统计通过独立常数接口重放模型，完整分位、全部方法输出须逐值相等。检查输入块数值、时间、有效掩码及注意力，误差/汇总采用原1e-12容差，参数摘要必须不变。

主自然面板须获得普通peer_ridge、KNN、SAITS、同干预其他填补器以及三个机制控制之外的稳定下游MAE增量，MSE全量保留；不能只胜错位控制或旧失败方法。若无强基线增量，停止该固定归一化干预，不扩展统计窗、回退阈值、位置或学习选择器。若有信号，仍需跨来源/预测器、独立确认和相关工作核对才能确定论文贡献。正式运行期间每30分钟仅紧凑查状态，完成后分析，9月18日起不自动新增实验。
