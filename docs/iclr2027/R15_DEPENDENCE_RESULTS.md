# 固定期望风险后的相关性干预结果

R15读出于2026年9月15日10:34完成。原审查在一个MAE并列选择上遇到浮点求和顺序差异；按照R15_AUDIT_REPLAY_NOTE.md修正数组切片后，dependence-audit-v002完整核验3240个决策条件，原结果未修改，原核验阈值未放宽。1080组原决策的候选期望MAE/MSE与条件最优权重跨rho逐值一致，rho=1与R14乘子1的共享数值字段差为零。稠密协方差与反向递推投影方差的最大差为1.20e-14，风险重建差为5.11e-15，凸组合最优性残差为8.16e-10，均通过登记阈值。

在八候选、三个过程及四个缺失条件等权的汇总中，Chronos单候选配对事后MSE偏差随rho=0/0.5/1分别为0.002465、0.020309、0.038799，TimesFM为0.005310、0.033505、0.059736。对应MAE偏差分别为Chronos 0.001680、0.009303、0.017977，TimesFM 0.003249、0.014899、0.027112。所有候选的期望风险未变，单候选可获取MSE收益始终为Chronos 0.009988、TimesFM 0.015869。

凸组合配对事后MSE偏差亦随rho变化：Chronos为0.005627、0.029460、0.050821，TimesFM为0.008945、0.042552、0.071564。相对均值组合的条件可获取MSE收益保持Chronos 0.215022、TimesFM 0.285388。完整观测条件下各候选预测相同，三种事后偏差均为零。逐过程结果保留在process_panels.csv；周期过程的绝对偏差远小于两个非周期过程，不能将汇总量外推为普遍比例。

候选与条件MSE最佳候选的平均两两排序反转概率，在Chronos由0.030002升至0.121654，TimesFM由0.061163升至0.160136；该均值包含最佳候选自身的零反转项。样本反转率与高斯投影公式的最大标准化差为4.33，样本投影方差的最大标准化差为3.82，均低于预定10阈值。其作用是核验抽样与推导，不能作为独立历史的显著性检验。

本结果说明，在指定已知条件未来分布中，仅改变相关结构即可改变事后选优差距，而实际可部署固定点预测的期望MAE/MSE保持不变。36个历史及其预测复用R14，rho干预后的未来不要求是原AR过程的平稳延续。本轮既不估计真实数据的不可学习比例，也未产生真实预测精度提升。一般[虚拟最优偏差](https://www.cs.ubc.ca/~kevinlb/papers/2016-IJCAI-VBS.pdf)已有先例；高斯投影和协方差计算不是独立创新。

可检验的后续方法假设是用条件期望风险生成选择器训练监督，减少一次未来观测产生的随机差异。该假设须与相同历史、预测、模型和更新预算的一次未来监督比较，并回到真实数据MAE/MSE验证。R13真实缺失训练未形成稳定优势，当前论文目标仍未达到，不能仅凭评价性质改变投稿结论。
