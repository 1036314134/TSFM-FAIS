# 逐位置组合与已有工作的关系

2026-09-14。本文献记录界定当前逐位置组合试验的贡献范围，不将尚未审查的实验结果作为方法有效性的证据。

Hasson 等的 ICML 2023 论文已研究组合权重是否应在序列、预测位置和分位数之间共享。其第6节使用历史回测窗口学习权重，并通过正则项控制共享程度；第6.1节明确说明前文的表格数据定理不能直接用于该时序设置。因此，允许权重随预测位置变化、比较共享与不共享组合，以及一般的组合学习保证，都不能单独构成本工作的新增贡献。[论文第6节](https://proceedings.mlr.press/v202/hasson23a/hasson23a.pdf)

Cerqueira 与 Torgo 的《Multi-output Ensembles for Multi-step Forecasting》摘要报告了3,568条序列和30个多输出模型的比较：动态方法的平均排序较好，但随着跨度增加，多数方法难以超过等权静态组合。这里仅核对了摘要，未据此推断完整实验设置。当前试验须保留简单静态组合及两个跨度，不能以一个动态方法优于单一填补器来替代强基线比较。[原始摘要](https://arxiv.org/abs/2306.14563)

SwiftTS 的公开预印本第3节将任务定义为预测预训练模型微调后的可迁移性，第4节使用数据与模型编码器以及跨数据集、跨跨度的元学习。该任务选择的是预训练模型；当前任务固定预测器，改变缺失历史的处理方式及候选预测的组合，且当前逐位置方法需要先取得全部候选输出。两者的信息和计算预算不同，不能将 SwiftTS 的候选前向节省主张直接用于本方法。已读材料为 arXiv v1 的摘要和第1至4节开头；OpenReview 完整页面被浏览器验证拦截，不声称已经核对其最终会议版本。[SwiftTS 预印本](https://arxiv.org/html/2510.23051v1)

当前实现的可检验差异是：同一冻结预测器对多种填补历史产生候选轨迹，源端完整历史教师提供监督，部署端仅使用缺失历史摘要和可见候选轨迹；网络从逐位置中位数出发，在候选最小值与最大值之间预测修正。该范围约束只限制输出，不保证真实未来误差优于中位数。局部条件与同容量时间池化条件的比较检验局部输入的作用，不能单独识别模型架构、教师质量或分布变化的因果影响。

研究判断必须同时检查下游 MAE/MSE、两个预测器、各来源、原始缺失与人工缺失，以及较长跨度。所有当前迁移集合已被查看，正面结果只能支持继续开展新的独立确认。若该固定试验未改善相应控制和强静态基线，则不以增加网络规模或挑选种子替代贡献证据。
