# R35 执行核验口径

正式启动前，7项数学测试通过，覆盖小系统稠密高斯条件均值/协方差、条件采样因子、正负配对、原观测恢复、滤波时间方向、前缀支持、协方差拒绝及整数分位质量。8个历史的小批已生成307个新查询，并通过全部预测与组合输出的逐值重放；独立末12步高斯条件均值/协方差最大差7.99e-15，未读取小批评价误差。

核验中的逐步状态均值/协方差及独立稠密后验采用rtol=1e-9、atol=1e-10，前缀回归的增广最小二乘对照沿用rtol=1e-8、atol=1e-10。PSD分解的负特征值容限、正负配对的1e-12、预测逐值重放及指标1e-12维持原登记规则。首次小批核验曾因临时转置矩阵与生产过程的连续存储矩阵采用不同浮点归约次序而出现4.44e-16差异；核验按生产存储顺序重算后逐值一致，没有修改预测、模型或容差，原核验源码及修复记录保留。
