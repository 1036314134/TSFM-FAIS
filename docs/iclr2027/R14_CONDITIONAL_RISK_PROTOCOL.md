# 已知条件未来分布的受控诊断

2026年9月15日，在R13读出和先例核对后登记。本轮为明确标记的模拟诊断，不是新的真实数据验证，不预设能提升预测准确度。使用三个预先固定的稳定线性高斯过程：独立AR三变量、耦合AR三变量、带48步周期的耦合AR七变量。参数保存在conditional_future.py；每个过程有独立的6,144步校准序列，以及12个独立初始化的96步测试历史，测试历史与校准序列独立。共36个不同历史。

每个历史使用完整观测、30%/60%随机点缺失、30%/60%末端整块缺失五种观测条件，共180输入。掩码独立于数值。保留八候选：LOCF、线性、季节、KNN、SAITS、TimeMixer++、MoTM及原生回退。两个神经填补器仅在各自独立校准序列上使用10轮/64窗口的固定预算，共六个拟合；任何拟合失败均停止，不以失败替换扩大候选差异。MoTM使用原固定公开网络与上下文内设置；所有预测器冻结。校准序列的均值和总体标准差作为报告量纲。

精确条件分布仅使用实际观测历史、掩码、已知过程参数和已知日历相位。向量Kalman更新与逐标量条件更新须一致，并通过小规模稠密高斯条件公式独立验证。完整历史末态被观测时后验协方差为零。当前未来的均值由后验均值传播，方差分解成缺失历史后验不确定性与未来创新两项。

候选填补与Chronos/TimesFM预测每个观测输入只生成一次。固定这些输入和预测之后，未来创新标准差乘子取0、0.5、1、2；噪声变化不能改变任何候选预测。每个观测条件用固定种子产生512个条件未来样本，各噪声乘子复用标准正态随机数，保留时间和变量相关性。模型未见真实未来；后验末态和未来创新均按条件分布抽样，不把一个隐藏完整末态当作已经观测。

分别计算七、八候选池的精确期望MAE/MSE、最佳条件单候选、最佳条件MSE凸组合、均值/中位数，以及事后单候选与MSE凸组合在同一未来上的误差。MAE期望用高斯绝对误差公式，MSE期望为均值偏差平方加条件方差。MSE条件最优权重不依赖未来噪声乘子；事后选择可依赖抽到的未来，因此不得作为部署方法。额外计算事后选择在独立同分布未来上的精确期望风险，以识别其泛化代价。

主要诊断为单候选和凸组合的配对事后乐观差：在同一未来上，以条件最优策略的误差减去事后最优误差。单候选还报告各有限面板最佳固定算法、条件最优与事后最优的差距分解；面板固定算法也使用已知期望风险，仅为分析参照。明确区分可获取收益、未来选优偏差和已知过程参数带来的理想信息。缺失与未来噪声造成的Bayes噪声下界分别保留，不能把这种过程已知的分析值当作真实数据估计。

凸组合求解复用同一预测几何的面分解，并以原独立单纯形求解器检查；失败样本可回到原求解器，最终最优性阈值保持1e-7。保存条件风险、抽样选择及所有种子，均值和方差抽样核对使用轨迹级标准误差。完整观测的八候选预测必须相同，事后差距应为零；零创新且末态完全观测时未来样本应完全一致。

单候选损失的Monte Carlo均值与解析期望核对采用每条完整未来轨迹作为抽样单位，标准误差分母下限1e-10，最大标准化偏差超过10则停止核验。该条件只检查抽样实现，不据此选择或排除有利结果。单候选事后MSE差还须逐样本复现“未来创新在候选预测差方向上的投影减去期望风险间隔”的恒等式；它是误差展开，不单独作为新理论。均值组合与条件MSE最优凸组合的期望差作为固定权重凸组合可改进空间的参照。

准备/冻结预测/风险读出/独立审查均为正式阶段，第一优先级、单核管理，上限2/2/3/2小时。运行期间只按小时检查，不分析。阶段结束后再判断该诊断是否提供超出既有结论的证据。多个掩码、噪声水平和未来复制不增加36个独立历史的数量，不使用它们虚增统计样本。
