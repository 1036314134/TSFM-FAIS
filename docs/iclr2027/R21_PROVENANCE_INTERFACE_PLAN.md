# R21：区分填补内容与原观测标记的接口检查

2026年9月15日，用户在A/B均停止后明确选择保持方法论文定位并重定研究问题。本轮重新检查预测器如何接收填补内容，A/B和R18保持停止。

研究问题：在填补数值、历史范围、归一化、注意力可用位置及冻结预测参数均相同的条件下，向输入编码器保留原始缺失标记，能否改善真实未来预测？这是关于输入来源信息的可证伪假设，尚不是已验证方法，也不等同于已校准的填补置信度。

本地Chronos-2先归一化数值，再将时间、数值和有效标记拼接到输入块编码器。其普通context_mask=0还会把对应数值归零，并可能关闭整块注意力，因此直接传原掩码不能隔离来源标记的作用。TimesFM 2.5的公开缺失处理先插值，输入块编码器拼接数值与填充标记；该标记另用于归一化、置零和注意力。两者的二值位语义不同，不能称为统一的原生置信度接口。

最小干预只修改块编码器接收的标记特征，数值特征与其归一化、时间编码、注意力和输出恢复均沿用普通完整填补路径。Chronos将标记特征改为原observed位；TimesFM改为原missing位。TimesFM的注意力及统计仍沿用原实际填充位置，仅在编码器入口改特征。该干预是明确的内部接口改写，不是调用公开掩码参数，也不是模型参数更新。修改只在本次调用的临时钩子内生效，必须通过参数摘要、逐值输入审计及解除钩子后的原路径重放。

先做不评分的小批接口检查：两个模型、少量已用上下文，核验透传与原预测逐值相同、完整历史标记干预为恒等、真实观测数值与其他输入块字段完全不变，Chronos仅修改历史编码调用而非未来编码调用；TimesFM处理正负两次调用及补齐批次，不能误改虚拟样本。记录标记确实改变的坐标、实际批次和接口版本。

接口通过后才登记开发精度筛查。拟在既有自然目标缺失窗口中按来源等额、序列轮流及时间顺序选择最多24个历史，每来源最多3个，不能依据误差选取。固定原八候选池，复用原前缀拟合和填补缓存，主比较为保留来源标记的八候选预测中位数对原八候选中位数。同时包括相同标记数量的固定位置移位控制、源最佳单候选、固定组合、原生处理及所有单候选。MAE主指标，MSE完整报告，完全使用已用开发数据。

标记注入可能处于原模型训练分布之外，可能减弱有用填补信息；它也可能只产生普通扰动正则化效果。若正确位置标记不能优于同数量移位标记，不能归因于来源位置。如果只胜弱单候选、不胜中位数或源固定方法，不能据此继续复杂化。只有存在可重复、来源不集中的精度信号，才设计源数据学习的适配模块并认证未用确认数据。禁止将固定标记注入本身直接宣称ICLR级创新。

相关工作边界：UP2ME已将多任务处理写为掩码重建，并有冻结编码器/解码器的适配机制（https://proceedings.mlr.press/v235/zhang24al.html）。AIM相关研究已强调原生缺失标记与额外训练遮盖的区别（https://openreview.net/pdf?id=eOATzq7NvI）；目前只检索到全文片段，尚未完成全文核验，不作具体优劣或首次性判断。TRACE研究跨模态缺失与时间不齐的条件估计，应用范围与本轮固定预测器接口不同（https://arxiv.org/abs/2606.06285）。冻结模型的残差及多视图校正已有研究（https://arxiv.org/abs/2607.17511），不作为本轮新贡献。上述边界仍须在方法成立后补全严格相关工作比较。
