# 官方车场小时快照：未评分新时段采集契约

2026年9月17日，在新时段预测或评分之前登记。数据源为新加坡HDB公开车场可用量接口；先前本地Arrow的三个前缀时点已与官方快照核对，但其完整转换仍不透明。此次另建来源可追溯的快照集合，不覆盖原Arrow或其他项目文件。[官方数据入口](https://data.gov.sg/datasets/d_ca933a644e55d34fe21f28b8052fac63/view)

固定请求2025-06-01 00:00至2025-07-26 23:00的新加坡本地整点，共1344个小时。该时段位于旧Arrow截至2025-05-31之后，仍属于已知Singapore来源组。它可以用于后续已登记的时间/序列验证，不能因此宣称新来源独立或预训练未见。

正式采集前的四点探针发现，2025-06-01 00:00接口返回空记录，而前一分钟可返回2025-05-31 23:58:36的历史快照。为统一处理日界线，所有API查询参数固定设为目标网格时点前一分钟，同时记录网格时点、实际查询参数及响应时间，仍严格拒绝晚于网格的快照。此规则在任何新时段预测之前固定；不把该代理时间等同于传感器在整点重新测量。

每个时点保存完整官方响应压缩文件、请求地址、响应快照时间及SHA。请求节奏最多每秒一次；重试遵循服务器Retry-After并保留失败记录。HTTP或解析失败是采集失败，不能直接当作真实缺失填进序列。返回晚于请求时点的快照拒绝，防止未来信息进入当前网格。

解析时以车场标识和lot_type共同定义测量，固定采用C类型。对重复C记录，取不晚于请求时刻的最新update_datetime；同一最新时间若数值冲突则标为冲突，不擅自挑选。原数值、总容量、更新时间及年龄保留。超过容量的非负数值保留并标记，不截断或按预测误差删除。

同时保留最近快照的原始as-of可用量和新鲜度掩码。后续主要候选观测要求快照与单车场更新时间均不超过当前网格之前一小时；更早数据作为过期记录保留，不能称作在当前时刻新测得。缺项、类型缺失、时间异常、冲突、过期与技术采集失败分别记录；不把所有NaN归为设备故障。

此阶段不选择预测方法、不运行基础模型、不读取预测误差，也不挑选有利车场。目标/peer人口、训练前缀、窗口、跨度及指标须在后续任何评分前另行登记。新集合不与旧类型映射不明的数据默默合并，所有原始响应及转换代码均保留供复核。
