# R22：经典校准与候选验证数据检查

2026年9月15日。过去反馈的经典常数/仿射校准诊断完成，912条评分和10种R19原控制逐值重放通过核验。控制包含原中位数、均值、三个源固定控制、两个长历史原生控制和三个历史ERM结果。无新基础模型调用，无神经训练，计算约2.03秒，独立误差重建最大差1.42e-14。

matched_affine_ridge的Chronos MAE/MSE为0.699744/1.245698，相对中位数0.702047/1.263797改善0.33%/1.43%，仍差于源MAE固定组合0.691419/1.225184和同历史范围原生预测0.601912/0.961500。TimesFM为0.690262/1.079747，相对中位数0.699046/1.138911改善1.26%/5.19%；其MAE仍略差于源MAE固定组合0.689934和源最佳单候选0.685576，且高于同历史范围长原生预测0.620571。长原生预测存在MSE取舍，完整表保留。

generic_affine_ridge为Chronos 0.704866/1.262109、TimesFM 0.696203/1.106953。常数均值和中位数残差校正没有表现出稳定优势。该诊断只说明这几种低容量过去校正不足以解决现有问题，不是ELF的正式复现，也不能否定更完整的在线适配方法。不会把经典校准的局部改善当作新论文贡献。

验证数据初筛进一步读取了CPHL_30T、ECDC_COVID_D和SG_Carpark_15T的原观测掩码，尚未生成预测或读取预测误差。CPHL两个单变量序列共有60个合格后段窗口，其中28个历史存在原生缺失；ECDC九序列15个合格窗口中没有原生历史缺失；停车场354个单变量序列共有10620个合格后段窗口，均含原生历史缺失。多个窗口与序列不能计为同数量的独立来源。

扫描3668份既有实验清单和身份记录发现一处CPHL文本，但它是已用Water Quality Darwin数据的测量列名。这还不能证明CPHL_30T已用于预测，也提示其测量/站点关联必须进一步核对。CPHL的两个条目为NRSDAR和TAN100、时间始于2022年，停车场条目始于2025年。这些日期是当前Arrow快照提供的元数据，来源链路和真实采样网格仍需验证。停车场继续归入已知新加坡来源组，不增加独立来源数。

这些是验证储备候选，尚未认证独立确认。原通用数据配置要求至少两个变量，首次单变量清点因契约检查停止；单独的只读Arrow检查路径已保留真实单目标维度，未修改旧实验契约。失败记录保留于univariate-reserve-v001，完成清单为univariate-reserve-v002。未来采用这些数据须有单目标评估契约与完整使用/来源核对，不据此更改旧结果或挑选有利测试窗口。

后续R23检验当前已到达的观测对同次较早预测的条件更新，区别于本轮从过去八个窗口估计静态校正。全部23个开发历史及主要比较提前固定，新候选数据暂不用于方法试错。
