# R45：模型默认长上下文原生基线

2026年9月17日，在新增预测之前登记。R44已显示北京人工面板的联合候选优势可由匹配的目标范围/隔离预测控制解释，不能作为候选交互的方法贡献。此次补齐Chronos-2默认可用长历史的原生控制，判断短历史比较还剩多少有效提升空间，不登记新算法或上下文长度搜索。

本地冻结权重版本29ec3766d36d6f73f0696f85560a422f50e8498c的config.json明确context_length=8192，公开预测入口未指定长度时读取模型的该值。旧R6封装规格中的96和当前实验192均不是这个骨干的默认上限。本轮固定上限8192，不比较一串自选长度。每任务实际使用[min(8192,t)]个已经到达的历史点，右端严格为t之前；HDB只来自原前672小时开发文件。

人口保持北京231、HDB83共314任务。变量集合固定为原R40保存的selected列，不新增peer或改变选择规则；同时给原目标列单独输入的控制。扩展历史的最后192点必须覆写为已冻结的原输入context，逐值保持所有原观测及原NaN，包括人工任务最后24小时的目标隐藏，不能从完整原数据恢复这些人工缺口。较早部分只读取同一序列在当前时刻之前的真实原观测，天然缺口保持。

四个新原生输出由两个输入单位及两个变量范围形成固定对照：原量纲长历史和原训练前缀标准化长历史，各自使用原变量集合或仅目标。原量纲对应直接提供测量值；前缀单位便于与旧输入方式比较。两种单位的预测均转换到同一原prefix均值/总体标准差坐标报告MAE/MSE，不能把输入归一化选择混同为计分口径。不同长度/单位的模型内部统计可能不同，不强行替换其默认归一化。

所有调用保持原骨干参数、原H24/H96和原0.5分位读出，无填补、适配或已知未来字段。每个任务另重放原192点原生联合查询，必须精确恢复旧native_peer/native_peer192；新标准化长历史的末192点也必须逐值等于原有效模型输入。记录实际输入长度、开始位置、行数、输出补丁、内部字段、耗时和CUDA峰值，确认没有被旧封装器隐式裁到96或192。

每个新点输出也保留与原VAR各半控制，原R44全部输出原样保留。北京238、HDB111方法，总64191窗口、119169目标分数。5次前向/任务，共1570次模型调用，独立审计重放同量。长历史增加了可用信息和计算量，不能把它与短输入方法的差距全部解释为缺失处理机制，也不宣称相同计算预算。VAR仍是旧固定控制，不因某来源效果而换权重。

启动前核对真实最大长度、完整模型调用的显存/耗时及短查询恢复。若资源或接口不支持，保留技术失败，不根据评价分数静默缩短历史。完整预测冻结后才评分。独立核验源时间边界、当前隐藏保护、变量/单位变换、补丁长度、原生掩码/时间字段、骨干参数、查询重放和全部指标；同输入预测重放精确，指标和聚合1e-12，不要求不同输入单位或长度的结果相同。

结果分六面板报告，并分别与短原生、已有HDB336、两套适配及全部强固定控制比较。若更充分的原生历史已达到或超过当前候选方案，应据此收窄贡献空间；若仍有缺口，也不能直接推断已有失败方法有效。HDB后28天未评分，未用确认和其他预测器比较仍需补齐。正式工作每30分钟检查一次，9月18日起不新增实验。
