# 固定多输出预测器的单次填补限制

## 条件风险与可达输出

固定当前已观测历史及缺失位置，令允许的补全集合为非空紧集 C，冻结连续预测器为 F:C→R^q，其中 q 为预测跨度与目标数的乘积。给定这些观测，令实际未来的条件均值为 μ，且二阶矩有限。对按输出坐标平均的 MSE，有

\[
\mathbb E[\|Y-F(c)\|^2/q\mid O]
=\mathbb E[\|Y-\mu\|^2/q\mid O]+\|F(c)-\mu\|^2/q.
\]

因此，在所有单次补全中最优的条件风险等于 Bayes 风险加上 `dist(μ,F(C))²/q`。连续性与紧性保证最小值可达。该等式适用于任意固定 F；它不要求 F 在完整数据上已准确。若另外假设 `Y=F(U)+ε`，其中 U∈C 且 `E[ε|O]=0`，则 μ=E[F(U)|O]。在这一额外假设下，对 C 上每一种条件分布都存在达到 μ 的单次补全，当且仅当 F(C) 为凸集。

证明：充分性来自紧凸集包含其上任意概率分布的均值。必要性只需要考察 C 中任意两个点上的二点分布：若所有这样的均值均属于 F(C)，则 F(C) 包含任意两点的全部线段。这里的结论是逐观测的存在性，不保证能从有限观测学得该补全，也不保证补全随观测连续。

若 C 连通，标量连续 F 的像为区间，因而满足上述条件。多输出连续 F 的像可以非凸；q>1 本身并不保证非凸，线性 F 在凸 C 上仍满足条件。仅凭输出维数大于缺失自由度或数值优化未达到零残差，不能宣称已证明某个真实模型不可达。

允许补全使用与实际未来条件独立的内部随机数，并只返回一次 F 输出，也不能降低到最优确定补全风险以下：其风险是确定补全风险的平均。若已知正确的条件分布，使用 K 个独立补全的预测均值，则其额外估计风险为 `tr Cov(F(U)|O)/(Kq)`。这描述预测平均的计算与方差关系，属于标准均值估计结论；它不证明现有候选算法构成正确后验，也不保证实际候选平均达到 Bayes 风险。

## 局部修正后仍存在的风险项

进一步固定缺失部分的 m 个自由坐标，设 F 在 u₀ 的邻域内三次连续可微，其 Jacobian J∈R^(q×m) 满列秩。令隐藏变量为 `Uσ=u₀+σZ`，其中 Z 有界、E[Z]=0、Cov(Z)=Σ。假定完整数据条件均值正好由 F 给出。记向量 c 的第 j 个分量为 `tr(HⱼΣ)`，Hⱼ 为 F 第 j 个输出在 u₀ 的 Hessian，并记 P⊥ 为 J 列空间的正交补投影。

存在足够小的固定半径 ρ，使得 σ→0 时，在 `||δ||≤ρ` 内允许任意单次补全仍有

\[
\min_{\|\delta\|\le\rho}\frac{\|F(u_0+\delta)-\mathbb E F(U_\sigma)\|^2}{q}
=\frac{\sigma^4}{4q}\|P_\perp c\|^2+O(\sigma^5).
\]

证明要点：Taylor 展开给出 `E F(Uσ)=F(u₀)+σ²c/2+O(σ³)`。满列秩及足够小的 ρ 保证 `||F(u₀+δ)−F(u₀)||≥s_min(J)||δ||/2`。选择 δ=0 已能将输出残差控制在 O(σ²)，所以最小化解必须满足 δ=O(σ²)。在这样的解上，`F(u₀+δ)=F(u₀)+Jδ+O(σ⁴)`。将 σ²c/2 投影到 J 的列空间，最优未消除分量为 `σ²P⊥c/2+O(σ³)`；平方后即得该式。上界通过取 `δ=σ²J⁺c/2` 达到，正交投影同时给出匹配的下界。

若 P⊥c≠0，该局部最优风险项对充分小的非零 σ 严格为正。与条件均值填补的普通曲率偏差相比，这里允许先把全部填充值作局部最优修正，剩余部分来自输出变化无法覆盖的方向。结论有明确限制：满列秩不能省略，域外的其他补全可能达到目标，真实预测器也未必满足光滑性或完整数据准确性。q>m 只是允许存在正交补，不能代替 P⊥c≠0。该推导是基础 Taylor 展开与投影的结果；文献独立性仍待确认。

在下述二步反例的 u₀=0 处，J=(1,0)ᵀ、c=(0,2/3)ᵀ，系数恰为 1/18。将隐藏区间缩为 [-σ,σ] 后，对 0<σ≤1，实际最优 MSE 差正好是 σ⁴/18，与展开一致。

## 同时涉及 MAE 与 MSE 的反例

令不可见的 Z 均匀分布于 [-1,1]，已观测内容固定，真实二步未来为 `Y=(Z,Z²)`，冻结预测器为 `F(a)=(a,a²)`。允许填入任意实数 a，因此结论不依赖候选池限制。指标按两个未来坐标平均，使用本例指定的单位；本例数值不是实验数据集的标准化成绩。

对任意单次填补，MSE 为

\[
R_2(a)=\frac4{15}+\frac{a^2}6+\frac{a^4}2,
\qquad \min_a R_2(a)=\frac4{15}.
\]

对于 r=|a|≤1，MAE 为

\[
R_1(a)=\frac5{12}-\frac{r^2}4+\frac{2r^3}3
=\frac{79}{192}+(r-\tfrac14)^2(\tfrac{2r}3+\tfrac1{12}).
\]

对于 r≥1，`R₁(a)=(r+r²−1/3)/2≥5/6`，故全局最小 MAE 为 79/192，达到于 a=±1/4。

预测均值 `(0,1/3)` 的 MSE 为 19/90，MAE 为 `1/4+2/(9√3)`；逐坐标预测中位数 `(0,1/4)` 的 MSE 为 103/480，MAE 为 3/8。两个输出都在两项指标上严格优于所有单次填补各自能达到的最优值。特别地，最优单次填补与 Bayes MSE 的差为 1/18；与最优 MAE 的差为 7/192。虽然每个坐标分别都有可用的填充值，两个坐标要求的填充值不同，无法由一个共同补全同时实现。

反例表明，在冻结多步预测器下，寻找更好的单个填充值有可能受到输出可达性的限制。它没有说明实际时序模型或全部数据分布均存在这种限制，也没有说明现有七种填补器的预测中位数具有后验解释。

## 预测器失配可以改变实际效果

真实基础模型通常不是完整数据条件均值。令 ν=E[F(U)|O]，实际条件均值 μ=ν+b，并记 d=dist(ν,F(C))。距离函数的三角不等式给出

\[
\max(0,d-\|b\|)\le \operatorname{dist}(\mu,F(C))\le d+\|b\|.
\]

因此，只有对模型条件偏差也有控制时，参考输出的几何距离才能约束实际未来的最优填补风险。若仍取 F(a)=(a,a²)、Z 均匀分布于 [-1,1]，但实际未来改为 Y=(Z,0)，则预测均值 ν=(0,1/3) 仍处于曲线之外，实际 Bayes 输出 μ=(0,0) 已可由填补 a=0 达到。其真实 MSE 为 1/6，而平均预测的 MSE 为 2/9，反而更高。这个情形说明，真实 MAE/MSE 检查不能被参考输出拟合残差替代；实际候选分布估计错误还会带来另一项偏差。

## 与已读工作的边界

Le Morvan 等的 NeurIPS 2021 论文在标量响应设置中研究填补与预测的关系。其第 4 节已给出条件均值填补的非零风险及曲率界，并讨论保持回归函数时修正填补的存在性与连续性。本文候选方向需要明确处理固定向量输出的逐观测可达性，普通非线性失配不能算作新发现。[原论文](https://proceedings.neurips.cc/paper/2021/file/5fe8fdc79ce292c39c5f209d734b7206-Paper.pdf)

Ipsen、Mattei 与 Frellsen 的 ICLR 2022 论文研究缺失输入下的监督深度学习，并通过重要性采样近似多次填补后的预测平均。已核验作者机构摘要及原论文索引中第 4 节的实验设置：该节预训练生成模型后固定生成部分、更新判别部分。因此“保留缺失不确定性并组合预测”已有直接先例；固定判别网络的多输出可达性需要单独比较。全文下载在两个官方入口受到浏览器验证或 403 限制，不能标记为完整通读。[作者机构页面](https://orbit.dtu.dk/en/publications/how-to-deal-with-missing-data-in-supervised-deep-learning-2/)，[原论文](https://openreview.net/pdf?id=J7b4BCtDm4)

当前评估为需要进一步证据。两个主要风险是：可达集合表述可能只是已有统计结论的直接重述；真实模型即便存在拟合残差，也可能不影响真实未来 MAE/MSE。下一项受控检查只用于判断是否值得投入，不能将离散网格残差称为全局下界或单独替代真实预测评价。

## 真实模型受控检查协议

固定每个开发家族的第一个源训练起点，共 15 个窗口。以原始完整历史构造新的单缺失实验，仅隐藏第一个目标变量在上下文末端的值；其余历史均视为已观测。输入与未来评分统一使用原有历史训练前缀的均值和总体标准差，L=H=96。扫描区间以倒数第二个目标值为中心，半径为其余 95 个已观测目标值总体标准差的两倍。该区间只定义受控情景，不宣称是条件分布置信区间。全局均匀的 401 点及嵌套 201 点均预先固定。

冻结 Chronos-2 和 TimesFM 2.5，始终预测 96 步，再分别观察前 1、12、24、96 步，避免改变模型调用跨度带来额外差异。对扫描预测的均值与逐坐标中位数，记录最近网格填补、折线最近点提出的填充值，并真实执行一次预测核验该填充值。最终拟合记录取网格与核验结果中距离参考输出更小者；全部选择不接收实际未来。折线距离和网格距离均不能作为真实连续响应的严格下界。

先记录输出拟合残差、响应方差、二者之比及网格细化变化，再独立评分源窗口实际未来的标准化 MAE/MSE。对照包括 LOCF、原生缺失处理、已知完整历史参考、情景预测均值/中位数及对应单次填补投影。完整历史使用被隐藏的真实值，只作为额外信息参考。记录 TimesFM 正值处理分支可能变化的窗口，保留观测方差近零窗口，核验中点的单例与批量公开接口输出及模型参数保持。

该检查每个模型每个窗口有 412 个逻辑输入预测请求，断点恢复后运行时间仅描述当前进程的已记录工作。每个窗口独立保存，遇到优先任务继续让路。只有当长跨度残差相对响应变化足够大、细化网格后仍存在，且真实未来误差有研究价值时，才讨论扩大研究；该阶段不用于选择或解封独立确认方法。

## 已完成检查的解释

两模型的 15 个源窗口均完成。一步拟合残差相对响应方差的中位数约为 1e-10，96 步对应 Chronos 0.009307、TimesFM 0.017999；这支持在所检查曲线上存在数值上可测的多输出拟合差距，仍不构成全局不可达性证明。单缺失情景预测均值的实际误差仅在 TimesFM 上优于原生处理，Chronos 没有优势。完整数据见 `scalar-completion-curve-readout-v001`。

进一步完成既定 90 个多缺失任务的固定高斯条件填补对照，两个模型的预测组合均优于同高斯模型的单次填补，却都落后于原有候选预测中位数。输入样本和重新计分已独立复核。该结果不支持把普通高斯预测平均作为主方法，也说明可达输出的几何分析必须与工作分布偏差、预测器偏差及强对照共同讨论。理论方向仍待新颖性审查，不能由这些实验直接宣称论文贡献已成立。
