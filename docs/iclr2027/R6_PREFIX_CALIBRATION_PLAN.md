# 目标前缀教师校准：固定设置的开发试验

登记日期：2026-09-14。已有缓存检查的源固定分数重放误差不超过 1.11×10⁻¹⁶。H96 下，不可部署的每序列理想固定组合相对源固定组合将 Chronos-2 MAE/MSE 从 0.600751/1.109923 降至 0.567883/1.003422，TimesFM 从 0.616414/1.148950 降至 0.559454/1.000886。理想权重使用评价未来，不是本试验的训练目标。15 条序列中 11 条有至少两个完整前缀历史，合计可选 43 个历史。这些证据支持检验一个有限成本的可部署估计，不证明它会有效。

本试验保持源固定模型、R6 评价输入及预测缓存不变。仅使用每条目标序列原 20% 训练前缀：前缀前 60% 拟合校准用填补器，后 40% 提供长度 96、步长 96 的完整历史，每条最多等距选取四个；少于两个则直接使用源固定权重。SAITS 与 TimeMixer++ 沿用 10 轮、64 窗口、batch 16 的原预算，其他候选与原七候选池相同。训练批次、统计量、掩码校准及季节相位都明确限制在相应前缀内。

每个可用历史使用六种原有缺失机制、缺失率 0.1/0.3/0.5、固定新种子 9103，共 18 个条件。使用原冻结预测器得到完整历史教师和七个候选的 H96 点预测。标准化仍采用原 20% 前缀统计，预测器参数不更新。教师输出不需要该历史之后的真实未来，校准程序不读取评价未来或理想权重。

对每条序列，将全部历史和掩码等权的候选 Gram 矩阵与教师内积取平均，求七维单纯形上的最小教师 MSE 权重。Chronos 的两个目标共用权重；TimesFM 按目标分别求解。主输出权重固定为本地权重与原源固定权重各占一半，以限制最多四个历史所产生的估计波动；这个系数不做搜索。保留不收缩的本地权重作为预先声明的控制，以及原源固定组合、七候选中位数、含 MoTM 的八候选中位数。不得根据 R6 结果选择收缩系数、窗口数、种子或条件。

评价时直接应用到已完成的 R6 两种跨度预测缓存，不重新拟合原部署填补器。这相当于用较早拟合的填补器估计候选质量，再在使用整个前缀拟合的候选上部署；两种拟合预算的差异是本试验的限制。H192 沿用 H96 权重，不另做校准。全部面板、全部原始缺失与完整控制、两个下游指标均保留。比较还须并列原 R6 的主方法、成员目标和真实源未来监督控制。

输入审查独立核对原始轨迹、前缀边界、43 个教师历史、774 个遮盖输入、原观测值保持、8 个神经填补拟合记录和标准化统计。权重应保存后再进入评价阶段；检查教师目标的最优性、源固定重放、全部预测和原观测未来指标。43/774 是由已经核实的准入清点计算的预期覆盖，最终完成记录必须再次核实，不以完成标记单独代替覆盖审查。

R6 已用，本试验是开发性复用。该方法与历史组合权重、完整历史蒸馏均有既有工作的联系，当前不宣称这些组成部分本身新颖。若双模型双指标及逐来源结果有足够改善，再冻结方法并设计新的独立确认；若不成立，保留失败并重新评估论文的实质贡献。只启动该一个分支，仍为第三优先级、单核 Idle、资源空闲准入和进程结束通知。
