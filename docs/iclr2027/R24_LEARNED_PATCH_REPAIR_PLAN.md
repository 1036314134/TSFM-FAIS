# R24：源预测监督的缺失块表示修复

2026年9月15日，R23固定条件更新停止后登记。新的可检验假设是：在完整数值填补之后，针对含缺失位置的输入块学习低秩表示修正，能否改善冻结时序基础模型的未来预测？该方案增加新的可训练模块，基础模型原权重冻结；有效预测计算包含适配模块，不称为未修改的原预测器或纯黑箱方法。

固定基础数值输入为源开发MAE选定的seasonal_lag填补结果，保留原观测值。对输入块嵌入e和原缺失位向量m，令修正为U GELU(V LayerNorm(e)+Wm)，仅在m含缺失时加入。LayerNorm不含可训练仿射参数，低秩维度8，U零初始化。完整块保持原嵌入，完整输入保持原预测。Chronos只修正历史块，未来块不改；TimesFM正负两次历史编码均使用同一适配模块，批次补齐样本不改。位置感知版本pattern使用原m；同参数量控制fraction把每块m替换为重复的缺失比例。两者都知道含缺失的块及缺失数量，只有pattern保留块内位置。

两种版本共享初始化、训练样本、顺序、损失及优化预算。源任务固定R3的mask_seed=6101、训练时间分割与旧标准化，计算筛查只使用维度不超过64的样本，并保留排除记录；排除只由维度决定。源验证和已用自然数据不用于优化、检查点选择或早停。计划固定3轮、AdamW学习率1e-3、权重衰减1e-3、梯度范数上限1，单一种子5101。主训练损失为标准化误差的0.5 MSE + 0.5 sqrt(e^2+1e-6)，另加1e-3的表示修正相对能量约束。只优化新增模块，不对基础模型权重计算或累积梯度。

先做源训练样本上的接口与梯度诊断，验证零初始化与原预测一致、非零适配仍保持完整输入恒等、完整块/未来块/虚拟批次不变、梯度只流向新增参数，以及最大支持维度的内存和耗时。公开推断和可微推断的误差要按目标前缀标准差核对；若数值路径不同，先定位再执行正式训练，不放宽已有数值门槛。

诊断通过后冻结完整执行协议。先训练两个预测器各pattern/fraction一套，共4模型。源验证保留同口径强固定基线；已用自然开发面板沿用23历史及96/192两种上下文长度，其中192用于检验长度共享模块能否超过同信息原生预测及固定季节填补。源训练仅L96，192结果须明确为长度迁移。所有新预测在未来评分前冻结。未用储备不参加本次方法选择，单一种子的筛查不能替代最终重复和独立确认。

此方案与原输入凸组合、输出组合器及固定标记注入具有不同可训练空间，但这种差别不自动构成创新。输入/表示适配、低秩模块与冻结模型监督学习均有已有工作；相关的INPUTADAPTER已在跨医院任务中用目标标签训练冻结预测器前的输入变换（https://openreview.net/pdf/1ff6e8783004070f91d5417723b7ceed4eba5a47.pdf）。本项目必须分别检验源任务向未见来源迁移、缺失位置条件相对通用适配的增量、完整输入保持及预测精度，不能以增加参数或只胜基础填补器作为投稿贡献。
