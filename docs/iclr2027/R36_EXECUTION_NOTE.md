# R36 执行核验口径

正式启动前5项专项测试通过，覆盖零适配器、原观测与全缺失行保持、饱和修正下的正定界、独立条件均值、无标签通道损失与固定组合。另有6个源任务覆盖三种缺失干预的真实模型梯度检查：零修正输入和预测逐值相同，梯度有限，无需改动基础模型数值操作。

完整小批使用12站的36个源任务、8个评价历史。72个源静态预测、24个新增评价预测与8个零修正基线均逐值重放；三个训练目标的最后一次参数及优化器更新差0。独立NumPy条件均值与适配器输入的最大差0，小批未评分新的评价结果。正式训练仍为864任务/864次更新，不能把小批预算当作正式学习。

条件矩阵在float64中计算，独立条件输入与float32编码固定使用rtol=1e-6、atol=1e-6；适配后协方差的独立重建使用1e-12。源静态/VAR数学对照沿用既有1e-9/1e-10及增广最小二乘1e-8/1e-10检查，原始预测和优化器重放逐值相等，指标与聚合仍为1e-12。固定组合通过原1e-7的原始/对偶检查，新增组合采用按方法顺序的累加，避免矩阵存储布局改变归约顺序。

源校准新增1728次静态预测，学习中的forecast_covariance有864次可微预测，两个重建目标不调用预测模型。正式评价新增693次预测；零修正输入逐值匹配原静态查询，独立核验再实际重放零修正预测。全部成本单独记录。所有适配器部署为一次预测调用，固定组合按其所需基础输出计调用数。

三个目标共享原始历史、初始化、模型容量、任务顺序和更新数，但监督标签类型与数量不同：预测目标为两PM真实历史未来，目标重建仅两PM隐藏历史，全通道重建覆盖各干预中原本可见的隐藏通道。这一差异是登记的监督对照，不能写成逐标签数量完全匹配。真实未来训练标签始终位于原前缀内，评价未来不参与学习。
