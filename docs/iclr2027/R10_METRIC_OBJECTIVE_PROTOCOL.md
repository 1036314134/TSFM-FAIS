# 预测MAE与MSE训练目标的匹配比较

2026年9月15日，在R9源扩张与短迁移核验后登记。原始缺失迁移仍不及强中位数组合，人工缺失上的MAE/MSE有不同取舍。本轮只改变源端训练损失，检查直接考虑MAE是否改善这一状况；使用原R7的165训练历史、52验证历史、3,906输入、种子6101及全部既有缓存，不调用时序预测器，不重新拟合填补器。

每个预测器保留15家族留出折与一个完整源拟合。输入为原33点特征补64零值，97维/2,120参数网络、25轮、批量128、AdamW学习率及权重衰减0.001、梯度上限1，种子5101/5102/5103，与R7对应点特征程序一致。四新条件为mae_teacher、mae_future、joint_teacher、joint_future，共384拟合。主条件预定joint_future，其余是匹配控制。

MAE训练采用sqrt(e²+epsilon²)，epsilon固定为0.001，误差e按原训练前缀标准化。它与绝对误差之差逐点介于0和0.001；评价仍使用精确绝对误差及平方误差。joint损失为平方误差与该平滑绝对误差各半，不搜索权重。教师与实际未来标签的作用范围维持原定义；只有当前折允许的源训练未来进入拟合。MSE分量使用原二次形式，省略的项与学习参数无关。

每个折和每个新条件另求同样本、同标签、同损失的固定凸组合与固定单候选。固定凸组合以原MSE最优解初始化，在七维单纯形上用解析梯度的SLSQP求解；最大2,000步、ftol1e-13。记录可行性和归一化一阶最优性差，阈值为1e-7，超出则停止诊断，不放宽阈值。独立核验采用直接残差与梯度重算。四套单候选按相同加权损失选择。

所有外层验证预测保存并冻结后，才读取验证真实未来。原R7的22方法原样保留，新增四程序的三种子与平均预测16方法，加八个固定/单候选，共46方法、129,168决策评分。源家族等权聚合和MAE/MSE口径不变。核验模型与训练人口、目标/参数/梯度实现、初始化和训练统计、固定最优性、预测与评分重放。已用验证集仍属于开发分析，不称独立确认，不把某个目标的训练改善视为部署保证。

正式实验为训练加独立核验，第一优先级、单核执行，分别设6小时和2小时上限。运行期间只每小时检查一次；结束后立即核验结果并决定是否值得短迁移评价。平滑绝对损失、联合损失和固定组合优化本身均不作为新颖性主张。
