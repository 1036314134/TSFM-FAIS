# 逐位置信息与真实未来目标的匹配试验

2026年9月15日，在R16完整迁移读出后登记。原R6逐位置网络仅使用完整历史教师MSE，R10真实未来目标试验则使用整段共享候选权重。本轮限定检验两者的交互，保持原逐位置模型、特征和源人口，不扩大网络、候选池或优化预算。一般逐位置组合及真实损失训练已有先例，不能单独作为新贡献。

复用R6 positional-source-v001的原七候选和输入：49维全局摘要、16维局部预测位置输入、609参数。local逐位置输入与pooled时间平均后广播输入为匹配两条件，原网络、标准化、零初始化、输出clip到同位置候选最小/最大值完全保留。Chronos的联合摘要在两个目标间共用，局部输出仍按目标生成；TimesFM原本按目标生成摘要。模型输出为预测组合，不声称产生唯一填补历史。

复用原165训练历史、52验证历史及两个掩码种子6101/6102；训练5940个观测输入、每预测器11880个目标轨迹，验证1872输入、3744轨迹。不采用R16新增模拟人口，也不改变原输入的次序。原R6完整源local/pooled三种子共12个教师模型复用，另在两预测器、两输入模式下重放seed5101四个旧模型，参数、统计、初始化和训练损失数值必须逐值一致；训练历史字段可重命名为不限定教师的名称，数值不变。

新目标为mse_future和joint_future，分别最小化真实未来MSE与平滑MAE/MSE各半，平滑MAE为sqrt(error^2+0.001^2)，评价仍用真实MAE/MSE。每目标轨迹先对预测坐标平均，再用原家族权重；新目标不得使用验证未来或完整教师。两个目标与local/pooled、两个预测器、三种子5101/5102/5103交叉，共24个新完整源模型。主local_joint_future，其余均为固定对照。优化器、25轮、128批量、学习率与权重衰减0.001、梯度裁剪1、输出范围均与原R6一致。

本轮先做完整源训练与同源时间留出评价，原R6家族留出结果单独保留。保留七个单候选、预测均值/中位数、原教师模型三种子与平均输出，以及真实未来MSE和联合目标各自的同源固定凸组合和固定单候选。固定组合使用同家族权重和对应损失，最优性阈值1e-7。种子平均沿用以中位数为中心平均偏移、最后再clip的原规则。共37种输出、277056行目标级评分。

所有模型及预测冻结后再读取验证未来评分。独立核验源校验值、目标顺序、训练/验证分离、初始化、容量、标准化、四个旧模型精确重放、非均匀网络推断、输出范围、固定最优性与全部指标。完成后立即在既有R6双跨度及旧原始缺失缓存上评估，并保留八候选中位数等此前强基线。目标数据已被多轮使用，迁移为回顾性开发核验，不能称新独立确认。

训练与独立审查为两个正式阶段，上限各3小时和1小时，第一优先级单核管理，不停止或修改其他项目。运行期间每小时检查一次，未完成即静默结束；完成后短分析及迁移连续处理。若局部真实损失不能超过匹配控制和强基线，不据局部结果或更换种子宣称投稿就绪。
