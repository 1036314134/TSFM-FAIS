# 固定共享门控的原始缺失覆盖扩展

2026-09-14，在源监督目标匹配验证后登记。原 R5 九家族自然数据包含 373 个历史、18 条序列，其中 164 个历史来自七个家族且有原始缺失。其输入、两预测器候选预测、原策略和未来观测掩码已经核验。新共享门控此前主要在已用跟进集和 R6 评价，缺少对这整个早期自然集合的统一比较。该集合早已被查看，扩展仅为回顾性稳健性检查。

保持所有模型和所有评价历史不变。比较原完整源 ensemble/member 教师门控、真实未来监督门控、原始历史等权门控，以及匹配的源固定凸组合。完整源参数都来自原 165 个源训练历史；本轮不训练新门控、不生成填补结果、不调用基础预测器。额外真实未来固定组合使用上一项源验证保存的完整源权重，先核对其真实源残差最优性与候选顺序。

从已保存的六个填补候选与 guarded-native 预测，重建相同 H96 的 33 维可见特征。重新运行原冻结的教师前三选择器，并要求输出与旧缓存逐窗口匹配，以检查新特征接口在这批数据上的兼容性。源模型通过独立矩阵推断核对权重，再生成全部新方法预测，保存后才评分。

每变量的均值和总体标准差使用原 20% 训练前缀。所有方法在各目标原来可观测的未来位置计分，每目标至少 48 个观测。分别报告全部 373 历史、164 个原始缺失历史及完整历史控制，按窗口、序列、数据集、家族等权汇总。旧 raw-native 的失败记录保留，不能删掉失败窗口后形成完整平均。原 1024 步历史控制使用额外过去信息，单独说明其信息预算。

保留全部原基线，逐家族报告新门控相对中位数、固定组合及原生输入的方向。不能把九个已用家族重新称为独立新来源，也不根据本次结果修改权重或选择某个模型专属规则。原始 NA 的覆盖与 R6 的人工缺失覆盖分开解释。所有计算通过第三优先级守护队列串行执行，结束事件通知继续启用。
