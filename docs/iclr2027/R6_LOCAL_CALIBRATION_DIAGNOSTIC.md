# R6 确认后的固定组合与前缀支持检查

登记日期：2026-09-14。R6 的策略、预测及指标审查已完成，误差已经查看。主组合目标没有稳定超过源固定凸组合；本文仍不具备主方法普遍占优的证据。本检查属于确认后的解释性分析，不能形成新的独立验证结论。

第一项仅清点原训练前缀内完整历史的数量。假设将前缀前 60% 用于填补器拟合，后 40% 用于完整历史教师校准，历史长度固定为 96，起点间隔为 96，每条序列最多等距选取四个完整历史。这里不生成教师预测，不训练任何模型，也不以新未来误差决定窗口准入。可用窗口数量仅证明采样可行，不能证明校准有效。

第二项在已有人工缺失预测缓存中，为每条序列求一组固定凸组合权重。Chronos-2 的两个目标共用权重，TimesFM 2.5 按目标分别求解；两个跨度分别计算。目标直接使用本次评价的真实未来，因此该权重是不可部署的理想参照，具有使用评价结果拟合的乐观偏差。它只回答有限候选池中是否存在更好的固定组合，不回答这种权重能否从部署信息学得。

对照为原源固定凸组合，候选池、标准化、预测和评价历史完全复用 R6。优化采用已有七顶点单纯形二次规划，检查最优性残差及平均 MSE 不差于源固定可行权重；MAE 同时保留，但不声称它被该优化最小化。先按目标、掩码历史、序列、数据集、家族等权汇总。四家族是有目的选取的有限集合，多个掩码与跨度不能计为独立样本。

执行入口为 `scripts/analyze_r6_local_calibration.py`，输出到 `artifacts/iclr27-r6/local-calibration-diagnostic-v001`。不新增基础模型调用或可部署模型；通过现有资源让路队列单核执行。检查完成后再决定是否值得实现一个固定方案的前缀校准试验，不预先扩展模型或超参数搜索。
