# R10目标变化的迁移结果

短迁移评估已完成，核验246,024条决策预测及252,858条评分，预测重建最大差1.07e-14，指标重算差为零；全部R7共享参照复现，旧比较完整保留。证据目录为artifacts/iclr27-r10/metric-transfer-v001。

人工缺失H96上，主metric_joint_future的Chronos MAE/MSE为0.610105/1.121383，同损失固定组合为0.609543/1.109277，仍未改善。TimesFM为0.582252/1.065021，较同损失固定组合0.613581/1.145462的MAE/MSE分别降低约5.1%/7.0%；该收益也超过七、八候选中位数。这个正面结果只覆盖当前人工缺失面板，不能据此替换其他面板或更换预定方法。

旧七家族原始缺失上，主条件Chronos为0.612616/0.804634、TimesFM为0.618077/0.801955，均不及八候选中位数0.609386/0.797358与0.613597/0.793853。R6北京原始缺失上，主条件为0.957183/1.952382与0.980834/2.046423，也未形成统一优势。辅助metric_mae_future的TimesFM在北京原始缺失上为0.975993/2.030160，优于该面板两个中位数，但它在其他面板有取舍。全部目标、种子、家族及H192保留。

当前双预测器之间有一项明确的实现差别：Chronos门控对两个目标共用权重，TimesFM按目标分别生成权重；与此相应，前者33维特征对两个目标汇总，后者具有目标级特征。已有逐位置修正试验同时改变了输出形式、网络与监督等因素，不能替代相同容量、样本和更新次数下的目标特征对照。下一项R11在相同逐目标训练行上比较复制的联合特征与目标级特征，保留联合预测器及真实回退逻辑，并证明TimesFM输入不变。此变更不增加预测器调用，不预设真实缺失收益，也不将一般的逐目标组合称为新颖性。
