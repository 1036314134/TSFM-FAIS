# 源历史权重的匹配对照

2026-09-14，在完整历史教师诊断后登记。当前七候选教师理想组合在四来源宏平均上仍有明显空间，但主门控相对源固定组合的教师 MSE 改善没有转化成真实 MSE 改善。原训练中五个最小家族只有 12/165 个历史，却在家族等权目标中占三分之一权重。这是可核验的权重集中现象，尚不是失败原因的证明。

只改变共享门控训练损失的样本权重：原条件为家族等权，新条件为原始历史等权。各原始历史具有相同遮盖次数，每个预测器内部目标决策次数也一致，因此新条件在决策行上使用单位权重。特征均值与标准差继续使用原家族权重，完全匹配旧条件；不把输入标准化变化混入损失权重比较。教师、33 维特征、七候选池、结构、25 轮、batch 128、AdamW 参数、梯度上限、三个种子及其平均方式全部保持原设置。

仅研究原 ensemble 教师目标，不启动多种权重插值或超参数网格。先在两个预测器各一个真实家族留出折、种子 5101 上，用新训练入口恢复原家族权重，要求所有状态张量与原已保存模型逐项完全相等，证明入口没有引入其他训练变化。随后完成 30 个家族留出折、每折三种子共 90 个新模型，再使用原 165 个训练历史拟合 6 个完整源模型。全部拟合只用原源训练数据。

对照同时包括旧家族等权共享门控、旧家族等权固定凸组合以及新原始历史等权固定凸组合。后者用相同教师二次目标和单位权重求解，检验收益是否只需改变固定组合。所有验证数据仍按家族等权报告 MAE/MSE，不因训练权重变化而改变评价口径。源模型保存后，才在已用 R6 两跨度预测缓存上做诊断，不新增基础预测调用或填补拟合。

检查训练/验证及家族隔离、特征标准化相等、独立矩阵权重重放、每个来源完整覆盖、预测和两个下游指标。记录每个家族实际训练损失权重及梯度裁剪比例，以便解释结果。R6 结果仍是开发性复用；若新门控没有稳定超过相应静态控制，不默认继续扩展权重搜索，也不将其包装为已获独立优势的方法。继续第三优先级、单核 Idle 和进程结束通知。
