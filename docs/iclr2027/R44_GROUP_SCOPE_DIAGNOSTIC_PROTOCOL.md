# R44：候选交互与预测变量范围的匹配诊断

2026年9月17日，在新增查询之前登记。R43主raw_plus_pool在两个自然面板均失败，停止决定不变。北京人工面板的proxy_pool_only_median为0.538310/0.640069，较原half_var_local_ridge改善16.94%/24.28%，但它同时改变了直接输入预测器的变量和候选之间的信息共享。此次补齐匹配控制，用于解释该辅助现象，不把控制改名为R43主方法成功，也不登记新的方法优越性主张。

完全沿用R43全部314任务、原12/6候选、192历史、原标准化及源信息，不改候选数量、顺序、数值、权重或模型参数。所有新诊断均在六面板报告。HDB后672小时继续未评分；当前两来源属于重复开发，不能称独立确认。

每项使用四个固定查询。第一，将原候选目标轨迹按候选、目标排列，每候选内部的目标行共享group_id，不同候选的组号不同，隔离候选间的信息共享；第二，相同矩阵全部使用同一组号，复现R43的仅候选联合查询；第三，仅输入原始目标行，保留NaN；第四，原始目标行追加相同候选轨迹，但不直接加入其他原始辅助变量，与R43的原始全变量加候选作变量范围对照。上游填补仍使用原辅助信息，因此后两类不能描述为完全不使用协变量信息。

隔离组查询读取每个候选的单独预测，并固定汇总均值/中位数；加入原始目标单独预测后再给标准输出均值/中位数控制。联合查询给候选均值/中位数；目标锚点加候选查询分别读原始目标、辅助预测均值/中位数。加原始目标单独预测，每来源新增C+10个点输出，C为12或6；每项也保留同VAR各半控制。因此北京从186扩为230方法，HDB从71扩为103方法，总61679窗口、114809目标分数。

本诊断不使用R43的完整目标回退来替换新增查询，四种查询对全部314任务执行，以免比较中混入不同回退信息范围。原R43回退结果仍原样保留。这会让8个完整目标HDB任务的新联合候选读出与原R43控制定义不同，须明确区分。306个非回退任务的新联合分位必须逐值重现原proxy_pool_only查询。HDB原始目标单独预测必须重现原native_target192。原始目标锚点的统计和编码与目标单独查询一致。

正式共1256次完整模型前向，审计再重放1256次。隔离候选的一次物理批前向包含C个逻辑预测组，不能与一个联合组混称相同逻辑调用。启动前小批额外逐候选串行预测，验证组隔离确实等价于分别运行；不同批形状的浮点等价检查固定rtol/atol=2e-5，同一批查询重放和既有查询恢复仍精确。原输入字段精确保持，指标及聚合1e-12，不为通过检查放宽。

核心诊断比较为联合候选中位数对隔离候选中位数、仅目标锚点加候选对原全变量锚点加候选、原始目标单独对原始联合变量，以及每个候选仅目标预测对原同候选的全变量预测。必须同时报告自然、人工与原生/长跨度面板，单独解释信息路径和群组变化。若新增对照解释了辅助优势，则补正原解释，不能将缺少基线形成的差距包装成方法贡献；若交互仍有增量，也须另行研究其条件和未用确认，不直接恢复已失败主方法。正式运行期间每30分钟检查，9月18日起不新增实验。
