# 条件风险诊断的研究定位

关于虚拟最优的乐观偏差，Cameron、Hoos与Leyton-Brown在IJCAI 2016已分析随机求解器的单次运行最优与最佳期望表现的差别，并提出重复运行和重采样评估。因此，min与期望交换导致的偏差本身不属于本工作的创新。[原文](https://www.cs.ubc.ca/~kevinlb/papers/2016-IJCAI-VBS.pdf)

Wagner等2019年的图像质量算法选择研究也报告了明显事后最优差距与多种选择器未能获得稳定收益的现象。本文不能把类似的选择器失败单独当作足够贡献。[原文](https://arxiv.org/abs/1908.06911)

SynTSBench已用可控时序和已知最优预测分析模型能力及不可预测成分。本轮不会声称首次使用合成数据或理论噪声下界；目前已核对其摘要、相关框架与附录D的最优预测说明，未据有限阅读断言全部先例不存在。[原文](https://arxiv.org/html/2510.20273v1)

待检验的问题限定为：在缺失历史、固定填补候选和冻结预测器下，显式给定观测信息后，有多少事后选择差距来自不可预测未来，以及它与缺失历史造成的条件不确定性如何区分。当前只是诊断假设。采用已知线性高斯过程，使观测历史条件分布可以精确计算；固定历史和候选预测，只改变未来创新噪声。该实验可能解释某些受控现象，但不能直接识别现有真实数据的噪声份额，也不能证明所有选择器都不可学习。

当前论文研究质量仍未达到目标。若诊断仅复现一般已知结论，应如实作为辅助检查保留；是否能形成论文主张，需要新的、非平凡且有充分覆盖的证据。
