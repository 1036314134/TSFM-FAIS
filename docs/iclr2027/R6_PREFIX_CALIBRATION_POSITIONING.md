# 前缀校准与既有预测组合工作的关系

2026-09-14 核对 [Chroma 原文](https://arxiv.org/html/2510.06419v2)第 3.4 节、第 4 节实验设置及 GIFT-Eval 描述。其预测组合使用时间序列验证窗口：在训练部分末尾保留一个预测跨度，比较成员预测与该段真实观测，再选择单个成员或以贪心方式拟合组合。文中明确提到可用多个验证窗口；GIFT-Eval 上在首个评价窗口的历史中确定组合，后续窗口保持固定。因此，在过去窗口上学习固定组合、将其用于后续预测，以及无需更新基础模型的组合推理，都不能作为本工作的独立新颖性主张。

当前试验的具体区别是候选来自同一个冻结预测器接收不同填补历史，拟合目标是完整历史教师的输出；某个校准历史之后的真实值不需要被观察。该信息区别必须通过实验支撑其价值，仅改变组合成员的来源或将真实标签替换成模型输出，尚不足以证明有竞争力的方法贡献。现有试验还依赖至少两个全变量完整历史，并且校准用填补器与部署用填补器的拟合区间不同，不能忽略这些限制。

若当前固定试验获得可复现改善，进入新的独立确认前还需要一个直接相关的对照：使用相同过去窗口内确实可见的未来观测拟合组合，并在教师与真实标签均可用的公共历史子集上匹配比较。该对照可以复用已经生成的候选预测，但应提前固定未来可观测条件、窗口匹配及回退规则；不可在测试误差上挑选最有利的历史子集。本轮没有将此对照伪装成已完成实验，也没有因相关工作检查而修改正在运行的主方案。

[Regularized Ensemble Forecasting for Learning Weights from Historical and Current Forecasts](https://arxiv.org/abs/2602.11379) 的摘要也将历史与当前预测信息用于正则化组合权重。当前仅核对摘要，尚未逐式或逐实现比较，不能据此声称本试验的收缩策略不同于该工作的全部方法。主方案固定的等量收缩属于稳定估计的常规控制，论文贡献须来自经过对照验证的问题差异、方法行为或经验结论。
