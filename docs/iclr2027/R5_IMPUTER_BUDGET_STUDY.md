# 神经填补训练预算的开发对照

独立确认没有支持三候选方法优于预测中位数。当前评价中的 SAITS 与 TimeMixer++ 采用 10 轮、最多 64 个训练窗口，不能据此判断这些算法的充分训练表现。本项只在已有开发任务上检查训练预算敏感性，不修改原始独立确认结果，也不继续调选择器。

数据固定为 ETTh1、current_velocity_H、electricity，分别覆盖常用基准、较低维输入和 321 维输入。评价沿用原 90 任务开发筛查面板中的对应 18 个任务，即每个数据集同一既定起点的六种已登记缺失条件；这些掩码不被视为六个独立时间起点。

训练序列从旧填补器清单的窗口标识中恢复，保持旧顺序。它们来自原数据集的确定性序列子集，并非一律为当前数据加载器的前四条。特别是 current_velocity_H 的原训练序列与 R4 评价的首条序列不同，这是原数据集级填补器配置的一部分。本项不改变这一配置。每条训练序列只使用最初 20% 的前缀；重建的 64 窗口批次必须与旧清单的内容摘要及窗口标识完全一致，未通过时停止检查来源，不能把变化归因于预算。

保留原冻结模型作参照，再从同一初始化重新拟合 10 轮/64 窗口、50 轮/64 窗口、50 轮/512 窗口。较大批次保留全部原 64 个窗口，另从同一前缀的均匀描述符候选中确定性加入 448 个新窗口。模型结构、批量 16、初始化种子 0、训练步长 24 与原缺失配置保持不变；ETT 使用 2101–2103 掩码种子，另外两数据集使用 1101–1103。合计新拟合 18 个填补模型。

新增填补结果保留原观测值，并复用原 LOCF 回退。固定其他四个候选，只替换这两个神经候选，再查询两个冻结预测器，报告单独 SAITS、TimeMixer++ 和七候选预测均值/中位数的 MAE/MSE。旧候选银行也实际重放，检查与已修正预测缓存的一致性。主指标继续按原训练前缀标准化；不以训练损失代替下游预测误差。

原模型与重新拟合 10/64 的差别单独保留，用于识别运行环境或数值再现差异。预算结论优先比较本次同环境的 10/64、50/64 和 50/512。该检查不涉及网络容量、完整超参数搜索或新家族确认，结果不能被称为充分调优的算法排名。

18 个模型拟合、两个预测器的评价及 `imputer-budget-audit-v001` 均已完成。三个原 64 窗口训练批次全部精确复现；较大预算包含这些原窗口，模型结构及四个经典候选输入保持不变，重新评分差异为零。

结果说明训练预算会实质影响下游误差，但影响并不单调。ETTh1 上，50/512 的预测中位数在两个预测器上都优于 10/64；current_velocity_H 和 electricity 上，中位数在两模型上都没有获得同样改善。完整逐条件表及与本次重拟合 10/64 的差值在 `artifacts/iclr27-r5/imputer-budget-audit-v001`。

| 电力数据的 TimeMixer++ | 10 轮 / 64 窗口 MAE / MSE | 50 轮 / 512 窗口 MAE / MSE |
|---|---|---|
| Chronos-2 | 0.637103 / 0.872041 | 0.554625 / 0.619763 |
| TimesFM 2.5 | 0.592263 / 0.669310 | 0.594532 / 0.751014 |

相同的新填补结果在 Chronos 上降低误差，在 TimesFM 上却增加误差。该现象不能单独归因于协变量：两个预算同时改变了目标和其他变量的填补，而两个预测器的结构也不同。若进一步分析，应保持同一原始窗口，交叉替换目标列和非目标列的填补结果，明确区分两类输入改变及其交互作用。

电力数据的 SAITS 在 Chronos 下从 10/64 的 0.544629/0.678087 改善为 50/64 的 0.418077/0.466078，但 50/512 又退化为 0.647737/0.911696。因此，不能把更大预算自动视为更强的下游预测流程，也不能使用已看到的评价误差为每个数据集挑选预算后再声称独立优势。当前是三个开发历史上的受控敏感性证据，原自然缺失确认失败的结论不变。

TiRex 对同一填补输入的 72 组评价也已完成，`imputer-budget-tirex-audit-v001` 复算差异为零。原生接口采用已固定的单条批量、纯 torch 和关闭 TF32 的设置，预测器参数保持不变。七候选预测中位数从 10/64 到 50/512，在 ETTh1 上由 MAE/MSE 1.274877/3.555188 改善为 1.234378/3.388647；在 current_velocity_H 上由 0.659929/0.677802 退化为 0.663790/0.683133；在 electricity 上由 0.566158/0.670876 退化为 0.592711/0.737729。该趋势与此前两预测器在这三个历史上的预算方向一致，但不扩大独立历史样本量。

电力数据的 TimeMixer++ 在 TiRex 上从 0.593451/0.642463 退化为 0.602484/0.775509，与 TimesFM 的方向一致，与 Chronos 的改善方向不同。ETTh1 的原生缺失流程为 1.212690/3.164339，仍优于上述两个预算的七候选中位数。第三模型没有支持普遍增加训练预算或普遍采用该预测中位数的结论，也不是原生缺失确认集上的第三模型验证。

以上数字描述初始单历史面板。后续已完成每数据集四个历史的扩展，见 `R5_BUDGET_ORIGIN_EXTENSION.md`。原电力 TimeMixer++ 对 Chronos 的大幅收益未在另外三个历史复现，四历史平均反而略有退化；引用预算方向时应优先同时报告扩展结果，避免将这个初始局部例子写成普遍收益。
