# 全缺失目标与尺度信息的对照解释

本记录给出输入标准化对照的数学解释，属于方法开发笔记。以下代数性质不作为本项目的新理论贡献；其是否解释实际实验差异仍需逐窗口结果验证。

设当前历史上下文为 C，目标变量为 k。若 C 的第 k 列完全缺失，则对该变量施加单位变换 x′ = ax + b（a > 0），当前可观测输入保持不变。只读取 C 的确定性预测器 F 因而产生相同输出。然而，若要求预测随单位平移，取 a = 1、b ≠ 0，又应满足 F(C)′ = F(C) + b。两项要求不能同时成立。仅凭完全缺失的当前目标列，预测器没有足够信息确定该目标的数值原点；增加辅助变量也不会消除这一问题，因为本构造只改变目标的单位。

若部署时还提供历史拟合前缀 P，可以用其目标均值 μ 和标准差 σ 明确恢复尺度信息。在每个输入变量的前缀标准差均为正的条件下，定义预测流程

\[
\widehat Y = \mu_{\mathcal T} + \sigma_{\mathcal T}
F\left((C-\mu)/\sigma\right),
\]

其中缺失值继续保留，\(\mathcal T\) 为目标集合。对各变量同时变换前缀和当前上下文，有 μ′ = aμ + b、σ′ = aσ，因此标准化后的输入完全相同。对于任意固定的 F，上式输出随对应目标的正比例缩放和平移而变换。这一性质不要求 F 自身具有尺度等变性，也不意味着 F 的预测一定准确。

这里有三个适用限制。第一，常量前缀采用尺度 1 的工程回退时，上述一般缩放推导不适用，应单独分析。第二，若先在原始单位中运行填补器，再标准化其输出，整个流程还取决于填补器是否随单位一致变换；例如基于原始多变量距离的邻居选择需要另做标准化距离对照。第三，前缀统计量属于额外历史信息，必须明确所有方法是否都允许使用，不能将它带来的变化直接计为填补选择收益。

对应的经验检查是：在完全相同的预测起点上，将原生缺失输入与前缀标准化后的原生缺失输入配对，分别查看无全缺失目标、存在全缺失目标以及仅辅助变量全缺失的情况；再检查较长历史是否恢复了目标观测。已完成的 Chronos 历史对照提供所需预测，分层汇总使用原始上下文掩码派生的观测特征。该检查只解释输入信息差异，不使用当前未来值改变预测策略。

本地实际使用的 SDK 已核查：`chronos/chronos2/model.py` 从 `chronos/chronos_bolt.py` 引入 `InstanceNorm`，上下文经该模块归一化，输出再反变换。该模块对整列缺失使用中心 0、尺度 1。此行为使前述信息差异在当前模型上具有明确的实现对应。后续分层统计已完成，结果见 `R4_SCREENING_FINDINGS.md`：显著尺度变化集中于汇率、交通各一个目标全缺失任务，其余任务只有很小的数值差异。该核查支持当前开发案例的解释，并不等于已验证对所有模型或数据的普遍结论。
