# R6 完整历史教师与迁移损失诊断

2026-09-14，在 R6 确认及两项前缀校准读出后登记。此前 R5 已用跟进数据的 16 个历史教师诊断只针对旧三元组学习器；不能替代当前四来源共享门控的判断。当前需要区分可见权重学习失败与教师代理目标本身的局限，而不是立即扩展超参数或改用模型专属规则。

只使用 R6 人工缺失面板对应的 32 个原始完整历史，不增加来源、窗口或准入筛选。对两预测器、H96/H192 各获得一次完整历史的冻结点预测，最多 128 个新增历史级预测调用。输入由已绑定的原始轨迹中起点前 96 步取得，均为全变量完整；沿用原始尺度输入、前缀标准化和原冻结预测器版本。不得使用原始缺失历史的填补值冒充完整教师。保存教师预测、输入/参数摘要及覆盖记录后，再做诊断计分。继续通过第三优先级资源守护队列串行执行。

复用原八候选预测及已审查的 23 方法输出。对原七候选凸组合类，计算逐输入最小教师 MSE 的理想权重，以及每条序列固定权重的教师最优参照。前者可界定主门控在当前样本上的教师额外损失，后者与已有每序列真实未来理想参照比较。教师理想参照使用不可见的完整当前历史，真实未来理想参照使用评价标签，都不可部署；不称为方法效果。坐标中位数不一定在七个预测向量的凸包内，不能把凸组合教师最优值错误地称为其中位数类的下界。

主诊断保留完整历史教师自己的下游 MAE/MSE。以源固定凸组合 b 为参考，逐输入计算主门控等已部署输出 p 的真实 MSE 差、教师 MSE 差及二者差值。对于向量长度 q，恒等式为：真实损失差减教师损失差等于 2/q 乘 (p−b) 与 (t−Y) 的内积。独立按向量计算核对该关系；它是标准平方损失展开，不是新理论。样本交叉项包含预测模型误差和未来随机性，不能直接称为已识别的模型偏差或因果机制。

两个下游指标、逐来源及两跨度均保留。按目标、掩码、原始历史、序列、数据集和家族进行与 R6 一致的汇总，报告配对方向与范围，不把 1,152 个掩码输入当作独立历史。如果当前教师理想组合仍明显优于可见选择器，可以进一步检查学习迁移；如果教师目标本身已出现明显取舍，应优先重新评估代理目标，而非只增加训练规模。诊断结果不能反向改变已冻结的 R6 主方法或将该数据重新视为独立验证。
