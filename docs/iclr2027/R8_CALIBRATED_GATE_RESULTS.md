# 时间校准与偏离约束的结果

本轮于北京时间2026年9月14日22:35完成，独立核验543个检查点、128项内层选择和106,704条外层决策评分；预测重建最大差7.11e-15，固定组合最优性最大差5.27e-16。全部原基线精确复现。证据位于 artifacts/iclr27-r8/calibrated-source-audit-v001。

预定主条件point_calibrated的Chronos MAE/MSE为0.788712/1.575545，优于R7 point_future的0.795853/1.611948，但仍弱于源实际未来固定组合0.784590/1.569753和教师固定组合0.780245/1.555166。TimesFM为0.766890/1.537796，与原point_future完全相同，仍未超过教师固定组合0.768876/1.521435的双指标。主条件与仅选择轮数的point_early_stop在两模型上完全相同；不能把Chronos的改进归因于新增偏离约束。

含完整源拟合在内的16个Chronos折，点特征程序10折回退到固定组合、6折选lambda=0和25轮；TimesFM全部16折选lambda=0和25轮。表示条件的校准结果C=0.791784/1.595058、T=0.783194/1.569557，均比其仅选轮数控制差。所有学习器被选择时都是25轮，当前内层校准不支持更少轮数。因此本轮既未建立约束项收益，也未解决强固定比较问题，不能据训练完成提升为主方法。

下一项有界研究转向不同训练历史的数量。原165历史在多种遮盖下重复出现，增加遮盖不会增加历史起点。新的元数据清点已确认，在不改变15家族、原20%填补拟合前缀、60%时间边界与原52个外层验证历史的条件下，可把训练历史从165增加至322，新增157个历史和2,826个单种子遮盖输入。增加只发生于有足够时间长度的8个家族，不视为15个家族一致扩张。新旧历史以192步间距保持训练窗口区间不重叠，时间相关性仍存在。完整清点位于artifacts/iclr27-r9/source-expansion-inventory-v001，样本入选未使用预测误差。

该学习曲线试验保留相同小网络与两种监督，并额外控制优化步数，避免把更多训练更新误认成更多历史的作用。正面开发结果仍需新的独立确认，增加训练样本本身不作为新颖性贡献。
