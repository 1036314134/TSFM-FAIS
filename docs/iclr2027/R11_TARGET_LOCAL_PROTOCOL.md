# Chronos目标级特征与共享特征的匹配比较

2026年9月15日，在R10源及迁移评估后登记。现有Chronos门控共用两个目标的特征和权重，而TimesFM已有目标级特征。本轮检验目标级描述是否改善Chronos选择，保持时序预测器、七候选预测、原165训练/52验证历史、单掩码种子6101和全部分割不变。没有新填补器拟合或时序预测器调用。

把每个Chronos源输入拆成目标0、1两条决策，候选预测仍来自原联合多变量预测。对同一7,812条决策生成两套33维特征：broadcast复制原联合33维特征，target按当前目标重算原相同字段。全局缺失率、维数及候选原生覆盖等仍描述实际上下文；guarded_direct的回退特征必须遵从Chronos规则，即任意输入变量全缺失时整体回退，不能误改为TimesFM的单目标规则。TimesFM原7,812条目标决策也用新函数重算，必须逐值精确复现其原33维输入，从而复用原R10 joint_future模型。

两种Chronos程序使用相同目标行、顺序、家族权重、初始化、97维输入（33特征补64零）、2,120参数网络、25轮、128批量、AdamW 0.001学习率与权重衰减、梯度上限1和三个原种子。监督均为实际源训练未来的联合MAE/MSE目标，epsilon0.001，与R10完全一致。broadcast没有目标编号输入，两个目标收到相同特征，推断权重应精确相同；target允许因目标可见特征不同而选择不同权重。二者更新次数相同。保留原R10联合决策模型，区分新增目标行带来的更新变化。主新条件为target，不能按外层结果更换。

Chronos十五家族留出折和一个完整源拟合、两条件、三种子共96个模型。每个折再为目标0、1分别拟合同损失固定凸组合与固定单候选；两个目标固定权重组成一种目标级固定程序，两单候选组成另一程序。原R10的46方法全部复用并拆成目标级预测，新增两条件的三种子与平均8方法、两个固定程序，总56方法。所有外层预测冻结后才读取验证真实未来，按目标合并后复现原基线，允许由求和顺序变化产生的1e-12数值误差并记录最大差。新程序独立评分精确重放，预期104,832条目标决策评分。

准备阶段不读取真实未来。独立核验原上下文、目标特征、联合回退标记、目标次序、TimesFM输入不变、96模型人口/统计/预算、32个目标固定组合最优性、broadcast权重共享与预测/指标。TimesFM不重新训练；它在统一逐目标流程下对应原R10 joint_future，不把复用算作新实验。结果仍是预测组合，不能宣称对应唯一填补历史。

正式实验包括准备、训练和独立核验，第一优先级、单核执行，各阶段上限1/3/1小时。运行期间只每小时检查一次，完整核验后立即解释并决定下一步。已用目标集合不变，不宣称新的独立确认；一般逐目标组合本身不作为新颖性贡献。
