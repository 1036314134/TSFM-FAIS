# 冻结预测器表示的源端准确度试验

2026-09-14，在33个接口请求全部通过之后登记。本实验优先级为第一。运行期间只等待完成；完整结果审查后再决定下一轮修改。

使用原15家族的全部165训练历史与52验证历史。保留六个既有缺失机制和0.1/0.3/0.5三个名义缺失率，只取原种子6101，共3,906输入，其中2,970训练输入和936验证输入。选择依据仅为原元数据，不根据预测误差筛选。与原完整双种子结果分开报告。

沿用本地冻结Chronos-2和TimesFM 2.5及L=H=96。七候选仍为六个原填补器与原生回退，不重新拟合填补器。每个有效候选输入独立预测，保留点输出、分位数和目标对应的预测头输入；相同有效输入可复用。完整原历史的教师点预测也按相同调用方式获取，只用于源监督。统计量继续来自原训练前缀。采集阶段不读取真实未来数组。

Chronos保留两个目标各自前半、后半未来块表示的均值，拼成3,072维。TimesFM保留两个符号分支的最后历史块表示，每个目标为2,560维。用预定高斯投影压缩为32维，种子分别为9521、9522，矩阵元素按1/sqrt(32)缩放，不从数据或标签拟合投影。每候选加入32维投影及其相对LOCF的32维差值。两类模型的表示语义不同，分别训练选择器。

比较四个预定条件：原33维特征补64个零值，与加入真实64维表示；分别使用完整历史教师MSE及实际训练未来MSE。四者采用相同97维输入结构、隐藏宽度16、每模型2,120参数、25轮、batch128、AdamW学习率与权重衰减各0.001、梯度上限1和种子5101/5102/5103。原33维中的区间字段仍采用point-only定义。家族权重沿用原定义。主条件为内部表示加实际未来监督，其余为匹配对照；不事后按单个预测器切换主条件。

30个家族留出折、四条件、三种子共360个验证模型，另拟合24个完整源模型，总384个检查点。保留相应教师/实际未来标签下的源固定凸组合、源固定单候选、七候选均值和中位数。预测器保持冻结，学习器返回候选预测的凸组合。所有验证预测保存后再读取验证真实未来，按原源口径报告训练前缀标准化MAE/MSE、家族结果和种子结果。实际未来标签只进入当前折允许的训练行。

采集明确记录模型所在设备、有效输入去重、参数摘要、源文件绑定和额外重复检查。首个新查询及随后每128个新查询与不带表示读取的预测作精确比较；模型参数前后保持一致。有效输入缓存原子保存，重启只恢复未完成项。最多需要两个模型各7×3906+217个不同输入请求，实际数量受重复输入复用影响；重复性检查和中断尝试另记，不能等同于部署成本。

独立审查核对选择人口、源分割、原始目标、固定投影、LOCF差值、97维条件匹配、384检查点、训练统计及预测/评分。此为已用源数据上的开发试验；内部表示可读取不代表有用，正面源结果仍需独立迁移确认。此方向要求本地模型权重，不承诺仅有预测API的场景可用。当前不登记新的目标集合或改变主要MAE/MSE口径。
