# 预测组合决策类的可达误差检查

2026-09-14，在关系门控源审查和迁移读出之后登记。完整关系门控在 R6 人工缺失上优于原 33 维门控，但未稳定超过同容量对角控制；七家族原始缺失上的两个指标仍没有稳定优势。现有门控的权重在预测区间内固定，七候选坐标中位数则可以在不同预测位置使用不同候选的值。两种输出类并不相同，不能只把二者差距解释成特征或参数不足。

本项仅复用已核验的 R6 H96 和早期九家族 H96 预测缓存，不训练模型、不调用预测器。对每个原始未来观测掩码，分别计算同一七候选池内的实际未来最佳单候选、区间固定权重的最优凸组合，以及逐预测位置最优凸组合。前两者保持当前决策范围：Chronos 对两个目标共享选择/权重，TimesFM 按目标分别选择/加权。逐位置控制对每个预测步与目标独立取七个点预测范围内最接近真实值的点，等于将已观测真值投影到该区间。

所有理想参照均使用评价未来，只表示有限候选输出类的可达误差，不是可部署方法，也不证明该差距能被学习消除。未观测未来不填成标签；逐位置理想预测在未评分位置以七候选中位数补齐，仅用于保存有限预测数组。它不改变原未来掩码或计分位置。

区间固定权重的二次目标按每目标实际观测数归一化，使用已有七维单纯形求解器，并以直接残差梯度检查最优性。验证其 MSE 不高于同范围最佳单候选。逐位置参照的 MAE/MSE 必须不高于区间固定组合和七候选中位数；该性质来自允许的输出集合包含关系。含 MoTM 的中位数使用额外候选，另行比较，不把七候选理想参照误称为它的下界。

R6 各面板与九家族的全部/原始缺失/完整历史子集分别报告，按原家族等权和训练前缀标准化口径汇总。先检查可达空间是否足够大，再决定改变输出粒度还是补充原始缺失训练数据。不因理想参照较好就直接扩大模型或选择最有利的来源。继续第三优先级与结束事件通知。
