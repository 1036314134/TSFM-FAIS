# 训练预算结论的额外历史起点检查

前一预算面板在每个数据集只评价一个历史起点。本项复用已经拟合并核验的 18 个 SAITS/TimeMixer++ 模型，在同一开发序列其余全部已登记验证起点上评价，检查已有方向是否依赖单个历史。它是开发敏感性研究的后续检查，不是新的独立家族确认，不修改原自然缺失确认结论。

数据与选择规则在生成新填补结果之前固定。ETTh1 额外起点为 12660、14964、17268；current_velocity_H 为 3562、4138、4714；electricity 为 19142、22598、26054。每个起点沿用原面板的 random_point、independent_block、value_dependent 三种机制、0.1/0.5 两种缺失率和种子 6101。共新增 9 个历史、54 个掩码任务；合并旧面板后为 12 个历史、72 个掩码任务。全部起点来自原验证段，选择不读取未来误差。

保留 10 轮/64 窗口、50 轮/64 窗口、50 轮/512 窗口及原 legacy 四种预算记录。新增填补只加载旧预算研究的检查点，不重新训练、挑选预算或改变模型结构。每个数据集和预算先重放一个旧任务，核验加载检查点后的填补结果与原记录一致；之后生成额外任务的填补。原观测值及四个经典候选保持不变，未解决的点沿用同一 LOCF 回退。旧任务的冻结预测不重算。

Chronos-2、TimesFM 2.5 和 TiRex 分别评价额外任务，输入、预测器设置、主指标及原生处理规则保持原定义。新增逻辑评价为每个预测器 54×4 个任务—预算组合。TiRex 继续固定纯 torch、batch size 1、关闭编译与 TF32，并在 legacy 输入上与原生 SDK 比较。所有预测在读取相应未来用于评分之前保存。

报告旧起点、额外起点及合并面板的逐数据集 MAE/MSE，同时保留每个起点在两种较大预算相对 10/64 的配对差值。六种掩码先在历史内平均，历史再等权；同一序列的四个历史也不能当作四个独立数据家族。本项不设置新的最优预算选择规则，不用小样本显著性检验支持广泛结论。

资源继续排第三，通过既有队列执行。队列终止时使用 Windows 系统通知，不恢复已停用的周期进度查询。

本项已完成。三个预测器各完成 216 个新增任务—预算组合；旧检查点重放最大差异为 4.50e-7 以内，没有重新拟合模型。第一次审查在覆盖检查处仍使用旧的 18 任务常量而失败，已改为核对准备清单中的确切任务 ID 集合和声明数量。18/54 任务规模、错误 ID 与重复 ID 的回归检查通过，重新审查全部预测的 MAE/MSE 差异为零。旧失败日志与源码快照保留。

合并四个历史后，七候选预测中位数在 ETTh1 的三模型平均 MAE/MSE 都随 50/512 预算改善，在 current_velocity_H 和 electricity 的三模型平均中都退化；逐历史并不完全一致。例如 Chronos 的 ETTh1 是两次共同改善、两次共同退化，不能将数据集平均提升写成每个历史均提升。

原电力 TimeMixer++ 对 Chronos 的大幅改善仅出现在四个历史中的一个，另外三个历史的 MAE/MSE 均升高。四历史平均从 0.509804/0.702200 变为 0.520258/0.711488，方向与最初单历史的结果相反。该单历史仍可作为已明确条件的交叉输入例子，不能作为预算普遍改善的依据。

current_velocity_H 的 TimeMixer++ 展现了另一种模型差别，以下都为四历史等权、每历史六条件平均：

| 预测器 | 10/64 MAE / MSE | 50/512 MAE / MSE | 两指标共同改善的历史 |
|---|---|---|---|
| Chronos-2 | 0.737114 / 0.827770 | 0.763693 / 0.872270 | 0/4 |
| TimesFM 2.5 | 0.669345 / 0.683377 | 0.657149 / 0.664951 | 3/4 |
| TiRex | 0.616648 / 0.620702 | 0.626207 / 0.635902 | 1/4 |

TimesFM 和 TiRex 都按目标独立调用，预算方向仍不一致。因此，仅按是否使用其他输入变量分类，不能解释本例全部预测器差别。这些仍是三个数据集、每数据集一条序列的开发结论，不是总体算法能力排名或新的独立确认。
