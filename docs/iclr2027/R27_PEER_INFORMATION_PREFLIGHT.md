# 相关序列历史信息：应用假设与可用性检查

截至2026年9月16日，原目标变量及既有历史范围内的多轮选择、固定修正与源监督表示修复，均未建立稳定超过强固定基线的预测优势。方法论文定位继续保留，下一阶段需要明确一个应用假设：预测时能否使用同一系统其他序列截至当前时刻的历史。该范围尚待用户确定，当前没有据此启动预测实验。

只读检查选择已有Beijing数据的12个站点，目标为PM2.5和PM10。站点时间起点、频率和目标列顺序一致。每个目标站点/变量只在双方已登记训练前缀重叠部分计算相关性，要求至少128个共同观测，按绝对相关性选取3个候选站点，未读取当前预测未来。

在R25的138个北京开发历史、192步上下文内，按站点、变量和时间去重后有1580个目标缺失位置。其中1162个位置（73.54%）至少有一个候选站点的同期原观测，1041个位置有三个候选站点同时可观测。这证明存在可进一步检查的信息补充机会，不证明它能改善下游预测，也不证明这些站点在用户的实际部署中可读取。

若该信息范围可用，首轮须给所有方法相同的同期历史、相同时间截止和前缀拟合范围。至少保留原生Chronos直接联合读取相关历史、简单前缀回归补足、以及同信息的填补池作为对照。只有超出直接读取额外数据和简单处理的增量，才可作为新方法候选。通用检索增强已有TimeRAF等工作，不能把引入相关序列本身当作创新：https://www.microsoft.com/en-us/research/publication/timeraf-retrieval-augmented-foundation-model-for-zero-shot-time-series-forecasting/?lang=zh-cn 。

若该信息范围不可用，相关序列不进入后续预测设计。新的实验需继续遵守原信息范围，重新确定核心研究假设；当前没有足够证据承诺摘要截止前能形成投稿质量。

可核查记录为artifacts/iclr27-r27/peer-information-preflight-v001/manifest.json，包含每个目标的前缀候选关系和各窗口覆盖计数。该步骤没有基础模型调用，没有新的模型训练，没有当前未来预测误差读出，也没有使用未认证储备进行方法选择。
