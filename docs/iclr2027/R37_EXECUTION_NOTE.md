# R37 执行与数值核验口径

本方法需要访问冻结模型的归一化模块、输入块权重和激活函数，是输入编码接口适配，不能称为只依赖预测API的黑箱填补器。当前固定实现针对已核实的Chronos ReLU残差输入块及arcsinh，不预设其他模型接口相同。

正式启动前7项数学/接口测试通过，8个历史的小批产生176个干预/参照查询，并恢复8个普通静态预测，全部预测及组合逐值重放。独立NumPy编码矩计算最大差1.08e-7，归一化统计参考差8.77e-8。编码参考包含float64与原float32线性运算的差异，固定使用rtol=2e-5、atol=2e-5；新归一化统计固定rtol=2e-6、atol=1e-6，零不确定性统计和零不确定性块逐值保持。原始预测与组合须逐值一致，误差与聚合仍为1e-12。

标量ReLU期望的早期实现，在固定[-10,-5]数值网格上出现最多约2.2e-16的负舍入结果。正式实现改用等价的erfc尾部表达，并保持ReLU期望的非负取值范围。原实现、首批预测及诊断保留；修正后的完整小批使用smoke-v002，没有调整模型、数据或检查容差，也没有读取小批预测误差选配置。

每个正式历史包含6种单次路径和16次完整MC参照，共22次新完整预测，231任务合计5082次；另有231次撤销所有干预后的普通预测恢复验证。主方法自身只调用一次完整模型，同时仍需局部求积和额外输入块运算。MC块参照还执行16组输入块。共同准备过程的条件协方差和参照分解、样本生成耗时单列，不能忽略它们或把共享计算当作免费成本。

新加坡储备的官方前缀抽查与本轮北京预测实验分开记录。354条序列在三个前缀时点的身份核对及SB36车位类型差异尚不能认证完整转换流程；本轮没有以该储备的预测效果作方法选择。
