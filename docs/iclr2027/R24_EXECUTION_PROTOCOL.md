评价输入共910个：864源验证L96，以及23个旧自然开发历史各L96/L192。192步采用真实较长历史，按同一原前缀拟合的季节统计和原观测保护生成基础输入，96步结果与旧季节填补缓存逐值一致。新的季节统计重建共14次，无新神经填补训练。源固定MAE/联合凸组合及MAE最佳单候选已在相同2682源训练输入上重算，并检查一阶最优性；旧全源控制也保留。
