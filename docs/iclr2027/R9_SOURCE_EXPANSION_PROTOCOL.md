# 不同源历史数量与优化步数的匹配试验

2026年9月14日，在R8完成后登记。固定已核验的15个源家族与52个外层验证历史，将源训练历史从165增加到322。每条序列最多64个训练起点，完整保留原起点，再从原192步时间网格的剩余起点等距补充；20%填补器拟合前缀、60%训练验证边界、L=H=96均不变。清点已完成，新增157历史来自8个有足够长度的家族；未根据误差选择。保留六个原缺失机制、0.1/0.3/0.5三个率和种子6101，新增2,826个训练输入，原3,906输入全部复用。

仅为新增历史生成填补结果和预测。使用原SAITS与TimeMixer++训练前缀检查点，不重新拟合神经填补器；季节模板等确定性前缀统计按原规则重建。使用原随机遮盖协议标识和种子逻辑。每个新增来源先重放一个预定旧输入，检查遮盖完全一致、六候选相同观测不变，填补结果在float32允许的1e-6绝对与相对误差内一致，记录最大差。此阈值在新计算前固定，超出则停止诊断。新增原始历史和未来必须完整，不能按模型误差丢弃来源或历史。

冻结Chronos-2与TimesFM 2.5，使用与R7相同的单有效输入调用方式、原生回退、目标0/1及前缀标准化统计。只需点预测和完整历史教师，输入特征使用原33点特征补64个零，不继续采集内部表示。有效输入去重并缓存，允许复用经核对的R7同输入预测。每128个新请求及首个请求重放，模型参数前后核对。采集结果中的真实未来只来自新增训练历史。两个模型各最多7×2826+157个新有效输入，重复与复用另记。

比较expanded与steps_matched两种新程序：expanded在扩张源人口上训练25轮；steps_matched仅在原人口上训练，但更新次数等于当前扩张人口25轮的批次数。旧原人口25轮的point_teacher/point_future保留。两种新程序分别采用完整历史教师MSE和实际训练未来MSE，使用相同97维/2,120参数小网络、128批量、学习率和权重衰减0.001、梯度上限1、种子5101/5102/5103。steps_matched按固定种子连续洗牌迭代，达到预定更新次数即停止。两种新程序共384个拟合，包含30个家族留出折和两模型完整源拟合。主条件expanded_future，teacher及步数对照全部保留。

每个外层折排除该家族的所有原始和新增训练历史。另拟合同扩张人口的教师/实际未来固定凸组合与固定单候选。全部验证预测及模型记录冻结后读取原验证未来计算下游MAE/MSE；原22方法直接复用R7已审查预测，新增程序不改变它们。原评价口径、家族与种子结果全部保留。不同训练历史更多不等于统计独立或因果上只改变数量：可用历史扩展随家族长度变化，时间相关性及训练分布变化必须说明。

独立核验原始来源、人口、源前缀、遮盖与观测不变、预测输入与候选顺序、标准化、384模型的训练历史/更新次数/统计、固定组合最优性、预测组合和指标；原基线精确复现。此为已用源数据上的开发学习曲线，增加样本本身不作为新颖性。正式实验包含新增输入准备、预测采集、训练及独立核验，第一优先级；准备上限2小时、采集12小时、训练4小时、审查2小时。运行期间每小时检查一次且不开展研究分析；短诊断与结果解释完成后即时推进。
