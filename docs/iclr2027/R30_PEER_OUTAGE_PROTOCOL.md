# R30：共享站点信息下的持续缺测预测

2026年9月16日。用户明确允许读取同系统其他序列截至预测时刻的历史，并授权后续常规研究范围选择自行推进，无需重复确认。主任务收窄为PM2.5/PM10连续不可观测时的未来24小时预测；原H96人口另作参考。R28/R29负面结论保留，不重新命名成成功。

固定北京12站、原11变量，目标为前两个PM通道。沿用R27在原训练前缀内按绝对相关性选取的每目标3个其他站点，形成6个附加PM通道；所有新方法共享相同17列数据、同样192小时历史与原前缀拟合信息。只能读取时间小于当前起点t的观测；采用数据提供者的统一名义本地时钟，假定这些历史读数在t可用，不推断真实发布延迟。没有其他站点未来值输入。

主面板natural_outage_h24：在原序列后40%时段，两个目标已连续缺失至少6小时，起点取已发生缺失年龄6+24k小时；同站预测区间不重叠。按预定可评分条件，未来24小时每目标至少12个原观测值。输入/观测掩码预查得到45窗口、12站；另32个候选因未来原观测不足不进入评分。此条件可能偏向较快恢复观测的事件，应保留准入和排除记录，不解释成所有持续故障的总体表现。

辅助synthetic_outage_h24：每站后40%时段的24小时网格上，原两目标的192历史及24未来均可观测，从合格时间序列等距取4个起点，共48历史。仅把当前站两个目标最后24小时隐藏，其他站点与原辅助变量保持原观测状态。隐藏数值先从输入清除；这是固定的局部通道不可用模拟，不称为全站实际设备故障。

参考legacy_native_h96：原R25/R29的138个北京目标缺失历史，保持L192/H96与原未来评分条件。三面板分别报告，主面板优先，不能把不同人口的绝对误差混排。合计231任务，仍属同一已用来源的开发；不同站点不是独立来源，跨站同期相关性保留。

候选peer_ar_bridge仅在原目标缺口内修复数值，其他原变量和peer观测保持原样。先在前缀中，以当前可观测的其他变量拟合标准化ridge回归，均方损失惩罚lambda=0.001，截距不惩罚。当前输入掩码决定可用特征，不用当前隐藏真值或未来误差选择特征。拟合须有至少128个共同前缀观测；不足时按前缀绝对相关性移除最弱特征，仍无特征时回退已登记线性填补。每种可用特征集合的系数与支持数记录。

对回归残差，在相同前缀连续原观测上拟合AR(1)系数并裁到[0,0.99]。当前历史的已观测目标残差作为锚点。缺口有双侧锚点时使用AR(1)条件均值，有单侧时按距离衰减，无锚点时残差为0；所有锚点必须早于预测起点。其工作模型是线性与平稳残差近似，不宣称真实条件后验或最优预测。回归与AR桥接都是已有统计成分，本轮首先检验同信息预测增量，新颖性另行判断。

匹配控制包括peer_ridge（无局部残差）、peer_residual_linear（双侧线性残差插值/单侧常数延伸）、local_ridge（仅用原11列回归，但预测器仍可读相同peer历史）、peer_future_ridge（将原生联合预测的其他变量预测代入前缀回归，未来协变量仅为模型预测）。这些控制隔离额外观测、局部偏差和残差动态的作用。

完整同信息填补池包含LOCF、线性、季节、多变量KNN、SAITS、TimeMixer++、MoTM与原生处理；既比较全17列填补，也比较仅在原两个目标缺口使用相同填充值、其他列仍为原观测/NaN的池。两池各报告单候选、预测均值与中位数。另保留不带peer的原生处理，单独标作信息范围对照，不能把对它的改善全归给新算法。合计25方法。

SAITS/TimeMixer++在12站拼接后的17维原20%前缀上共同拟合，L192、最多512窗口、50轮、batch16、seed0；人工缺失机制/比率沿用原六机制、0.1至0.5及种子1101/1102/1103。早期小批仅1轮/16窗口验证接口，不能作为正式基线。传统统计和所有回归只拟合原前缀；MoTM沿用冻结网络与固定上下文优化预算。不能把旧11维深度模型冒充17维对照。记录全部拟合失败和共享回退，基线不完整时不作强优势声明。

所有新预测器输入统一按各通道的原训练前缀均值/总体标准差转换单位，以支持完全没有目标历史观测的窗口；所有方法相同。填补阶段原观测逐值保护。完全没有当前原观测的附加peer列在所有预测输入中共同去除，原目标列保留。评分仍为原两目标在原可观测未来上的标准化MAE/MSE，站点等权；填补误差只辅助。原生local/peer对照仅差peer信息，可以用于信息增量比较。

先冻结源、peer映射、人口、方法与预算，再准备填补输入和全部预测，最后统一读未来评分。独立核验源时间界限、peer原观测、人工隐藏清除、前缀拟合、回归参数、桥接公式、原观测保护、模型权重、全部原始查询重放和站点聚合。既有储备不参与试错。

只有peer_ar_bridge在预设主面板同时优于共享信息的原生、两套均值/中位数及回归/线性残差控制，且MAE至少相对最强固定均值/中位数降低1%，才继续投入。MSE完整保留；被强控制双指标支配就停止。1%是资源筛查而非统计或投稿标准。辅助面板的信号保留其身份，不能覆盖主面板失败。固定本轮长度、站点数、残差模型及训练预算，不根据新误差展开网格。

全部45/48/138窗口与来源排除理由保留，不按结果删除站点或事件。所有结论限于当前开发设置。正式准备、预测、评分、独立核验期间每30分钟检查一次，完成后再分析；不干预其他项目的进程、环境或数据。
