改变损失权重改善了 Chronos 在 R6 人工缺失上的两个指标，并且超过两种固定组合。相对旧门控，它在北京、Bike 和 Occupancy 三个来源改善两个指标，在 Appliances 上略退化。TimesFM 的平均两个指标却均退化。因此，原权重集中不是可以统一解释或统一修复两个模型表现的原因。源验证中也没有双模型双指标一致收益，不继续扩展权重系数搜索。

H192 的新门控 C 为 0.626036/1.145485，T 为 0.665540/1.299189，仍呈相同模型间差异。北京原始缺失 H96 子集 C 为 0.953607/1.944074，优于原门控但不优于所有简单或原生控制；T 为 0.980401/2.044553，相对原固定组合退化。H192 原始缺失也没有统一收益。当前不能选择性保留 Chronos 的新配置并据此改写原主方法确认结论。

证据为 `origin-weighting-source-v001` 与 `origin-weighting-transfer-v001`。评价完成后，外层队列最后写入状态时遇到 Windows 文件占用而退出；这不改变已经核验的实验完成产物。状态写入已增加最多 1.4 秒的有限重试，永久错误仍抛出。队列的资源让路、进程清理、所有权和写入异常等 35 项检查通过，未改动其他项目或系统权限。

本结果是 R6 已用数据上的开发性对照，论文目标仍未达到。下一项需要补齐同一小型网络在源家族留出条件下的真实未来监督对照，检验此前教师与真实标签的比较是否能跨学习器成立；当前的真实未来小网络只有完整源拟合及 R6 结果，不能直接用早期配对分类器的源结论替代。
