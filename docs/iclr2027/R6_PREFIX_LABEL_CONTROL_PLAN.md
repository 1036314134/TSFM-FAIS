# 历史教师与历史真实标签的匹配对照

2026-09-14，原前缀教师校准效果读出之后、匹配控制计算之前登记。原校准在 TimesFM 上改善、Chronos 上退化。对照复用已经核验的 43 个历史教师、774 个候选预测及冻结的全部 R6 评价预测，不新增基础模型调用或填补器拟合。

候选历史沿用原采样，不补充新的起点。历史起点之后的 96 步必须完整落在原 20% 训练前缀内，且两个目标各有至少 48 个原始观测值，才进入共同校准集合。每条序列少于两个共同历史时，两种控制均使用原源固定权重。每个保留历史的 18 个遮盖条件全部保留，各历史等权。

两种控制唯一的监督差别是完整历史教师与该历史之后已经可见的真实观测。教师损失也只在相同真实标签观测位置计算，目标各按实际观测数归一化，再等权平均两个目标。这样不能把教师使用更多历史或更多评分位置的优势混入监督目标比较。Chronos 共享两个目标的权重；TimesFM 按目标拟合。两者都使用原源固定权重与本地最小 MSE 权重各半，比例不搜索；H192 直接复用 H96 权重。

求解前核对过去真实标签与原轨迹及前缀边界；通过直接残差梯度核对最优性，在保存权重后构造两模型、两跨度的全部评价预测，再读取评价未来计分。保留训练前缀标准化的下游 MAE/MSE，分别报告全部既有面板和每来源结果。原源固定组合的评分必须与已核验结果重放一致，全部原基线与两种新控制并列表现。

R6 已用，本对照仍是开发性解释。观察到真实标签控制更好时，只能说明这个匹配设置下教师并非必要；反方向也不足以证明教师普遍占优。不会据此对原确认数据重新宣称独立优势。历史验证预测组合已有 Chroma 等先例，本对照是必要的相关方法控制。
