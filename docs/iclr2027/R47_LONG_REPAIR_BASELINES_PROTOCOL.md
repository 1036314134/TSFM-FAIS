# R47：默认长历史与既有固定填补的匹配基线

2026年9月17日，在新增预测之前登记。R46主未来查询规则未通过两个自然面板的强基线条件，停止，不扩掩码、层或训练网格。本轮只补齐一个尚不完整的比较：在相同默认可用长历史下，使用现成的固定填补修复最近192点目标缺口，是否比纯原生长输入更准确。它是固定基线补充，不预设为新算法或此前主方法成功。

保留北京231和HDB83任务，原8192上限、实际可用历史、变量集合、前缀单位、原H24/H96及未来评分位置。完全复用R45的native_long_prefix_peer输入。北京固定选已有KNN、Gaussian、local ridge、peer ridge四个简单统计/非参数控制，覆盖此前自然/人工面板中的有力对照；HDB使用R43原六个median、ffill、linear、seasonal24、knn、gaussian。此选择是开发后的基线补充，不是独立算法选择结果，也不声称补全所有神经填补器的长历史比较。

对每条已冻结填补目标轨迹，仅替换长输入最后192点的原缺失目标位置；原已观测目标值必须精确相同，全部更早目标历史和全部非目标变量保留原值及NaN。填补器不额外使用更早长历史，也不重新拟合。两类预测范围为原变量集合和仅目标，均使用同一修复轨迹及同一长区间，不提供真实未来或执行注意力/编码干预。

HDB原先只有KNN/Gaussian具有仅修复目标、直接预测原变量集合的短输入对照；其余短全变量版本还填了辅助列。为避免同时改变时间范围和辅助填补，本轮为HDB全部六个候选增加匹配的192点原变量预测，KNN/Gaussian须精确恢复旧target_knn/target_gaussian。该补充在任何新预测之前固定。

每个固定修复/范围给原0.5分位点输出及相同VAR各半控制。北京新增16方法，共266；HDB新增36方法，共159。保留R46全部旧输出，总74643窗口/136089目标分数。每例另重放两类原生长输入，验证变量范围与原R45查询一致。实际调用北京231×10、HDB83×20，共3970次前向，独立审计同量重放；没有新模型训练，上游已有生成成本仍保留。

启动前验证当前隐藏保护、填补源身份、只替换当前目标缺口、原观测/更早历史/非目标保持、目标范围与全范围的同目标轨迹一致；小批不评分。全部输入和完整预测冻结后才评分，独立重放及原输出要求逐值一致，指标和聚合1e-12。失败不按结果删任务或另挑填补器。

结果分别报告六面板及各站/车场，比较同长原生、同修复的短预测和已有强固定/适配控制，MAE/MSE都保留。更多历史/既有填补的组合即使取得较低误差，也只能先认定为更强基线；不能凭此声称ICLR方法贡献。后续汇总应清楚区分有效控制、被否定方案、当前未解决问题和未用确认数据。

HDB只使用前672小时开发数据，后两个336小时段未评分。两个已用来源、相关站点和多轮选择限制仍在；此次不做新确认。正式运行每30分钟检查一次，9月18日起不新增实验。
