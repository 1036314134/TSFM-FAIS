# 分开计算已知偏移与学习教师残差投影

当前统一三候选规则在完整开发面板上得到 Chronos 0.776350/1.553672、TimesFM 0.760947/1.520308，均超过相同七查询条件的预测中位数；Chronos 的改善仍小。新检查保持预测缓存、33 个输入特征和源完整历史教师，比较三个相同容量的回归目标，不新增预测器调用或读取确认结果。

记七候选预测的逐坐标中位数为 m，候选变化为 v_j=p_j−m，教师残差为 e=F(X_complete)−m。内积以预测坐标数 q 归一化，n_j=√〈v_j,v_j〉。候选相对 m 的教师平方损失恰为 n_j²−2〈v_j,e〉。n_j² 完全可见，只有第二项涉及当前无法获得的完整历史。拟学习单位方向投影 u_j=〈v_j,e〉/n_j，零变化候选取零；推理时以 n_j×预测的 u_j 重建线性项。对照直接回归相对教师风险 d_j，再以 (n_j²−预测的 d_j)/2 重建同一线性项；中间对照直接回归未经单位化的投影 b_j=〈v_j,e〉。这样区分保留已知平方项与目标单位化的作用。三者使用同样的一个 160 棵树回归器、33 个特征、7 个候选标识、家族权重及已固定树参数，共 90 个家族折。

输出在 m 与七个候选预测的凸组合中选择，m 不额外调用预测器。给定权重，估计目标为 wᵀGw−2bᵀw，G 由实际候选预测变化的内积精确计算，b 由上述回归器估计。Chronos 对完整联合目标共用权重，TimesFM 对目标分别求权重。8 个顶点的单纯形逐面求解，保留非负性、和为一以及归一化对偶间隙不超过 1e-7 的检查；原始单位的对偶间隙另存。数值最优只涉及估计目标，不保证实际 MAE/MSE 改善。

动机是有界回归器在候选偏移超过源数据范围时难以外推平方项。一个受限例子中，锚点为 0、教师为固定 μ>0、单个候选为 a；真实相对风险为 a²−2aμ，单位投影为 μ。若直接风险估计保持有界，估计最优预测会随 a 增大而接近 a/2；若单位投影估计保持在 μ 附近，预测保持在 μ 附近。该例子假定教师残差有界。当真实变化或教师残差也随 a 增大时，投影回归同样可能失效；不能用这个例子保证真实预测更准确。

平方损失的组合恒等式和利用预测分歧优化权重已有先例，例如 [Krogh 与 Vedelsby，NIPS 1994](https://proceedings.neurips.cc/paper/1994/hash/b8c37e33defde51cf91e1e03e51657da-Abstract.html)。这些通用公式不是本文的新贡献。此检查只检验在完整历史教师监督和冻结预测器的缺失输入任务中，分开已知平方项是否比同容量的直接风险回归更有效；方法新颖性仍需进一步核查。

三个回归目标拟合时均只读取源训练的完整历史教师；验证权重和预测先保存，之后再读取当前未来评分。每组保留全部 1872 个开发任务及单独的 90 任务面板，复现预测均值和中位数强对照，并与已经完成的三候选方法比较。确认集继续封存；若没有相对强基线的双指标改善，不把数值优化成功当作方法成功，也不扩大此原型的规模。

90 个折及独立数值复核已完成，16848 个决策的估计和指标复现，差异均为零；最大归一化对偶间隙为 2.24e-11。Chronos 的直接风险、原始投影、单位投影分别为 0.797182/1.605342、0.784091/1.555673、0.780535/1.552932；TimesFM 分别为 0.780944/1.585802、0.771205/1.534810、0.767362/1.520226。两个分解步骤均改善相同容量的直接风险回归，但单位投影与已完成的三候选排序相比只保留很小的 MSE 取舍，MAE 较差。该原型不作为独立确认的主要方法，也不再扩大；其作用限于说明直接估计风险和保留可见平方项之间的差别。
