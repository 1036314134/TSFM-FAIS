# R40：填补可信度与冻结注意力的有限机制检验

2026年9月17日，R39停止后登记。本轮只检验当前库内尚未做过的注意力干预，不延续失败的固定组合权重搜索。R21只改输入编码标记，R34只改统计，R37只传播编码矩，均未改注意力。Chronos-2的本地实现以块内是否存在观测构造硬掩码，先做时间注意力再做组内变量注意力；完整填补通常令历史块全可用。[官方实现](https://github.com/amazon-science/chronos-forecasting/blob/main/src/chronos/chronos2/model.py)

缺失不确定性用于下游注意力已有先例。UASA包含填补及下游预测并联合训练，不能把“用不确定性调注意力”本身称为新颖性。此次检验的是已冻结预测器上的固定条件方差规则；训练状态不同也不足以单独证明论文贡献。本轮没有完整复现UASA，不将其列为已战胜的基线。[论文及出版记录](https://ora.ox.ac.uk/objects/uuid%3A245d573e-5d12-4348-9820-6799258b471e)

固定使用北京R38全部231任务及HDB R39全部83任务。两来源组及各自三个面板分别报告，不合并成掩盖退化的主平均。HDB仅前672小时开发数据，后28天继续未评分。完整复用北京146个、HDB31个旧输出及各自原始前缀、peer、标准化和Gaussian填补。输入长度192，原跨度不变；HDB原生336控制继续保留。没有新的训练、模型下载或候选筛选。

对原静态模型协方差C0，令工作先验S=C0−1e-6 I，保持R37对求解正则的解释。在每个历史时点，已观测单元可信度r=1；缺失单元的条件方差V由S_MM−S_MO(C0_OO)^(-1)S_OM得到。定义r=clip(1−V_ii/S_ii,0,1)；S_ii不大于1e-12且原缺失时r=0。每16点块取r平均。该量是线性Gaussian模型的方差解释比例代理，未校准为填补正确概率、潜表示后验或下游误差保证。

主gaussian_conditional_attention使用与原静态Gaussian填补逐值相同的输入、归一化、时间和有效值编码。每层时间注意力和组注意力在原可用键上增加log(r_patch)，r=0的键使用原硬屏蔽极小有限值；原来不可用或不在同组的键保持屏蔽。REG及未来查询键的权重固定为1，其他未来编码不变。若某个组注意力查询行所有原可用键的r均为0，则保持该行原掩码，避免零质量归一化；记录这类回退，不声称彻底阻止所有不确定信息传播。权重在各层固定，未根据中间表示重新估计。

七个机制控制为：仅时间注意力、仅组注意力、用原观测比例代替条件可信度、将块可信度沿时间循环错位一块、原生NaN输入仅按观测比例干预、Gaussian输入仅改原观测编码字段、Gaussian输入同时改原观测字段与条件可信度注意力。最后两项构成与原填补/仅注意力的2×2比较，均不改变数值和统计。错位控制保持每通道块可信度多重集，不解释为缺失机制的随机试验。

8个新点输出分别另配同一个旧VAR各半控制，作为北京先前强组合的匹配比较，HDB失败的各半组合仍保持原身份。北京共162方法、37422窗口/74844目标分数；HDB共47方法、3901窗口/目标分数，总41323窗口、78745目标分数。主方法固定为未加VAR的gaussian_conditional_attention。两自然面板各自比较同输入Gaussian、各自已有的原生/长历史控制、最强固定组合以及新机制控制；北京原生为192点，HDB另有336点控制。辅助面板、MSE及所有负结果完整保留。不能事后改主身份为组合、原观测比例或仅某来源的赢家。

每任务8次干预查询，外加解除钩子后的Gaussian和原生普通预测核验，共3140次实际基础模型调用，完整审计另重放同样数量。主方法部署仍是一次基础模型调用加局部条件方差计算。保留实际输入、完整分位、原/新注意力掩码、原观测编码字段及参数摘要。普通恢复与正式预测重放要求逐值一致；独立条件方差r检查rtol1e-9/atol1e-10，浮点log掩码参考rtol1e-6/atol1e-6，全部指标1e-12。禁止为通过检查放宽界限。

先验证全可信度恒等恢复、原屏蔽不开放、未来/REG不变和无证据行处理，再运行未评分小批。若主方法在两来源自然面板无法形成强基线之外的稳定MAE增量，停止该固定规则，不扩注意力温度、层选择、可信度阈值、错位或训练网格。若有机制信号，仍须新增方法论证和未用确认；本轮不能证明ICLR投稿水平已达成。正式期间半小时检查一次，9月18日起不新增实验。
