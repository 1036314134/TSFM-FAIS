# 输出集合示意图

图件是第四节解析例子的辅助说明，不替代引言中的真实电力数据例子，也不属于实测结果图。左右面板使用同一预测映射 F(a)=(a,a²)、同一 Z 的均匀分布及相同坐标范围，只改变实际未来 Y。它说明输出集合之外的预测不自动意味着更低的真实误差。

灰色曲线表示允许填补得到的预测，蓝色菱形表示预测均值，空心圆表示 MSE 下最优单次填补的预测。两面板均给出真实未来定义、两个预测坐标轴和精确 MSE。颜色与点形共同编码，保持黑白阅读时的可区分性。图由 TikZ 生成矢量内容，正文内不使用缩放，标注字号为 8 pt，面板标题为 9 pt。

四个风险值直接来自已完成的精确积分例子及预测器失配反例。它们使用例子本身的单位，与实验数据的前缀标准化成绩分开。图注明确区分解析说明和真实时序预测器的证据。
