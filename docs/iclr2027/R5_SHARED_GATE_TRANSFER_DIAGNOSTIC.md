# Fixed shared-gate transfer diagnostic on used data

The completed source study supports retaining the actual-ensemble-loss condition over its identical member-loss control: both MAE/MSE improve for both forecasters. The source means also improve against the seven-candidate median and source-fixed convex weights. Compared with the previous 35-triple classifier, the new gate improves TimesFM by about 0.62%/1.54% but worsens Chronos by 0.86%/0.13%. This is mixed development evidence and does not establish overall superiority.

Keep the architecture, 25-epoch schedule, three seeds and both objectives exactly as in `R5_SHARED_FORECAST_GATE_PLAN.md`. Fit all 12 final seed models on only the original 165 source training histories in 15 families. Save the complete source bundle before reading target feature tables or generating predictions with these gates. No target observations, validation examples or actual source future outcomes enter fitting. The primary output remains the average of all three seed weight vectors; no backbone-specific switch to another architecture is introduced.

Apply the two frozen gates, source-fixed convex weights and source-fixed single to the existing seven forecast candidates for all 823 previously evaluated tasks. Reuse the audited 33-feature tables and original predictions. Retain the 18 existing method outputs, including the MoTM supplement, for 22 total methods. All masks, prefixes, target variables, forecast horizons and panel definitions stay the same. Check the gate forward pass against independent matrix replay and verify unchanged methods reproduce their old scores.

These 823 tasks informed earlier method development. This run is therefore a transfer diagnostic on used data, not independent confirmation. It is intended to decide whether the unchanged small gate merits new evaluation data, rather than to tune its settings on these tasks. Both metrics, both forecasters, natural and artificial missingness, the old three-candidate selector, simple individual methods and the modern-imputer comparator must be retained. A promising result still requires an unused cohort and a separate final-method freeze before an independent performance claim.
