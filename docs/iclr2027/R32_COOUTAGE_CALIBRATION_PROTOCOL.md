# R32：成组停报的预测监督机制检验

2026年9月17日，读取并核验R31结果后登记，属于新的开发实验。R31主模型自然面板失败，源训练的辅助观测比例未覆盖90个自然目标行中的81行；冻结门控对该特征敏感。R32只检验这一具体解释是否能够产生强基线以外的下游增量，不重新搜索门控容量、特征、学习率或种子，不把数据增强本身宣称为新颖贡献。

保持R31原96个校准历史起点、每起点6/24/54小时三个缺测长度及全部历史真实未来不变。在每个任务上构造三个预设观测干预：targets_only只隐藏本地两个PM目标；local_pollutants隐藏本地前六个污染物通道；regional_pollutants进一步隐藏六个附加peer通道。遮蔽只作用于最后对应长度的历史，气象等原辅助观测保留，原本缺失的值不会被补成真值。共864任务，只有96份不同历史与未来，不计为864个独立样本。两个PM的人工隐藏历史仍是填补监督标签，其他被遮蔽通道不加入监督损失。

R32沿用R31前3506小时选择的peer、尺度、回归与已经拟合的神经填补器。SAITS与TimeMixer++使用原512训练窗口/最多50轮/batch16/seed0产物，不重训、不增加原始标签范围。源学习至7012小时结束；部署仍用R30原全前缀专家和相同的93个H24评价历史。当前评价样本的数值和未来不参与构造训练干预；干预定义来自前六列的已知变量类型及明确的区域信息缺失假设。该假设尚待真实故障元数据支持，不把观测模式直接等同于已认证的设备故障。

主forecast_gate、imputation_gate及fixed_input_mix保持R31的97/97/2参数、10维输入特征和损失定义。seed5101，AdamW lr0.01、wd0.001、梯度上限1，均从原初始化重新训练。固定只遍历864任务一轮，仍为864次更新，与R31三轮288任务的更新和真实未来标签预算相同。顺序是该种子对864个任务的一次打乱。该比较改变观测干预分布和样本重访安排，不伪称两轮的逐步优化轨迹相同。

同时重算全部25项基础校准预测并重新拟合全局/逐站MAE固定凸组合，保持任务内观测归一化及1e-7原始/对偶检查。0.5输入/输出组合和R30全部37个控制保留。R32表仍为44输出、4092窗口/8184目标分数；R31七项新增方法的既有文件完整保留并在跨轮报告中比较，不覆盖原负结果。预测冻结之后统一评分，MAE为主，MSE完整报告。

主自然45任务、人工辅助48任务分别按站点宏平均，保留逐站排除分析。继续条件是主方法获得peer/local ridge、KNN、SAITS、同容量填补监督、固定输入和同训练干预固定预测组合之外的稳定增量；仅修复R31的退化不足以建立方法贡献。若仍达不到则停止本次成组遮蔽设计，不继续枚举缺失组合、年龄、种子或训练轮数。数据支持缺口、变量类型与新作用机制的结论分别表述，不从这次开发推导真实故障成因。

复用数学实现但保留R31已冻结脚本，R32使用单独版本并保存相对原版本的修改记录。正式准备、校准预测、学习、评价预测、评分与核验全部完成后才分析效果。核验包括三种掩码的逐单元重建、原标签保护、前缀与神经产物身份、固定组合最优性、优化器末次更新、全部源/评价预测和指标。正式运行期间每30分钟只紧凑检查一次，短诊断与修复及时执行。仍无独立确认或投稿质量保证。
