# 冻结预测器表示的源端结果

本轮在北京时间2026年9月14日20:58完成。原定3,906个输入全部采集，独立审查核对46,730个有效输入缓存、384个学习器检查点和61,776条决策评分。预测独立重放最大差为1.07e-14，固定凸组合最优性最大差为4.31e-16。结果来源为 artifacts/iclr27-r7/latent-source-audit-v001，实验协议为 R7_LATENT_SOURCE_PROTOCOL.md。这里的15家族和52验证历史属于已使用的源开发数据，只有一个掩码种子；三种学习器种子不构成三个独立数据集。

各项数值均为训练前缀标准化后的下游MAE/MSE。按照原协议先平均目标，再平均家族内部输入，最后对15个家族等权。主条件预定为 latent_future，不能根据本轮表现改为另一监督目标。

主条件相对同监督点特征对照，Chronos的MAE/MSE增加约1.55%/4.83%，TimesFM增加约2.49%/3.21%。家族层面，Chronos双指标改善2个、双指标退化13个；TimesFM分别为5个、7个，另3个存在指标取舍。教师监督下加入表示也未降低任何一个预测器的总体双指标。不能据少数家族的改善认定此表示有可迁移收益，本轮不进入昂贵的目标数据表示采集。

这组比较只能说明当前固定投影、汇总方式、样本量和学习日程下的结果，不能证明预测器所有中间表示都无效。现有24个完整源模型尚未用于同家族后续时间验证；这一低成本诊断可区分已见家族上的时间泛化与本轮跨家族结果，具体范围另记于 R7_LATENT_GENERALIZATION_PROTOCOL.md。其结果仍属于开发诊断，不补充独立确认，也不能单独归因于领域变化，因为留出家族时训练人口也变化。

统计解释核对覆盖11项：家族结果存在异质性，因此保留总体与家族值；不从家族平均推断每个历史；源人口固定但具有选择范围限制；没有按模型结果控制共同结果变量；分类基率问题不适用；没有挑选极端历史开展前后比较；预定输入与模型均完成，未丢弃失败条件；四条件、种子和固定控制全部保留，不做选择性显著性陈述；本轮及后续诊断明确为开发分析；不作因果归因；未来标签的训练与验证用途分开记录，不作反向因果解释。未计算p值或置信区间，不宣称统计显著。本轮负面结果保留，论文投稿证据仍不足。
