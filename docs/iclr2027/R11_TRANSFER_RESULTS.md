# 目标级选择的迁移结果

第二次短迁移评估完成54,672条评分，预测重建最大差1.07e-14、指标重算差零；TimesFM目标特征与原模型别名全部复现。第一次评估的共享对照浮点差异通过单次上下文推断处理，未改主方法或模型参数；详细诊断见shared-inference-diagnostic-v001。

Chronos人工缺失H96，scope_target为0.611080/1.123876，scope_broadcast为0.608894/1.129633，出现MAE退化与MSE改善；按目标固定组合为0.599119/1.083132，优于学习选择器。旧七家族原始缺失上，target为0.614951/0.810056，弱于broadcast的0.611778/0.805503及八候选中位数0.609386/0.797358。北京原始缺失上target为0.954296/1.946266，有小幅改善，但不能代表其他原始缺失来源。源端改善未稳定迁移，不将这一变体提升为统一主方法。

TimesFM沿用原R10联合目标模型，人工缺失为0.582252/1.065021，旧原始缺失为0.618077/0.801955，属于明确标记的复用结果。全部面板、跨度、种子和原比较保留于artifacts/iclr27-r11/target-local-transfer-v002。

下一项候选池对齐试验保留R10决策单位与联合目标，使学习器和强中位数基线都包含MoTM。此前学习器使用七候选，而部分强基线包含第八个MoTM；这一对照需要在同候选池内完成。增加候选自身不作为新颖性，也不预设泛化收益。
