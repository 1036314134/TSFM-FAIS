# 原始缺失训练扩展结果

2026-09-14。八组留出的训练扩展及独立审查已完成。增加其他组的原始缺失历史后，Chronos对原源真实未来门控的宏平均MAE/MSE均有小幅改善，TimesFM则均略有退化；相对强静态控制仍存在指标取舍。本次不升级主方法，也不能据此断言更多原始缺失训练数据普遍有效或无效。

试验保留原15家族、165个源训练历史，并从另外358个原始缺失历史中排除整个评价组后训练。九个既有家族组成八个留出组，新加坡的两份数据一起排除。每折使用同一33维门控、25轮训练和三个固定种子，并拟合同样本、同损失的固定凸组合。评分使用训练前缀标准化后的真实未来观测位置，目标等权，再按序列、数据集和家族汇总。以下“扩展门控”是不同留出组模型的交叉验证结果，没有拟合一个用于所有评价家族的统一模型。

旧七家族上的两项指标在两个模型中都略优于原源门控，但均未超过八候选中位数。R6北京原始缺失192历史上，扩展门控C=0.954420/1.946468、T=0.980024/2.047683；七候选中位数为0.956488/1.953139和0.978526/2.041793，两个预测器的排序不同。自行车只有两个原始时间网格缺口历史，扩展TimesFM相对原源门控退化，不将该小子集的幅度解释为总体规律。

八个留出组等权的预定敏感性汇总为：扩展门控C=0.635045/1.006868、T=0.638085/0.945991；扩展固定组合为0.634677/1.010990和0.636861/0.947147。TimesFM在这一汇总中对扩展固定组合的MSE较好，但MAE仍较差；九家族汇总则两项均较差。两种口径均保留，不能事后挑选有利的一种。

独立审查重建全部输入，验证48个新检查点、13,962条决策级评分、整组排除、输入统计和固定权重最优性。预测重建最大差异2.66e-15，评分差异7.11e-15，直接最优性差1.80e-15。v001因旧基线批次重放差异停止；v002复用原审查缓存，原24个Chronos模型的全部状态张量完全复现，旧基线评分重放差不超过4.44e-16。详见 `R6_NATIVE_REFERENCE_NUMERICAL_NOTE.md`。修复没有改变训练方法或放宽阈值。
