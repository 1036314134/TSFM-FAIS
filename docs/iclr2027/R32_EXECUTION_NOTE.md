# R32 执行与复用记录

R32在正式启动前通过16项针对性测试，覆盖三种观测干预与6/24/54小时三种长度的逐单元遮蔽、未来值隔离、父任务对应关系，以及沿用的梯度、固定组合与原观测保护检查。完整小批包含两个站点的6个源任务和4个评价历史，仅核验预测重放，不评分小批评价结果。

首次小批的完整核验通过，但额外的跨轮输入一致性检查发现：重新加载同一个TimeMixer++产物后，某个未改变的源任务有10个候选填补单元与R31重算结果不同，原量纲最大差8.66e-5；其他候选、统计修复、尺度、特征和训练样本一致。此记录保存在base-reuse-diagnostic-v001.json，不据此判断预测误差，也不将原因扩展为已证实的特定后端问题。

正式实现将targets_only条件的候选数组直接从R31冻结文件复用，并逐数组核对上下文、回归修复、特征及其他字段。两个新增条件使用同一已拟合基线产物重新填补。准备和核验程序均验证神经模型记录、原训练批次与父输入身份；复用记录中的历史填补耗时不能累加为本轮新执行耗时。首次小批、脚本快照、修改记录及修正后小批均保留，正式方法、超参数、标签范围和容差没有变化。

R32通过独立文件版本保留R31已执行实现，新增版本的逐文件差异和父文件身份记录在variant_derivation.json及对应diff文件中。成组可用性干预、一次864步训练安排和基线复用是明确的版本差异，不将它们写成原R31实验结果。
