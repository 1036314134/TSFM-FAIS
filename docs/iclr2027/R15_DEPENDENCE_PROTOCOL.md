# 保持期望预测风险的未来相关性干预

2026年9月15日，在R14完成并独立核验后登记。复用R14的36个独立历史、180个观测输入、八种候选填补和Chronos/TimesFM冻结预测；不重新拟合填补器或调用预测器。源文件、预测、R14读出及审查结果均绑定校验值。本轮仍是已知生成过程的受控模拟，复用历史不计为新独立确认。

固定未来创新标准差乘子为1。设给定实际观测历史后的标准化未来为Y，条件均值为mu，完整时间与目标协方差为Sigma。取rho为0、0.5、1，构造Sigma_rho = rho Sigma + (1-rho) diag(Sigma)。所有条件均值和逐坐标方差不变，因此任意仅依赖相同历史的固定点预测或固定组合的期望MAE/MSE严格不变；期望风险排序、条件最优单候选及MSE凸组合亦不变。rho同时改变时间及目标间依赖程度，不将其当作每一对坐标共同的相关系数，也不将干预后的未来宣称为原AR过程的平稳延续。

每个观测输入仍用512个条件未来。rho=1逐值复用R14标准差乘子1的抽样，rho=0使用种子future_seed+500000产生具有相同逐坐标方差的独立高斯残差。中间条件取mu+sqrt(rho)*(原相关样本-mu)+sqrt(1-rho)*独立残差。两个残差流独立，三个条件配对复用。分析七/八候选池；Chronos联合两个目标，TimesFM分别选取两个目标，保持原决策单位。共3240个决策条件行，未来副本、掩码、rho和目标不能作为额外独立历史。

主要比较为rho变化时配对事后选优偏差的变化，同时核对所有候选的解析期望MAE/MSE、条件最优权重及同面板固定候选风险保持不变。保留事后单候选及凸组合在同一未来上的误差和在独立未来上的解析风险。主要报告八候选，七候选为控制；完整历史预测完全相同，事后偏差应为零。既报告各过程结果，也报告对目标、过程等权的均值。均值之比与过程内比值的均值分别命名，不能混用。

对每个候选与期望MSE最佳候选的预测差delta，记期望风险差为d，预测坐标数为Q。实际MSE排序反转等价于2*(Y-mu) dot delta / Q > d。该高斯投影方差为4*delta^T*Sigma_rho*delta/Q^2，对应概率为Phi(-d/sqrt(v))，零方差时严格反转概率为零。该等式和高斯计算属于标准推导，不作为新理论。读出使用反向状态递推求投影方差，审查使用完整稠密协方差独立重建。样本方差及反转概率用512条完整未来轨迹核对，标准化偏差超过10即失败，不据其筛选有利结果。

审查须重建选择、配对收益、解析期望、独立未来风险和所有凸组合的单纯形可行性与直接梯度最优性。凸组合阈值仍为1e-7；直接风险重建误差阈值1e-10；rho=1与R14乘子1的共享数值字段须在rtol/atol均为1e-10以内复现并报告最大差值。跨rho候选期望风险和条件权重要求逐值一致。文件覆盖、种子、过程参数及标准化边界均须核对，不能修改已完成R14产物。
