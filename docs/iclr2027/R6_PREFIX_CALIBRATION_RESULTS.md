# 固定前缀教师校准的结果

2026-09-14。试验与独立复核已完成，当前不支持将该校准作为双预测器统一改进。43 个完整前缀历史、774 个遮盖输入和 45 组目标决策权重均核验通过，8 个校准用神经填补模型全部拟合成功。直接教师残差的最优性检查最大差异 3.19×10⁻¹⁶；教师指标重放差异 1.11×10⁻¹⁶。30,440 个方法—跨度—输入的下游评分完成，预测重建差异不超过 2.67×10⁻¹⁵，标准化指标独立计算差异不超过 5.33×10⁻¹⁵，原固定组合和中位数分数重放不超过 8.89×10⁻¹⁶。

| H96 人工缺失结果 | Chronos-2 MAE / MSE | TimesFM 2.5 MAE / MSE |
|---|---:|---:|
| 原源固定组合 | 0.600751 / 1.109923 | 0.616414 / 1.148950 |
| 前缀教师校准，各半收缩（预定主输出） | 0.614169 / 1.126436 | 0.610681 / 1.116069 |
| 前缀教师校准，不收缩 | 0.632034 / 1.170204 | 0.610774 / 1.117264 |

主输出使 Chronos 的两个指标退化，TimesFM 的两个指标改善。但 TimesFM 相对原成员目标门控仍是 MAE 较差、MSE 较好的取舍。逐来源看，主校准在两预测器的 Bike 上双指标改善，在北京上双指标退化，在 Appliances 上 MAE 退化、MSE 改善；Occupancy 的方向则随预测器变化。不存在四个来源一致的双指标改善。

H192 沿用 H96 权重后，主校准 Chronos 为 0.642142/1.191903，相对源固定 0.630231/1.179018 仍退化；TimesFM 为 0.654603/1.234683，相对源固定 0.659963/1.266592 仍改善。北京原始缺失 H96 子集的主校准 Chronos 为 0.954595/1.948990，存在轻微 MAE 改善与 MSE 退化；TimesFM 为 0.978922/2.041206，两个指标略优于源固定。H192 原始缺失差异更小且有指标取舍。

证据位于 `artifacts/iclr27-r6/prefix-calibration-results-v001`。这是已经查看 R6 后登记的方法开发试验，不能称新的独立确认。不通过调整收缩比例、只保留 TimesFM 或筛选有利来源改变这一结论。尚未分离的原因包括教师与真实预测目标的差别、历史变化及校准用/部署用填补器拟合区间不同；当前结果不能单独证明其中某一原因。

直接相关的下一项对照仅复用已有预测缓存：在教师与过去真实未来标签均可用的共同历史集合上，用相同候选、相同观测位置和相同各半收缩分别拟合权重。该对照用于判断教师信号的作用，不增加新基础模型调用，不扩展超参数网格。论文目标仍未达到。
