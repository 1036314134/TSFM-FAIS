# 冻结预测器内部表示的接口检查

2026-09-14。在区间字段的源端增量对照仅出现小幅指标取舍后，先检查本地预测器是否提供可重复读取的内部表示。当前门控主要使用手工摘要；这些摘要是否遗漏了有用信息仍是待检验假设。此接口检查不构成准确度实验，不证明内部表示更有用，也不决定大规模特征收集或学习器结构。

只使用原源训练中的首个ETTh1输入和首个Coastal_T_S_H输入，各取LOCF与线性插值两个已经缓存的完整候选历史，共四个输入。两种维数同时覆盖常规输入与此前Chronos维度歧义涉及的三变量来源。每个预测器依次执行两次普通预测、两次带只读表示采集的预测；TimesFM另作一次第二目标扰动检查，共33个需要完成的单候选请求。每个请求原子保存并绑定模型、输入和运行定义，恢复时只复用已完成的同一请求，普通重复与采集重复必须对应独立请求。资源中断后的额外尝试单独记录；请求尝试在调用前登记，因此异常边界可能有尚未实际调用的记录，不能当作精确完成调用数。主机批次填充和双符号推断的内部工作量另记，不能把请求数解释为底层算子调用数。

沿用已审查的冻结运行器、模型权重、L=H=96和两个原目标。只在Chronos的output_patch_embedding输入以及TimesFM的output_projection_point输入读取张量。读取不修改张量或输出；普通重复预测、带读取的预测和表示重复必须完全一致，模型参数在前后相同，张量须有限。Chronos记录各变量的未来块表示；TimesFM记录含批次填充的两个符号分支，并验证第二目标扰动不会改变第一目标的预测及相应表示。不同模型的这些表示语义不同，不能直接声称它们已经是同一种可比较特征。

保存原始表示、点预测、模型和输入绑定、形状与重复性检查；不读取真实未来，不计算MAE/MSE收益，不训练新选择器，不修改任何已冻结预测或模型实现。输入源和两个原目标已被使用过，因此也不作为新独立确认。

该候选方向要求本地模型权重及可读取的中间张量，区别于仅提供预测输出的接口条件。若接口检查通过，后续仍须另行明确特征汇总方式、源监督、容量匹配及独立评价，才能判断是否值得采用。保留当前所有point-only和静态基线。

仅通过第三优先级守护队列执行。前两项工作及其数据准备优先；当前RECA复制任务存在时只保留等待程序，禁止提前加载模型或占用GPU。当前检查先于任何大规模内部表示收集。
