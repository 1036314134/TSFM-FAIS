# 预测输出决策粒度对照

本阶段使用原 R4 的 1872 个开发任务，比较预测输出层的决策粒度。候选仍为六种填补加原生缺失回退，共七条预测轨迹；所有输入流程和训练前缀标准化后的 MAE/MSE 均保持原口径。

固定考察整段 96 步、八段各 12 步、96 段各一步。每一段只依据当前七候选预测的逐坐标中位数，选择与其中位数平方距离最小的候选，并保留该候选在整段上的真实预测值；不读取实际未来。分别比较两个目标共同选择和两个目标分别选择。该步骤是预测输出组合，尤其对联合预测的 Chronos，组合结果不保证对应某一个填补完成的上下文，不能作为单次填补方法报告。

细化区段能够保留原粗区段的选择，因此最小共识距离应不增；但实际预测 MAE/MSE 没有同样保证。七候选是奇数，每步、每目标分别选择时应逐值恢复预测中位数。这两个性质及共同目标/分别目标的区别已通过三个专项检查。程序还核对中位数成绩是否复现原 R4 结果。

比较结果用于判断当前整段选择与强预测中位数之间有多少可观测差异来自输出约束，不能把共识距离当作实际风险的下界，也不能由更多细粒度决策自动推出更好的可学习策略。选择规则和区段数在查看本阶段结果前固定，没有新增预测器调用、模型训练或确认集评价。执行继续遵守第三优先级。

已完成全部 1872 个任务、两个模型及六种粒度/目标组合。逐步且分别按目标选择时，与七候选预测中位数逐值相同；原 R4 中位数指标也复现。Chronos 的共同目标整段共识选择为 0.788896/1.582665，八段为 0.785309/1.570073，中位数为 0.780606/1.558757。TimesFM 的分别按目标整段共识选择为 0.778565/1.571527，八段为 0.774918/1.562172，中位数为 0.772570/1.555558。所有结果保存在 `horizon-consensus-v001`。

更细粒度规则接近但没有超过预测中位数。Chronos 的整段共识选择在两项指标上优于当前成本敏感选择器，因此该学习器与中位数的差距不能全部归因于整段输出约束。TimesFM 的成本敏感选择器相对同粒度共识选择呈现 MAE/MSE 取舍。当前结果支持把精确共识选择保留为重要对照，不能由此断言单次填补普遍不足或新的学习策略已经成立。
