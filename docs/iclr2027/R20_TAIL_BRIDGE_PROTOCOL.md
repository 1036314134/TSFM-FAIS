# 探针B：末端缺失时移动预测起点

2026年9月15日，R19未通过继续条件后登记。只检验固定新动作，不训练选择器、不增加新填补器、不恢复R18。对当前长度L=96的历史，按预测器实际输入范围确定连续末端无观测长度g；g在1到48之间时，保留原窗口内前96-g步，从较早边界预测96+g步，取后96步作为当前未来预测。保留内部缺失和时间格点，不向更早时点补入观测。

Chronos联合使用全部通道，仅在末端所有通道共同缺失时移动起点。TimesFM按目标独立处理，分别计算各目标g；g=0或不满足范围时保持原96步原生回退预测。这样不会因Chronos目标缺失而丢掉仍有近期观测的协变量。两模型的可用事件范围单独报告。

预检查已有R5/R6自然缺失窗口得到11个g为1到48的共同通道停报事件，覆盖合并后的5个来源组；它们是两模型的主要真实配对面板。TimesFM共有17个可处理的目标末端缺失窗口，其中新增6个单独报告，不与共同面板混称。原神经填补拟合窗口的日历截止均早于这些当前历史窗口。全体事件在读新预测误差前固定，不挑有利g或来源。这些均为已用开发数据，不是独立确认。

补充人工机制检查：从R19已登记的完整历史锚点中，按4个来源组各取3个不同历史，组内先轮流序列再按时间，合计12历史。各自遮盖全部通道的最后8、24、48步，共36个输入、两个预测器72个桥接任务。它们本来是R19历史验证数据，须如实标记复用。完整观察的对照只用于核验g=0的时间对齐，不当作方法优势。

保留原八候选及其原生回退、均值/中位数、源MAE最佳固定单候选、MAE固定组合和原源联合固定组合。所有候选采用与当前原生数据相同的冻结前缀产物、标准化和观测保护。人工输入需重新计算填补候选；自然输入同样重算并与原缓存核对，以保持本轮计算路径一致。MoTM网络不更新，上下文优化记入成本，传统统计重建与神经产物加载分别记录。

关键预算对照：对每个当前八候选输入，除原H96预测外，还请求与桥接相同的96+g输出，并取前96步。它与桥接具有相同的请求输出跨度，但预测起点和输入组织不同。不能以仅请求更多输出带来的变化归因起点调整。TimesFM逐目标g不同，其原点不动的预算匹配预测也逐目标采用对应跨度。所有有效输入、目标索引、跨度、截取区间与模型版本均进入缓存身份。

主动作bridge_native为原量纲原生处理；输出按原观测训练前缀均值和总体标准差评价，MAE为主，MSE完整报告。主要比较为共同真实面板上bridge_native对原八候选中位数及输出预算匹配中位数；同时保留最佳源固定动作和全部单候选，避免仅胜弱基线。模型/来源方向、尾部长度与事件数分层呈现。若只在人工遮盖有利，保留为机制检查；若不能稳定胜强固定动作，不扩大候选池或训练选择器。

全部输入和事件在预测前冻结，全部桥接/基线预测在当前未来评分前冻结。审查重建g、保留观测集合、预测时刻对应、输出切片、模型参数、原生回退、相同跨度对照、共同评分掩码及汇总。先测小批不同跨度的重复一致性与吞吐，再执行全量。逻辑桥接任务、独立目标请求、去重输入、实际forward批次、输出长度和墙钟分别计数。

范围限定：移动预测起点及跨度对齐属于常规预测操作，不能单独声称创新。只有固定动作出现可复现信号后，才检查是否值得纳入策略池、与扩展后的最佳固定动作及中位数比较，并补充相关研究核对。当前论文目标未达到。

准备、预测、读出、独立核验为正式阶段，第一优先级单核管理，不干预其他项目。运行期间只每半小时核对一次，未完成立即静默结束；短诊断和完成后的分析即时处理。A不再扩展，B无信号时不自动增加第三条研究路线。
