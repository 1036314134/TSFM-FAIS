# 条件期望风险监督的新增源样本

2026年9月15日，在R15核验后登记。目标是比较选择器使用精确条件期望损失和使用一次实际未来损失的训练效果，随后在已用真实数据上评价下游MAE/MSE。R14/R15的36个历史不进入新增训练人口。当前阶段生成并核验新增样本及冻结预测，尚不产生训练效果或投稿就绪结论。一般元学习选择和已知过程合成评价已有先例，本轮不预称新贡献。

使用十二个固定稳定线性高斯过程，分成对角AR三变量、循环耦合AR三变量、周期循环耦合AR七变量三组，各四个过程。对角组AR系数0.2/0.5/0.8/0.95；耦合组A为对应系数乘单位阵加0.03倍循环移位阵，系数0.2/0.5/0.75/0.9；周期组系数0.2/0.5/0.75/0.9，加0.04倍循环移位阵，周期12/24/48/96，周期幅度乘子0.5/1/1.5/2。每组创新方差为0.04，变量创新相关系数依次0/0.2/0.4/0.6。完整矩阵与种子由conditional_supervision.py保存并绑定，所有谱半径严格小于1。

每个过程具有独立6144步校准序列和20个独立初始化的96步历史；前16个历史作为训练，后4个作为验证，共192训练历史与48验证历史。每历史使用完整观测、30%/60%随机点缺失、30%/60%末端整块缺失，共1200个输入，训练960、验证240。未来跨度96、目标0和1，校准前缀均值和总体标准差定义报告量纲。校准、训练、验证随机流相互区分，不从已用真实数据重采样。过程编号、参数及精确条件分布只能生成训练标签，不能作为选择器输入特征。

保留八候选及原计算预算，每过程的SAITS和TimeMixer++只在其校准序列拟合10轮、64个固定掩码窗口，共24个拟合。MoTM公开网络保持固定，原上下文编码与ridge设置不变。四种传统填补与原生回退边界沿用已核验实现，观测值必须精确保持，任何候选失败都停止而非删去。Chronos保持两个目标的联合决策，TimesFM按目标决策；原预测器参数固定。所有候选及预测先冻结，再生成未来标签。

每个完整历史只抽取一次实际未来，并在五个掩码条件间逐值复用。该未来从已抽到的完整末态传播，不从各掩码条件分别重抽；因此保留同一实际时间轨迹对多个缺失条件的配对关系。另仅依据各掩码实际观测、过程参数和相位计算后验末态、未来均值及逐坐标方差。块更新与逐标量更新必须在1e-10以内一致。未知未来不进入填补或预测；这些精确均值/方差只用于训练监督及模拟分析，不进入部署输入。

冻结后构造原33个可见候选/预测特征，补64个零，与R12八候选97维、2121参数网络匹配。以实际未来、条件均值、条件方差三者分别保存标签；审查重新生成完整历史、掩码、实际未来、条件后验、全部特征、有效预测输入和标准化边界。所有候选预测与原参数校验值对应，完整观测的候选必须相同。标签与特征独立保存，训练索引明确排除48验证历史。

后续训练比较预定为三个条件：原165源训练历史加192模拟历史的条件期望监督、相同混合人口的一次实际未来监督、仅原源历史的更新次数匹配控制。主条件为条件期望监督，所有条件同一网络、候选池、三种子5101/5102/5103、AdamW学习率及权重衰减0.001、梯度裁剪1、批量128，更新次数等于混合训练人口25轮。保留原52源验证历史和新增48模拟验证历史，不据真实已用目标结果挑选新主条件。原源仍使用R12的MAE/MSE联合实际未来监督；模拟样本的联合目标使用真实MAE和MSE各半，期望版本对高斯未来解析积分，一次未来控制对应真实绝对误差。均值方差公式只用于已知模拟过程，不能声称真实未来可知。训练实现另作执行前核验，当前采集不提前声明学习效果。

读出必须保留同池均值/中位数/固定组合及原R12模型。后续迁移须明确标记真实目标数据已被多轮使用，不视为新独立确认。若期望监督只改善模拟而不改善真实下游MAE/MSE，不把模拟标签优势当作论文主准确度结果。

当前正式阶段为准备、冻结预测、构造标签与特征、独立核验；第一优先级单核管理，阶段上限3/3/1/1小时，不停止或修改其他项目任务。运行期间仅按小时检查，四阶段完成后立即进行登记的训练实施与核验，不额外等待一小时。短诊断和失败修复即时处理，原产物保留，阈值不放宽。
