# R46：过去证据与未来查询的注意力范围

2026年9月17日，在新增预测之前登记。R44表明去掉直接协变量在人工面板有利、在自然/H96可能有害；R45证明较长原生历史提高了比较基线。本轮提出可证伪的问题：保留全部过去协变量，只限制未请求的辅助变量未来节点作为注意力键，是否能取得额外预测增量。所谓未来节点是模型内部由时间位置和未知值标记产生的查询表示，不是实际未来测量；这里没有发现过去实验读取未来标签的证据。

Chronos-2现有实现把上下文、REG及所有变量的未来查询拼入同一编码器，并将未来注意力键默认置为可用。此次在临时钩子中改变注意力掩码，不修改输入、归一化、时间/有效值编码、模型权重或数值后端。R29曾复制Q/C输入角色并提供近期已知条件，未执行此次未来键干预；R40只改变上下文可信度权重，本轮不是继续其温度/阈值/层网格。[原架构](https://arxiv.org/abs/2510.15821)。注意力掩码和编码器/查询分离均为已有工具，不预设本实现的新颖性。

全部沿用北京231和HDB83任务。使用三个已冻结输入：原生192、静态Gaussian完整填补192、R45原prefix单位的默认可用长原生输入。R45原量纲/前缀单位的聚合差异极小，本轮固定前缀单位以匹配旧管线，不据评价任务选择单位。长历史上限8192、实际可用区间、变量集合、原缺口与标准化均保持。HDB后28天未评分。

主query_aux_both_native_long在每个编码器块中执行同一任务规则。时间注意力中，非目标变量行的未来键设为原硬屏蔽极小有限值；组注意力中，未来位置的非目标键同样屏蔽。目标未来键、全部历史及REG键保持原状，原有屏蔽从不打开。这样辅助未来节点仍被计算，但不能作为键影响其他节点，不声称节约这些节点的计算。目标集合只由既定target_count定义，所有episode仍在原同一组中，不使用新标签。

长原生输入另有仅时间、仅组两项分解控制。第三项read-only控制将全部变量的未来时间键屏蔽，并将未来位置的组注意力限制为各行自身，保留自变换而取消未来节点间交互；历史和REG仍不改变。它验证更强的计算图限制，不是根据准确度选择的另一主方法。短原生和Gaussian短输入只执行与主相同的双轴辅助未来键规则，用于观察输入表示的差异，不扩完整网格。

共6个新增点输出，各自另配旧VAR各半控制；主不加VAR。北京250、HDB123方法，共67959窗口、125709目标分数。每任务6干预加三个普通恢复，共2826次完整模型前向，审计同量重放。两来源自然面板及另外四面板分别报告前缀标准化下游MAE/MSE。所有R45默认长历史、目标单独、原填补与适配/固定组合均保留；主必须与这些强控制比较，不能只比同输入原生。

实现须保留原掩码张量布局和未改位置的数值，避免R40曾发现的中立数值差异。过去/REG掩码、输入字段及参数摘要检查必须精确。启动前以每种来源/跨度的首个小批任务验证计算图性质：声明全部变量为目标时主规则精确退回原模型；对辅助未来初始表示施加固定有限扰动，主规则及read-only的目标输出应精确不变；read-only增加一个输出补丁时，共有预测跨度应在事前rtol/atol=2e-5内相等。普通模型也执行相同扰动/跨度对照，但其变化不用于宣称原模型不合法或质量更差。该性质检查仅涉及输入和预测表示，不读取额外未来真值，也不代表统计风险保证。

性质扰动固定为0.125 sin(0.37j)的隐表示向量，只在预检辅助未来行使用，正式方法没有该扰动。每个性质任务固定6个额外前向：中立主、普通扰动、主扰动、read-only扰动、read-only加一个输出补丁、普通加一个补丁。小批选择北京H24、北京H96、HDBH24各一个，合计18个额外调用，审计重放这些记录。其他小批查询及正式同输入预测重放要求逐值一致，指标与聚合1e-12；不为通过检查放宽规则。

先冻结全部预测再评分，独立核验源绑定、掩码定义及所有查询。若主无法提供两个自然面板强基线之外的稳定MAE增量，停止该固定任务规则，不追加掩码、层、幅度、输入或训练网格。控制的局部效果保持控制身份；有信号仍需充分相关工作、第二预测器和未用确认。正式运行期间每30分钟检查，9月18日起不新增实验。
