四种共享门控均未在这两个预测器上同时超过八候选中位数的 MAE/MSE。相对七候选中位数，主门控在 Chronos 两个指标均退化；TimesFM 只有轻微 MSE 改善，MAE 退化。R6 人工缺失面板中原始历史等权门控的 Chronos 改善没有在这批原始缺失历史上复现。因此，当前不宜将重新加权作为统一修复。

使用 1024 步历史的原生控制在 Chronos 上改善较大；TimesFM 上表现为 MAE 较好、MSE 较差的取舍。它有额外过去信息，不能视为相同历史预算下的填补选择收益。原 raw-native 失败仍按原协议保留，不对成功窗口单独求平均后宣称完整结果。

这项扩展增加了对当前固定共享门控的原始缺失覆盖，但数据已在早期研究中查看，不能称新的独立确认。证据位于 `artifacts/iclr27-r6/legacy-native-gates-v001`。当前仍为 NOT READY；下一项只测试原门控未显式接收的候选预测关系，并用同容量对角控制隔离该信息的作用，见 `R6_GEOMETRY_GATE_PLAN.md`。
