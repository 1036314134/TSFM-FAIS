# 条件风险监督的完整源训练结果

2026年9月15日12:25，R16训练及独立审查完成。18个匹配模型、两个R12完整源模型的精确重放、112896评分全部核验，最大预测重建差1.07e-14，固定组合最优性残差最大6.78e-8，通过原阈值。结果为conditional-training-v001与conditional-training-audit-v001。

新增48个模拟验证历史上，条件期望监督的实际MAE/MSE为Chronos 0.695280/0.838647、TimesFM 0.718143/0.883352；同人口实际未来监督分别为0.695993/0.839159和0.718805/0.884466。条件期望监督存在小幅平均优势。原源更新次数匹配对照为Chronos 0.707490/0.865406、TimesFM 0.734498/0.916807，说明新增模拟数据带来的平均改善明显大于两种模拟监督之间的差异。解析期望评分的方向一致：期望监督Chronos 0.688361/0.828011、TimesFM 0.711611/0.871484，实际未来监督分别0.688932/0.828278与0.712260/0.872244。

原52个同源时间留出历史上，期望监督为Chronos 0.781539/1.570952、TimesFM 0.756140/1.517927；同人口实际未来监督为0.780917/1.567710和0.755545/1.515277，后者平均略好。原源更新次数匹配对照为Chronos 0.778815/1.557343、TimesFM 0.756403/1.543427。TimesFM两种混合监督的MSE均有改善，尚不能将这部分收益归因于条件期望监督本身；Chronos未形成相同方向的收益。

原源固定组合的时间留出成绩为Chronos 0.778225/1.545989、TimesFM 0.767612/1.520259；八候选中位数为0.781924/1.554667和0.769650/1.537814。期望监督Chronos仍弱于固定组合，TimesFM相对固定组合的MAE较好而MSE相近。所有八候选、固定组合、均值/中位数及种子结果保留。本轮为同源时间留出，不与旧R12家族留出结果混排。

模拟上的期望监督小幅优势尚未转化为原时序数据中相对实际未来监督的优势。真实缺失迁移仍需核验，主条件保持conditional_expected，不根据结果更换。上述均值不足以证明独立的降噪贡献或投稿就绪；真实数据下游MAE/MSE仍为最终主要指标。
