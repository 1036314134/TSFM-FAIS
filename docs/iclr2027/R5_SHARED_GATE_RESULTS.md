# 小型共享预测加权网络的源开发结果

两种目标、两种预测器、15 个留出家族和三个固定种子共 180 个模型已完成。独立矩阵回放核对 89,856 个决策输出，权重、预测和指标的最大差异均为零；训练专用特征标准化与两条件的容量/数据匹配均通过。汇总首次因模型名称列进入减法失败，原脚本及日志保存在 `shared-gate-readout-v001`，修复只限定 MAE/MSE 数值列，没有重新训练模型。

| 条件 | Chronos MAE/MSE | TimesFM MAE/MSE |
|---|---|---|
| 实际组合损失，共享网络 | 0.779079 / 1.543561 | 0.754242 / 1.492189 |
| 成员损失，同容量网络 | 0.795789 / 1.639266 | 0.758550 / 1.499097 |
| 源固定凸组合 | 0.780687 / 1.555598 | 0.771366 / 1.529399 |
| 七候选均值 | 0.795885 / 1.586287 | 0.789373 / 1.588424 |
| 七候选中位数 | 0.780606 / 1.558757 | 0.772570 / 1.555558 |
| 原 35 三元组分类器 | 0.772412 / 1.541547 | 0.758966 / 1.515527 |

实际组合目标相对同容量成员目标，两预测器均有双指标改善，分别为 2.10%/5.84% 和 0.57%/0.46%。相对七候选中位数，Chronos 的均值改善仅 0.20%/0.97%，15 个家族中 5 个双指标改善、8 个双指标退化；TimesFM 改善 2.37%/4.07%，11 个家族双指标改善、4 个退化。完整逐家族结果和所有种子保存在 `shared-gate-readout-v001`。

与原三元组分类器比较，TimesFM 改善 0.62%/1.54%，Chronos 退化 0.86%/0.13%。因此当前支持相同小网络下的目标对照，不能写成新网络在全部预测器和全部强基线上都更好。它与原分类器之间还改变了容量、表示和输出类，不能把二者差别仅归因于目标函数。

每个种子模型有 1,096 个可训练参数。预先规定的最终输出平均三个种子的权重，故每预测器部署共 3,288 个参数；七个候选基础模型预测仍全部需要。没有新增预测器调用只描述本次缓存实验的额外调用量，不能理解为实际部署不需要预测器。

下一项固定相同设置，在所有 165 个源训练历史上拟合完整源模型，并对已用 823 任务作迁移诊断，见 `R5_SHARED_GATE_TRANSFER_DIAGNOSTIC.md`。该诊断不重新调参，也不能替代新的独立确认。当前论文目标仍未达到。

固定设置的已用数据迁移诊断现已完成，网络权重回放和全部旧方法的分数复算均完全一致。在人工缺失面板，Chronos 的新方法为 0.412671/0.680753，TimesFM 为 0.650144/1.178687；相同数据上的八候选中位数分别为 0.441859/0.779687 和 0.660686/1.307126。两个预测器上均改善两个指标，且超过此前三元组规则。该结果支持投入新的确认，但它不是独立确认。

自然缺失仍存在边界。已见家族未用序列的自然缺失面板上，两模型都略逊于七候选中位数；新 UCI 自然缺失面板中，Chronos 改善，TimesFM 小幅退化。原有失败结果及全部控制保留。未根据这些子面板为不同模型或不同缺失类型另设规则。

R6 已冻结同一主方法，使用四个新公开来源和 96/192 两个预定跨度进行独立确认，主跨度为 96。源真实未来监督的小网络作为新增匹配控制，和主模型使用相同源历史、特征标准化及训练预算。当前尚未取得 R6 预测结果，因此论文目标仍未达成。
