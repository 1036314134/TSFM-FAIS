# 条件期望监督的匹配训练执行

2026年9月15日，conditional-source-audit-v001完成1200输入、3600决策、240组共享未来及14880个有效预测查询核验，最大标签差6.66e-16。沿用R16_CONDITIONAL_SUPERVISION_PROTOCOL.md已登记的三种监督条件，本轮先训练完整源模型，评价同一来源的留出历史并进行后续真实缺失迁移。原R12家族留出结果保持单独报告；本轮同源时间留出不能当作未见家族评价。

原源165训练历史、52验证历史，以及新增模拟192训练历史、48验证历史保持固定。Chronos原3906行加1200行，TimesFM原7812行加2400行。训练分别仅使用原源2970/5940行和模拟960/1920行，所有验证目标在传给训练的数组中置为NaN。过程参数和条件标签只能用于监督，不进入输入；特征仍为原33字段补64零、八候选、2121参数，Chronos联合两个目标，TimesFM按目标决策。

三条件为conditional_expected、conditional_factual、source_steps_matched，主conditional_expected。前两条件使用完全相同混合训练人口、归一化、初始化、随机批次和更新次数，仅模拟监督由一次未来改为解析条件期望；后一个只使用原源训练人口，但更新次数相同。完整混合人口25轮分别给Chronos 775次更新、TimesFM 1550次更新，批量128，末批保留原语义；原源对照按其自身随机排列循环直至达到同样次数。三种子5101/5102/5103、AdamW学习率和权重衰减0.001、梯度裁剪1。家族权重沿用原函数，模拟三个过程组分别为三个新增家族，各组内四过程为数据集；同一条件下固定组合使用相同权重。

原源损失逐值保留R12的平滑MAE与MSE各半目标，epsilon为0.001，MSE使用原预测几何计算。模拟实际未来条件使用真实绝对误差与MSE各半；模拟期望条件使用给定观测历史后高斯绝对误差期望与MSE期望各半，方差项与模型权重无关，可从训练MSE中省略而不改变梯度。两种监督不得混用未知完整末态；期望目标仍由各缺失历史的后验计算。

训练18个模型，另在原源人口及原25轮预算下重放两个seed5101的R12完整模型，要求参数、归一化、初始化、训练历史和训练索引逐值一致。复用并保留R12完整源三种子及其平均权重输出、八个单候选、均值、中位数、原源固定组合和单候选。新增两种混合监督分别计算同目标的固定凸组合与固定单候选。所有模型和固定选择在验证评分前冻结。

固定目标用SLSQP解析梯度、2000步及ftol=1e-13；必要时沿用可行两坐标精修。模拟实际未来的绝对误差在零点不可微，核验使用有效次梯度：对绝对残差不超过1e-10的数值零点，在[-1,1]内以小型线性规划寻找满足单纯形最优性条件的次梯度。保存零点残差及证书；归一化最优性阈值仍1e-7，可行性1e-10。解析期望条件为光滑目标。证书与直接独立梯度/次梯度重建共同检查，不因求解器返回成功就接受结果。

两个验证面板单独报告：原52历史只用真实MAE/MSE；模拟48历史同时报告同一实际未来MAE/MSE和解析期望MAE/MSE。每个面板保留32种输出，共112896行评分。种子只用于检验训练变异，不增加独立历史数。平均模型组合使用三个种子权重的均值，所有条件一致。

独立审查检查来源校验值、索引、训练/验证隔离、权重、归一化、更新次数、模型容量、两个旧模型重放、固定组合证书、独立网络推断及全部指标重建。原结果不覆盖。训练和审查两个正式阶段上限各3小时、1小时；第一优先级单核管理，运行中只按小时检查。完成后再进行登记的真实缺失迁移核验，不用同源或模拟结果替代真实目标准确度。
