# 与输出组合一致的源教师评分

依据已经完成的组合目标诊断，当前问题不能全部归因于候选池不足。源验证面板上的未来理想单候选与三候选都明显优于当前学习器，固定三个候选也不是最强的理想动作类；完整历史教师下直接选择三元组有小幅真实误差改善。上述参照含不可用信息，因此下一步必须检验可见输入下的学习策略，不能把参照结果当作方法效果。

后续源开发检查固定 43 个输出选项：七个单候选预测、35 个三元组的逐坐标中位数，以及七候选中位数。最后一项同时作为固定参考和分数相同时的默认选项。三个成员必须互异，单候选选项显式保留。所有选项都由当前七个候选预测确定；仍需七个逻辑预测上下文，没有减少调用量的主张。

评分目标与实际返回的输出一致。记七候选中位数为 m，选项预测为 p，完整源历史教师为 t，v=p−m，q 为当前决策覆盖的输出坐标数，n=√(‖v‖²/q)。主检查沿用既有预测投影研究中的单位方向目标 b=〈v/n,t−m〉/q，n≤1e−12 时置零；部署评分为 n²−2n·预测b。其监督对应选项相对参考的教师 MSE 差，普通风险差回归作为同容量对照。该分解已有原型和基础推导，不作为新理论主张。

每个选项的输入由成员的 21 个历史/填补描述符的均值、实际选项预测的 12 个响应特征及七个成员指示值组成。组合描述符仅表示其成员，不假称存在一个对应的单次填补输入。响应特征仍使用 LOCF 预测、原六有限候选中位数和最后一个 LOCF 值（含已登记回退）的既定定义；不得混用七候选参考与原六候选特征定义。单独记录用于评分的 n，不读取当前隐藏历史或当前未来。

只使用原 15 家族、165 个训练起点及其人工掩码，按原家族留出方式评价 52 个验证起点。树参数固定为 160 棵、15 叶、学习率 0.05、最小叶样本 25、L2 系数 5、种子 5101，采用家族权重。Chronos 的选项由目标共享；TimesFM 可按目标选择。两个目标变量、96/96 长度、原始输入和前缀标准化评分保持原样。原生确认集不参与拟合或本轮选择。

对同一已拟合评分器，分别限制为七个单候选、35 个三元组、前两者的 42 个选项以及完整 43 选项，保留四种推理菜单的结果与选择频率；主要版本事先固定为 43 选项。这样可以区分动作范围和七候选中位数参考的作用。新评分器与原配对排序的模型形式及输入描述也有变化，不把二者全部性能差别仅归因于目标对齐。

实现前先读取既有 `forecast_projection.py` 和相应分析程序，复用经过验证的目标分解；避免重复构造略有差别的归一化。实际源验证决策须先保存再读取未来评分；检查特征白名单、准确评分下的最优选项、零方向处理、共同/独立目标边界、冻结源排名与七候选回退。先判断相对七候选中位数与原学习器的两项真实指标，再决定后续，暂不增加手工特征或更多教师组合。

这是待实现的源开发检查，尚无结果。即使开发改进，也需要新的、事前固定的验证证据才能恢复主要方法的优势主张。原三候选方法已经完成且未通过优势确认的结果继续保留。
