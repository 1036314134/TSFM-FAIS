# 当前缺失结构匹配的历史回放：开发探针A

2026年9月15日，在用户授权新方向及预检查后登记。主问题是在相同历史锚点、候选、评分位置和计算预算下，复现当前缺失结构是否比通用随机掩码历史验证更有利于当前下游策略选择。R18不启动。允许使用当前预测时点之前已到达的目标序列观测，冻结两个预测器参数；这属于有目标历史反馈的部署设置。

预检查发现1024步范围不能支持24任务。4096步范围内，301个已有目标缺失任务中130个具有8个完整观测历史上下文，并可构造非退化的位置对照；它们来自合并后的4个来源组。固定pilot-plan-v001按来源组轮流取任务，组内先轮流序列、再按时间取任务，选出24个已用开发历史：北京8、Bike2、MetroPT7、新加坡7。新加坡PM2.5和Weather合为一个来源组。支持不足的171个任务保留在清单；本轮结论只针对有足够精确支持的开发子集，不冒称总体覆盖或新独立确认。

L=H=96，B=8。锚点u按t-96、t-192等向前排列，使用最近8个合格锚点；u+96<=t，历史上下文完整，两个历史目标未来各至少48个原始观测。上下文不得早于原拟合前缀，另检查所有参与原神经填补器拟合的序列窗口在日历时间上均先于校准上下文。4096是近期可用范围上限，固定训练前缀及其统计作为共同已有信息。当前未来不进入准备、选择或推理。

三规则共享完全相同的8个锚点。matched原样平移当前96乘D缺失矩阵；shuffled对整个矩阵作共同时间循环位移，只接受保持逐通道缺失段长度多重集且矩阵发生变化的位移，同步缺失关系不变；generic按每个通道的当前缺失个数均匀抽取位置，作为缺失量匹配的通用随机对照。每个查询、每种规则固定一份掩码并在8个锚点复用，以免掩码多样性与匹配混杂。位移与随机种子由原任务标识确定，不读取误差。匹配只复现输入缺失结构，不声称无偏复现真实缺失机制。

保持六个原填补器、MoTM和guarded_direct八候选。原神经填补产物直接复用，不重训；传统填补的前缀统计按同一原前缀重建并计入成本。MoTM使用原公开网络、3步上下文优化、ridge0.5等既有设置，局部编码优化计入成本。当前和历史使用同一冻结产物及计算规则。当前六候选重放须在rtol/atol1e-6内复现原输入，观测值精确保持；MoTM与原参考按既有2e-5界核对。所有失败、部分支持和回退均记录。

主指标为按原观测训练前缀均值及总体标准差标准化的下游MAE，MSE完整报告并作为退化检查。每个目标先按实际观测数归一化，再等权目标、历史锚点。Chronos对两个目标共同选策略，TimesFM逐目标选策略。默认b为八候选预测中位数，属于固定输出组合，不对应唯一填补历史，不声称始终一次预测调用。

每个规则报告forced（在八个单候选中必选）、erm（默认中位数与八个单候选之间的经验风险选择）、conservative（经验保守回退）三版本。令d[u,a]=MAE[u,a]-MAE[u,b]。erm仅在最小平均d严格小于-1e-10时替换默认；conservative将平均d加上sd(d,ddof=1)/sqrt(8)，系数固定1，然后用同一规则；forced不检查是否优于默认。1e-10仅为预定数值并列容差，候选分数相差不超过该值时取固定候选顺序首项。主方法matched_erm，主机制比较matched_erm对generic_erm，位置增量比较shuffled_erm；不在结果后更换主身份。8个相关锚点的惩罚仅为经验规则，不作不退化或置信保证。

保留八个单候选、八候选均值/中位数、源训练MAE最佳单候选、同源MAE固定凸组合、原R12联合目标固定组合、96步前缀标准化原生处理及两种4096范围原生长历史对照（原量纲和前缀标准化）。长历史实际长度为min(4096,t-prefix_end)，完整使用同样可读的近期范围；其长度、拟合前缀信息和额外计算分别记录。源MAE固定组合允许原1e-3平滑作数值拟合，实际单候选选择与评价使用真实MAE。

每种规则的erm和conservative增加相同逐目标替换位置的均匀随机候选对照；forced增加一个全替换随机对照。其动作概率在当前未来读出前固定，评价为对单候选损失的概率平均，不把随机动作的期望损失误算成平均预测的损失。随机对照无需新增预测。高回退率时不能把默认策略的成绩算作新方法优势。

历史预测逻辑输入上限24*3*8*8*2=9216；当前八候选384；三个额外原生对照144，共9744，不含数值重放。所有预测参数固定，查询按有效float32输入、原拟合产物、模型版本、输入标准化模式及前缀统计绑定，记录去重输入、适配器调用、实际模型forward批次及形状、重复核验、加载/推理墙钟。先用每来源组第一个任务测量一小批吞吐，记录后再启动完整队列，复用完全相同缓存。准备的传统统计重建、神经产物加载和MoTM上下文优化另外计时，不声称效率优势。

全部历史/当前预测冻结后才生成选择；选择和随机动作概率冻结后才读取当前未来评分。独立核验时间边界、历史观测保护、掩码结构、训练前缀、模型版本、有效输入与缓存、配对风险、动作、随机对照损失、来源分组和成本。按窗口、序列、数据集、来源组依次汇总，另保留各家族及替换率，不将24任务、8锚点、两个目标或掩码计作独立来源。

该开发探针以主要真实面板相对强默认约1% MAE改善作为继续投入参考，并检查同预算generic/shuffled增量、两个预测器方向及MSE退化；它不是投稿门槛或显著性结论。若只改善相对较弱比较、只增加回退、或不能超越同信息范围的直接预测，则停止扩展机制，转而审查探针B固定动作。正式确认需另外完成未使用数据盘点并冻结，不在本轮宣称已具备新确认集。

正式阶段为准备、冻结预测、决策与评分、独立核验，上限分别2/3/1/1小时，第一优先级单核管理，不干预其他任务。运行期间每半小时检查一次，未完成立即静默结束；短诊断、失败修复和完成后的分析即时处理。
