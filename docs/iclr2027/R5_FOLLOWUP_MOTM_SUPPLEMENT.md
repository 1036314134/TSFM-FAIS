# MoTM follow-up comparator supplement

This supplement is recorded after completion of the seven-candidate forecast banks and while primary policy evaluation is running, before inspecting the new 823-task accuracy readout. It was motivated by the already examined original 373-window study, where including MoTM in a simple forecast median slightly improved the seven-candidate median. It is a late supplemental comparison and is not part of the original pre-forecast registration.

The primary method, matched objective control, frozen source models, 823-task cohort and three reporting panels remain fixed. The supplement evaluates the same pinned MoTM reference and historical-input recipe previously verified in `motm-reference-v001`, `motm-runtime-v001` and `native-confirmation-v001/motm`. Released networks remain frozen; the reference's observed-context adaptation and ridge coefficient 0.5 are unchanged. Empty channels retain the shared LOCF/prefix-median fallback, and observed entries must remain exactly unchanged. No current future value is used for filling or choosing a method.

Two additional outputs are reported: the standalone MoTM-completed input forecast and the coordinate-wise median of the original seven candidate forecasts plus MoTM. The latter has a maximum eight-context budget; it must not be described as having the same query budget as the primary seven-context selector. Identical effective float32 inputs may reuse an existing candidate forecast. The two forecasting models, 96-step context/horizon, first two targets and raw-input recipe remain the same. Scoring uses the original observed futures and the existing training-prefix standardizers.

All registered tasks are included; no panel, history, mask, MoTM coefficient or source checkpoint is selected using the new results. Both supplementary outputs are compared with the already frozen primary selector and seven-candidate median. Differences are reported separately for new natural sources, unused items in previously seen families and new synthetic sources. All failed cases and input fallbacks are retained in diagnostics.

The MoTM reference includes a Solar-trained component. The Alabama solar results must therefore carry that pretraining caveat; they do not establish performance on data absent from MoTM pretraining. The supplement provides a stronger comparator and cannot create a new independent confirmation for a subsequently modified FAIS method.
