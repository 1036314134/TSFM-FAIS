# 条件期望监督的真实缺失迁移结果

2026年9月15日，conditional-transfer-v001完成177684行评分、164016个决策预测重建，无新拟合或预测器调用。最大预测重建差1.07e-14，指标独立重建差零，原R12十种输出逐值复现。所有26种本轮输出及此前比较均保留。

旧原始缺失七家族面板上，主条件risk16_conditional_expected为Chronos 0.613592/0.803340、TimesFM 0.619317/0.800973，均弱于八候选中位数的0.609386/0.797358和0.613597/0.793853。相同人口实际未来监督分别为0.612530/0.799195、0.619221/0.801345；Chronos的期望监督更差，TimesFM存在指标取舍。更新次数匹配的原源控制为0.612309/0.801737和0.619675/0.802082。结果不支持条件期望监督产生稳定的真实缺失精度收益。

R6北京原始缺失H96面板中，主条件为Chronos 0.958100/1.955435、TimesFM 0.981947/2.049993，未超过八候选中位数或原生回退。人工缺失H96中，主条件为Chronos 0.612289/1.127957、TimesFM 0.600952/1.125497；与同预算原源控制0.606415/1.117412和0.600281/1.122293相比均较差。旧R10 TimesFM主条件0.582252/1.065021仍更好。时间网格缺口的局部改善没有改变这些主要判断，全部跨度与面板保留。

本轮已直接检验解析条件期望监督的假设，模拟内的小幅优势未稳定迁移。当前不将该方法升级为论文主贡献，不继续围绕相同高斯源比例或随机种子搜索。R14/R15的评价性质结果仍有效，但不能据此证明真实数据失败主要源于标签噪声。论文目标尚未达到。

代码审查确认，原R6逐位置模型仅使用完整历史教师MSE；R10真实未来MAE/MSE联合监督则用于整段共享候选权重。两种改变的匹配交互尚未检验。后续限定为原609参数逐位置/池化网络的真实未来MSE及联合MAE/MSE监督，保持原七候选与源人口，不扩大网络或改变已完成结果。允许权重随预测位置变化已有[ICML 2023先例](https://proceedings.mlr.press/v202/hasson23a/hasson23a.pdf)，该执行差异本身不视为新颖性保证。
