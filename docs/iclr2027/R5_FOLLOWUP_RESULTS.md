# 新验证结果与研究判断

这轮独立于新方法拟合的验证已完成，当前证据仍不足以支持跨预测器稳定改善。审查复核了 4,938 个新选择器决策和 26,336 个方法预测向量，预测重建差异为零；包含原始量纲误差在内的指标复算最大差异为 5.82e-11。来源为 `followup-policy-audit-v001` 和 `followup-readout-v001`。此数据集的结果现已被查看，后续方法修改不能再把它称作未用确认集。

主要指标均为训练前缀标准化后的下游 MAE/MSE，负的相对变化表示改善。各面板分别计算家族宏平均；表中每行涉及两个有对应样本的家族，不能据此推断大范围总体显著性。

| 预测器与面板 | 方法 MAE/MSE | 七候选中位数 MAE/MSE | 相对变化 MAE/MSE |
|---|---|---|---|
| Chronos，已见家族未用序列的自然缺失 | 0.924818 / 1.398397 | 0.925101 / 1.402619 | -0.03% / -0.30% |
| Chronos，新来源自然缺失 | 0.793807 / 1.157201 | 0.788168 / 1.145874 | +0.72% / +0.99% |
| Chronos，新来源人工缺失 | 0.424840 / 0.771805 | 0.456056 / 0.894169 | -6.84% / -13.68% |
| TimesFM，已见家族未用序列的自然缺失 | 0.922294 / 1.369762 | 0.914921 / 1.351148 | +0.81% / +1.38% |
| TimesFM，新来源自然缺失 | 0.711247 / 0.931313 | 0.711364 / 0.938325 | -0.02% / -0.75% |
| TimesFM，新来源人工缺失 | 0.702153 / 1.495100 | 0.684924 / 1.455969 | +2.52% / +2.69% |

Chronos 的人工缺失收益在 Solar 和 weather 两个来源上均成立，对应 MAE/MSE 相对变化为 -14.39%/-25.20% 与 -2.57%/-9.80%。TimesFM 在这两个来源上均退化，分别为 +0.48%/+0.60% 与 +4.94%/+4.54%。原生缺失上也缺少一致改善：Chronos 在两个新 UCI 来源均退化；TimesFM 在 Air Quality 小幅改善，在 Household Power 上 MAE/MSE 发生取舍。

较强对照进一步限制了方法主张。在 Chronos 人工缺失面板，源固定三元组为 0.434369/0.745735，新方法相对它降低 MAE 2.19%，却增加 MSE 3.50%。相对同容量成员目标对照，新方法的 MAE/MSE 降低 2.29%/4.68%，支持该面板上的组合目标作用。TimesFM 人工缺失面板中，LOCF 为 0.665099/1.273418，线性插值为 0.658217/1.301711，均超过新方法的两个指标。因此不能仅用 Chronos 相对七候选中位数的百分比作为全文主结论，也不能把较弱组合基线当作每个条件中的最佳固定方法。

所有 14 个神经填补模型拟合成功。部分 LOCF、插值和季节候选在完全无锚点的变量或窗口上缺乏原生输出，按预先固定的规则使用历史回退；这些状态已保留在 `candidate_status_counts.csv`。最终用于预测的输入有限且保持原观测值不变。不能将回退前的候选状态与最终预测缺失或删去失败任务混为一谈。

当前判断继续为 NOT READY。开发集优势与两个新人工缺失来源上的 Chronos 改善是有效的局部证据；它们尚未带来对主要强对照及两个预测器都稳定的优势。两预测器之间同时存在架构、预训练与输入依赖范围差异，不能直接将结果分化归因于联合或独立建模。

MoTM 单独预测及八候选中位数已按单独的补充协议登记，主方法和原结果不变。另登记仅使用 16 个已用人工缺失历史的教师诊断，区分当前选择器与完整历史教师最优三元组的差距；该诊断使用不可部署信息，也不是新确认。补充对照与诊断完成后，才有依据决定是否扩大源训练或调整研究问题。

补充对照已完成，6,584 个方法窗口分数复算的最大差异为 3.64e-11。Chronos 新人工缺失面板的八候选中位数为 0.441859/0.779687，新方法相对它改善 3.85%/1.01%。TimesFM 的八候选中位数为 0.660686/1.307126，新方法相对它退化 6.28%/14.38%；MoTM 单独预测为 0.671163/1.238834。新的 Chronos 收益因此没有完全被该对照消除，但原有 MSE/MAE 取舍及跨模型不一致仍成立。八候选组合比主方法多一个可能的候选查询，Solar 来源还涉及 MoTM 参考组件的预训练数据，须保留这些条件。

只增加 32 次完整历史预测的教师诊断也已完成。对同一 576 个人工缺失任务，使用不可见完整历史教师选择最佳三元组时，Chronos 的真实 MAE/MSE 为 0.360950/0.560875，TimesFM 为 0.606881/1.141902，均明显优于当前学习规则。教师误差最优的三元组与真实未来最优的三元组仍不同；后者 MSE 分别为 0.496990 和 1.028583。未来理想单候选的 MSE 还更低，分别为 0.443860 和 0.967837。这些参照说明候选选择及输出限制仍有影响，不能据理想参照的差距断言可以通过增加训练全部消除，也不能把这些分数作为可部署效果。

目前进一步检查的是源训练内、同家族较晚时段、留出家族和已用新人工缺失来源上的教师额外损失。该项只复用冻结模型和缓存，不重新拟合，也不增加预测器调用；其结果将决定下一项学习改动的依据。尚未启动新的大规模训练、端到端输出门控或目标前缀适应。
