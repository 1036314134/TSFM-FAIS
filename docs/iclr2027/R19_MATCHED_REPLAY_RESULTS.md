# 探针A：缺失结构匹配回放的开发结果

2026年9月15日17:02，R19四阶段及独立核验完成。24个已用开发任务覆盖4个来源组，当前与历史共9744个逻辑预测输入，9674个不同有效缓存查询通过重建；48个决策记录、1536条评分核验通过，历史风险独立重建差最大1.07e-14。该结果仅适用于具有8个完整历史锚点的目的性开发子集，未使用确认集仍未认证。

主matched_erm的Chronos MAE/MSE为0.686816/1.210180，八候选中位数为0.702047/1.263797，分别改善约2.17%/4.24%。但TimesFM主结果0.708251/1.214527，相对中位数0.699046/1.138911分别退化约1.32%/6.64%。报告保留原主身份，未将更有利的保守版本换为主方法。

相同锚点和预算的generic_erm为Chronos 0.761194/1.757611、TimesFM 0.703013/1.162743；shuffled_erm为0.704411/1.323310和0.682076/1.116062。Chronos的匹配版本较两者好，但TimesFM较两者差，不能据此建立位置匹配的稳定增量。采用相同保守规则后，Chronos generic_conservative的0.674568/1.169465优于matched_conservative的0.681408/1.179928；回退处理改变了比较排序，不能将其贡献归到结构匹配。

按来源看，Chronos相对中位数的MAE收益主要来自只有两个窗口的Bike来源；北京和新加坡MAE略差，MetroPT的MAE略好而MSE较差。TimesFM匹配ERM在北京、Bike、新加坡的MAE均较中位数差。任务、目标和八个锚点不计作新增独立来源，不根据小样本给出安全保证。

同4096可读范围的原生长历史预测为Chronos 0.601912/0.961500、TimesFM 0.620571/1.388216。两者MAE均优于主回放策略，TimesFM存在MSE取舍。完整历史预算控制说明，当前回放没有建立相对直接利用同样历史信息的精度理由。主ERM的替换比例为Chronos100%、TimesFM95.83%；保守版本为70.83%/68.75%，本轮并非始终回退。与同替换位置随机选择相比有所改善，也不足以替代上述强对照。
