# R43：保留原始输入的填补参考序列

2026年9月17日，在新预测之前登记。R42缺失扰动适配相对普通适配有局部增量，但未通过两个自然面板的强基线比较，因此不扩大同族训练网格。本轮检验不同输入表示：原始序列及其NaN完整保留，填补候选只作为额外辅助序列进入同一冻结Chronos组；读取原始目标行的预测。没有新增训练、参数修改、未来已知变量或信息来源。

Chronos-2的组注意力本身支持相关序列之间的信息共享，这项既有能力不是本研究贡献。TRACE已讨论缺失模态的条件估计，TS-ICL已统一预测和填补；本次仅核对其公开摘要，尚未完成实现对照。增加通道或复用现有接口并不自动构成新方法贡献，只有原始输入角色和强对照之外的效果才值得进一步研究。[Chronos-2](https://arxiv.org/abs/2510.15821)、[TRACE](https://arxiv.org/abs/2606.06285)、[TS-ICL](https://arxiv.org/abs/2606.05878)。

人口沿用北京231和HDB83任务，原上下文192、跨度、变量、prefix统计、peer及评价位置不变。原314任务和所有R42输出保留。HDB后28天继续未评分。北京固定使用已有12个目标填补轨迹：R30七候选locf、linear_interp、seasonal_lag、knn_multivariate、saits、timemixerpp、motm_reference，四个原统计修复，以及R35静态Gaussian。HDB固定使用R39六候选median、ffill、linear、seasonal24、knn、gaussian。不同来源候选集合的差异明确保留，不宣称同池或完整神经填补比较。

每个候选只取目标列的完整历史；原观测必须逐值相等。辅助行按目标原prefix均值和总体标准差转换为与原目标相同的输入单位，候选顺序固定，不去重、不按当前误差选择。原生矩阵首先保留，随后按候选、目标顺序追加辅助行。所有行使用同一group_id，未来全部未知，原始目标仍位于开头。辅助行来自同一批观测的确定性处理，不能当作额外独立观测、独立后验样本或校准不确定性。

主raw_plus_pool追加完整候选集合。五个直接控制分别只追加Gaussian、只追加KNN、只追加候选逐点中位数、追加与完整池同数量的原始目标副本、只追加一组原始目标副本。副本保留原NaN，用于检验通道数量及重复观测的作用。另做仅候选轨迹的联合查询，以候选预测均值/中位数读出；主查询的辅助行预测也额外取均值/中位数。共7个不同联合查询、10个新点输出。原始目标本身的预测始终为主，不在结果后切换到辅助输出聚合。

如果当前192历史的全部目标原本完整，所有新增方法共同退回原生预测：目标参考轨迹此时只是原值的复制，不启动拼接。在固定人口中，北京没有这种任务，HDB有8个；这些任务保留计分与回退记录，不删除。其余306任务最多41行（北京）或13行（HDB）；不同变量数的实际成本和形状保存。原始行的数值、NaN、内部统计及编码字段须与普通输入保持一致。

每个新增点输出另给同VAR各半控制，保留此前强组合的匹配比较，但主raw_plus_pool不加VAR。北京186个方法，HDB71个方法，共48859窗口/91825目标分数。两来源自然面板及各自辅助面板分别报告前缀标准化下游MAE/MSE。必须比较原生/已有长历史、原同候选填补预测和预测池、R42适配、单参考轨迹、重复副本控制及同VAR组合，不能只比弱原生或某个单填补。

306个实际干预任务每项7次查询，所有314任务另做一次普通预测核验，共2456次模型调用；审计另重放2456次。主方法本身每任务最多一次基础模型调用，但完整池还需要所有上游填补器；本轮复用缓存不代表其部署成本为0，也不据此声称整套方法更便宜。原上游拟合/生成成本与状态继续继承R30/R35/R39证据。

准备和预测完全冻结后评分；所有旧输出、候选身份、原观测保护、辅助行映射、回退、原始输入统计/字段、基础模型参数及全部查询核验。预测重放和原字段检查要求逐值一致，全部指标1e-12。先运行未评分小批，不依据小批精度修改候选或规则。若无法在两个自然面板获得強基线之外的稳定MAE增量，停止本固定表示，不扩候选数量、顺序、通道权重或相关训练网格。正式运行期间每30分钟检查，9月18日起不新增实验。
