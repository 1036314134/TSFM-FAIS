# 目标与其他变量填补的交叉替换

本检查沿用训练预算实验的三个开发数据集、18 个既定任务、两种神经填补器及两种更高预算。原始输入、原观测值和冻结预测器均保持固定；以本次重拟合的 10/64 为基准，分别比较 50/64 和 50/512。每项比较包含基准、只更新目标列、只更新非目标列、同时更新四种完整输入。源程序及结果分别为 `evaluate_imputer_input_scope.py` 和 `imputer-input-scope-v001`。

每个模型共 72 组输入干预，原观测保持及列范围检查通过。基准和全部更新端点与预算实验预测在既定容差内一致，模型参数保持不变。TimesFM 独立目标接口在改变非目标列时结果不变，作为该接口范围的结构性对照；它不是对所有模型架构的经验结论。

| 电力数据，TimeMixer++，50/512 对比 10/64，Chronos | MAE | MSE |
|---|---:|---:|
| 基准输入 | 0.637103 | 0.872041 |
| 只更新目标列 | 0.598389 | 0.720084 |
| 只更新其他变量 | 0.673980 | 1.003593 |
| 同时更新 | 0.554625 | 0.619763 |

在这一开发历史上，只更新目标列已经改善 Chronos；只更新其他变量反而退化；同时更新的收益更大。因此，不能把两个预测器对同一预算变化的相反反应简单解释成“其他变量填补变好了”。报告同时保留预测向量的交互残差与 MSE 的交互差值，后者还包含平方损失自身的非线性。

该检查是在查看预算结果后制定的探索性输入干预，不能当作新的独立确认。全部三个数据集的结果均保留，下一步只核验并整理作用范围，不用单一有利案例代替总体表现。

独立复算现已完成，结果为 `imputer-input-scope-audit-v001`。576 个预测向量的 MAE/MSE 均复现，最大差异为零；TimesFM 的目标独立性对照通过。预测交互残差与损失交互差值另存于 `interactions.csv`，不能将损失交互直接解释为预测网络内部的唯一机制。
