# R35：跨变量动态条件填补与预测分布混合

2026年9月17日，R34停止后登记。R5曾采用逐变量、固定相关长度的高斯工作先验并得到负结果；R30为可用变量静态回归加逐目标残差桥接。R35固定检验同前缀拟合的17维动态高斯系统：时间转移与跨变量创新共同决定缺口的条件分布，再检查传播完整预测分位信息是否比单次均值填补有效。它是新的开发探针，不把Kalman滤波、平滑、采样或分布混合本身宣称为原创。

源、时钟、peer及原训练前缀标准化沿用R30。每站只使用最早7012小时，全部17列均有原观测的相邻时刻对拟合一阶VAR。提前只读核对发现12站各有4052—5990个完整转移对，均高于预设128下限；不对插值前缀制造训练真值。完整案例拟合仍可能受选择性缺失影响，不声称正确刻画真实缺失机制。

在原前缀z单位中，以lambda=0.001的中心化ridge拟合A，截距不惩罚。如果谱半径超过0.99则整体缩放A到0.99，并以训练转移对均值重新计算截距b。用该A、b的拟合残差估计创新协方差Q，固定为0.95S+0.05diag(S)+1e-6I。初始均值和协方差来自完整前缀行，协方差使用相同收缩及对角增量。此处所有系数、稳定化和收缩规则在评价之前固定，不搜索阶数或参数。

对每个192小时带缺失历史，按实际原观测进行无测量噪声的Kalman条件化，再进行Rauch–Tung–Striebel平滑。原观测值及相应不确定性行列精确保留为观测值和0；未观测位置由模型推断。第一时刻使用登记初始分布，之后采用A、b、Q。平滑只读预测起点之前的当前历史，不读真正待预测未来。

保存过滤分布、一步预测分布、平滑均值与条件采样因子。使用8对正负成对样本，共16条联合历史；固定基种子6103，各任务通过任务标识生成种子。回溯抽样使用条件协方差P_f[t]-J_t P_pred[t+1] J_t^T，末端协方差为P_f[-1]。数值分解只允许1e-10倍max(1,谱范数)以内的负特征值视作舍入并裁0，超过即失败。观测位置的抽样扰动为0，每对原始填补的均值与平滑填补相同，按前缀单位1e-12检查。高斯模型允许不符合物理非负性的样本，不事后裁剪；这是工作分布而非已校准真实后验。

每一范围分别报告8个输出：静态联合高斯条件均值的一次预测、动态滤波均值的一次预测、动态平滑均值的一次预测、平滑均值预测分位分布的中位数、16次原0.5分位的均值和中位数、16次完整预测分位分布混合后的均值和中位数。静态模型使用同初始均值/协方差，逐时刻条件化，隔离时间转移的作用。另报告由最后过滤状态递推A、b得到的直接VAR预测，以检验基础模型是否提供必要增量。

预测分位的混合采用固定离散近似：每个条件预测先按分位轴排序以处理交叉；节点权重来自相邻分位水平的中点边界，端点边界为0和1。每个条件历史等权。权重以原分位水平的有理数表示计算成整数，避免0.5阈值的累加舍入；累计权重恰好到一半时取相邻两值的中点。极端尾部质量集中到边界分位，未建模无限尾部。平滑单次分位中位数控制单列，防止把排序作用误归于多次传播。这里的近似中位数/均值不等于已证明的真实Bayes最优预测，未来分布与条件历史模型都可能失配。
