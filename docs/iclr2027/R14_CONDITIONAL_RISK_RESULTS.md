# 条件风险诊断结果

R14于2026年9月15日08:55完成四阶段及独立审查。36个独立历史构成180个观测输入，两个预测器共产生2232个不同有效预测输入，六个校准前缀上的神经填补拟合均完成。4320个决策条件全部核验，凸组合最优性残差最大1.38e-12，指标独立重建差最大1.78e-15。记录为artifacts/iclr27-r14/conditional-risk-v001与conditional-risk-audit-v001。

在八候选、未来创新标准差乘子1的条件下，对三个过程和四个缺失条件等权汇总，Chronos条件单候选相对同面板固定算法的可获取MSE收益为0.009988，配对事后选优偏差为0.038799；TimesFM分别为0.015869与0.059736。偏差除以二者之和的汇总比例分别约79.53%和79.01%。这些是指定模拟面板中均值之比，不能解释为真实数据的不可学习比例，也不同于原summary.csv中过程内比例的平均值。

过程差异明显：Chronos在耦合AR、独立AR、周期AR上的平均可获取MSE收益分别为0.015535、0.010473、0.003957，对应选优偏差为0.047361、0.065506、0.003529；TimesFM分别为0.029203、0.016031、0.002374，以及0.071440、0.105898、0.001870。周期过程的偏差绝对量较小，不能把某个整体比例表述成跨过程通则。完整观测下各候选预测相同，配对偏差为零。

同样条件下，条件MSE最优凸组合相对均值组合的可获取收益为Chronos 0.215022、TimesFM 0.285388，而事后凸组合配对偏差分别为0.050821、0.071564。这两个比较使用不同参照；单候选的大偏差比例不能外推到凸组合。凸组合的可获取空间提示预测候选确有互补性，但精确条件最优使用已知生成参数，不能当作可部署学习器或真实数据上的准确度改进。

提高未来创新标准差会提高部分条件的事后偏差，同时MSE条件最优选择及可获取差值保持不变。该结果支持对事后最优差距作谨慎解释，但改变了所有预测的绝对期望风险。进一步保持逐坐标均值和方差、只改变未来依赖结构，可检验在每种可部署点预测的期望MAE/MSE均不变时，评价中的事后差距是否变化。

本轮是诊断证据，未提高真实数据下游预测准确度。虚拟最优的乐观偏差已有[算法组合评价研究](https://www.cs.ubc.ca/~kevinlb/papers/2016-IJCAI-VBS.pdf)讨论，已知过程及理论最优的时序评价亦见[SynTSBench](https://arxiv.org/html/2510.20273v1)。不能把一般噪声选择偏差、误差展开或合成最优值作为新贡献。当前真实缺失主结果仍缺乏稳定强基线优势，投稿目标尚未达到。
