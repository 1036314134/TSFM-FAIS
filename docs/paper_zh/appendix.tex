\section{拟合细节与对比定义}
\label{app:training}

\paragraph{主方法。}
北京的十一个变量分别为 PM2.5、PM10、SO2、NO2、CO、O3、气温、气压、露点、降雨量和风速，不包括风向与日历标识。每个 PM 目标通过共同可观测前缀上的绝对相关性选择三个其他站点。全部当前目标估计使用实际有观测的预测变量，采用式~\eqref{eq:ridge}~中的 128 行支持阈值和 $10^{-3}$ 岭惩罚。预测器读取前缀标准化后的 float32 输入，输出评分保留相同前缀单位；每种模型输入表示均直接回写原观测。主方法不增加额外归一化、注意力掩码或学习式嵌入。

VAR 在相同前 7012 小时内原本完整的相邻行上拟合，十二个站点各有 4052--5990 个完整转移对。谱半径稳定化、协方差正则化、精确观测滤波和等权输出融合均按第~\ref{sec:method}~节固定。预测器读取长历史，回归修复和 VAR 状态估计使用近期 192 小时窗口。这种不同分支采用不同历史范围的方式属于方法定义，并由匹配对照保持一致。

\paragraph{高斯与局部回归对照。}
设 $m$ 和 $o$ 分别索引某时刻的缺失坐标和已观测坐标，静态高斯修复为 $\mu_m+\Sigma_{mo}\Sigma_{oo}^{-1}(x_o-\mu_o)$。矩参数由前缀拟合，协方差采用与统计系统相同的收缩方式；每个时刻独立条件化，不使用 VAR 时间转移。局部岭回归将预测变量限制为原有十一个站内变量。“仅目标”预测对照中的修复仍可能利用本地或同伴观测，改变的是直接提供给冻结预测器的变量。因此，仅目标预测不能解释为完全不使用协变量信息的实验。

\paragraph{神经填补。}
SAITS 和 TimeMixer++ 在十二条扩展训练前缀中抽取 512 个长度为 192 的窗口共享拟合，窗口步长为 24。训练掩码涵盖随机点、独立块、同步块、错位相关块、值依赖和混合缺测，缺失率为 0.1--0.5，掩码种子为 1101--1103。每个模型训练 50 轮，批量大小为 16，初始化种子为 0。SAITS 采用两层结构、64 维模型表示、128 维前馈层和四个注意力头。实现使用各自的填补目标，不通过 Chronos-2 联合优化。MoTM 保留已发布神经参数及固定上下文适配设置，其中岭系数为 0.5。全部修复对照保留原观测，并在需要时使用相同的固定有限值回退。

\paragraph{低秩适配。}
两套 LoRA 对照在所有自注意力的查询、键、值、输出投影，以及输出片段投影上增加分支。降维投影采用 Kaiming 均匀初始化，升维投影初始化为零，种子为 7402。北京提供来自 96 个历史的 864 个源任务，其训练未来最晚结束于第 7012 小时，预处理前缀结束于第 3506 小时。HDB 仅使用前 336 小时，历史锚点为 192、216、240、264、288 和 312。HDB 预处理统计量与同伴选择使用这一可用的 336 小时训练集，不声称对每个源锚点均只使用严格早于锚点的数据。两种适配使用相同未来标签。缺失扰动训练保留原生缺失，额外加入目标、目标与同伴、全部变量三类固定缺测，缺失时长为 6、24 和 54 小时。源任务池由 204 个历史产生 1836 个任务，按固定来源平衡顺序为每个来源选择 864 次更新，总计 1728 次。当前评价未来不参与拟合。

\section{HDB 观测含义与保留时段}
\label{app:hdb}

HDB 小时值表示最新的合格 C 类型可用停车位报告。每次请求使用网格时刻前一分钟，快照及车场更新时间均须位于此前一小时内。原始数值、容量、更新时间和记录年龄分别保留，并区分记录缺席、过期、冲突、格式异常及技术失败。合格报告不一定对应恰好在整点进行的物理测量。

1344 小时集合包含 2,694,720 个车场与小时单元。拟合与开发区间分别为 $[0,336)$ 和 $[336,672)$；$[672,1008)$ 与 $[1008,1344)$ 尚未评分。十八个合格车场的十九个自然缺口任务用于组件迁移比较，样本量与未来观测要求限制了推断范围。
